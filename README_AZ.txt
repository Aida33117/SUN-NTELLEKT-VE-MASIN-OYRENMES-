SÜNİ İNTELLEKT VƏ MAŞIN ÖYRƏNMƏSİ — VAHİD ELEKTRON DƏRSLİK
Mingəçevir Dövlət Universiteti · Riyaziyyat və İnformasiya Texnologiyaları fakültəsi

Açılış:
1. ZIP arxivini kompüterinizə endirin.
2. Arxivi tam şəkildə bir qovluğa çıxarın (Extract All).
3. Əsas qovluqdakı index.html faylını Chrome, Edge və ya Firefox brauzerində açın.
4. Sol tərəfdəki mündəricatdan Giriş və ya 1–20-ci fəsillərdən birini seçin.

Quruluş:
- Giriş və metodiki bölmə: müəllif haqqında son yenilənmiş məlumat, müəllif portreti və kitabın PNG üz qabığı.
- Fəsil 1–20: hər fəsil ayrıca qovluqda saxlanılır və vahid kitab interfeysindən açılır.
- Hər fəslin öz HTML/CSS/JavaScript faylları və resursları qorunur.
- Fəsillərdəki interaktiv qrafiklər, diaqramlar, cədvəllər, kod nümunələri, testlər və laboratoriya elementləri orijinal səhifələrindən yüklənir.

Vacib:
- index.html faylını ZIP-in içindən birbaşa açmayın; əvvəlcə arxivi tam çıxarın.
- chapters qovluğunu və onun alt qovluqlarını silməyin və ya başqa yerə köçürməyin.
- Bəzi Google Colab və xarici dataset nümunələri internet bağlantısı tələb edir.
- Bu vahid buraxılışda fəsillər vahid naviqasiya altında birləşdirilib; hər fəslin orijinal interaktiv işləmə mühiti qorunmaq üçün daxili çərçivədə açılır.


YENİLƏNMİŞ OXU İDARƏETMƏSİ — 20 FƏSLİN HAMISI
Hər fəsildə başlıq hissəsinin altında eyni idarəetmə paneli mövcuddur:
- Oxu rejimi: mündəricat yan panelini gizlədir və oxu sahəsini genişləndirir.
- A+: mətn ölçüsünü artırır.
- A−: mətn ölçüsünü azaldır.
- Görünüş: açıq və tünd rejim arasında keçir.
- Çap / PDF: brauzerin çap pəncərəsini açır; PDF kimi saxlamaq mümkündür.

Bu idarəetmə düymələri 1–20-ci fəsillərin hər birində ayrıca yoxlanılmışdır.
