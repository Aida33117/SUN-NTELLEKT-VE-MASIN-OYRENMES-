2.1. Süni intellektdə riyazi aparatın rolu

Mövzunun əsas anlayışları və süni intellektdə tətbiqi

Riyaziyyat süni intellektin sadəcə nəzəri fonu deyil; verilənlərin təsviri, modelin qurulması, öyrədilməsi və nəticələrin qiymətləndirilməsi üçün formal dildir. Maşın öyrənməsi (MÖ) müşahidələri ədədi obyektlərə çevirir, model bu obyektlər arasındakı qanunauyğunluğu parametrli funksiya ilə ifadə edir, optimallaşdırma isə parametrləri məqsəd funksiyasını yaxşılaşdıracaq istiqamətdə dəyişir.

Xətti cəbr

Verilənlər matrisləri, vektorlar, neyron qatları və çevrilmələr.

Analiz

Törəmə, gradient, zəncir qaydası və itki funksiyasının azaldılması.

Ehtimal-statistika

Qeyri-müəyyənlik, paylanmalar, nümunə və model keyfiyyəti.

Məsələn, elektron poçtun spam olub-olmadığını təyin edən sistem məktubun sözlərini, göndərən ünvanını və digər əlamətləri ədədi vektora çevirir. Təsnifat modeli bu vektoru sinif ehtimallarına xəritələyir. Modelin səhvi itki funksiyası ilə ölçülür və parametr yenilənməsi optimallaşdırma üsulu ilə aparılır.

Əsas fikir: Riyazi model reallığın sadələşdirilmiş təsviridir. Yaxşı model yalnız mürəkkəb düsturlardan ibarət deyil; fərziyyələri aydın, ölçülə bilən və verilənlərlə yoxlanıla bilən olmalıdır.

2.2. Ədədi dəyişənlər, funksiyalar və koordinat sistemi

Mövzunun əsas anlayışları və süni intellektdə tətbiqi

Dəyişən müəyyən qiymətlər ala bilən kəmiyyətdir. Süni intellektdə dəyişənlər giriş əlamətlərini (məsələn, temperatur, yaş, enerji sərfi), hədəf dəyişəni (məsələn, tələb olunan proqnoz) və model parametrlərini ifadə edir. Diskret dəyişən sayılan qiymətlər, fasiləsiz dəyişən isə interval daxilində istənilən real qiyməti ala bilər.

Funksiya hər bir icazə verilən girişə müəyyən çıxış uyğunlaşdırır: y = f(x) Xətti funksiya f(x)=wx+b formasındadır. Burada w meyl əmsalı, b sərbəst həddir. Koordinat müstəvisində x üfüqi, y şaquli oxda yerləşdirilir.

İşlənmiş nümunə

Bir binanın gündəlik enerji sərfini orta temperaturla modelləşdirək: E(T)=−2T+120. T=15°C olduqda E=−2·15+120=90 vahid. Bu modeldə temperatur 1°C artdıqda proqnoz sərfi 2 vahid azalır. Bu, verilənlərdən öyrənilmiş səbəb əlaqəsi deyil, verilmiş xətti modelin riyazi şərhidir.

Koordinat sistemi iki əlamətin birgə təsirini vizuallaşdırmağa kömək edir. Çoxəlamətli verilənlərdə isə hər əlamət ayrıca ölçü yaradır; 100 əlamətli müşahidə 100 ölçülü fəzada nöqtə kimi qəbul edilə bilər.

2.3. Xətti cəbrin əsas anlayışları

Mövzunun əsas anlayışları və süni intellektdə tətbiqi

Xətti cəbr vektor fəzası, xətti asılılıq, bazis, ölçü, xətti çevrilmə və matris anlayışlarını öyrənir. MÖ-də verilənlərin saxlanması və çevrilməsi çox vaxt bu obyektlər vasitəsilə aparılır.

Xətti kombinasiya vektorların skalyar əmsallarla vurulub toplanmasıdır: v=a₁v₁+…+aₙvₙ. Vektorlar bir-birindən xətti asılı deyilsə, heç biri digərlərinin xətti kombinasiyası kimi yazıla bilməz. Bazis fəzanın bütün vektorlarını yaratmağa imkan verən xətti asılı olmayan vektorlar sistemidir.

Ölçü bazisdəki vektorların sayıdır. Məsələn, müstəvi 2 ölçülüdür. Maşın öyrənməsində müşahidənin əlamət sayı onun ilkin xüsusiyyət fəzasının ölçüsünü müəyyən edir. Ölçülərin çoxluğu hesablama yükünü, yaddaş tələbatını və overfitting riskini artıra bilər.

Nümunə

v₁=(1,0), v₂=(0,1) vektorları R² üçün standart bazisdir. (3,4)=3(1,0)+4(0,1). Deməli, hər ikiölçülü nöqtə bu bazis üzrə iki koordinatla ifadə edilir.

2.4. Vektorlar və vektor əməliyyatları

Mövzunun əsas anlayışları və süni intellektdə tətbiqi

Vektor istiqaməti və modulu olan kəmiyyətdir. MÖ-də bir müşahidə, istifadəçi profili, şəkil piksel bloku və ya sözün embedding təsviri vektor kimi təqdim edilə bilər. n ölçülü vektor x=(x₁,x₂,…,xₙ) şəklində yazılır.

Toplama komponentlər üzrə aparılır: (a₁,…,aₙ)+(b₁,…,bₙ)=(a₁+b₁,…,aₙ+bₙ). Skalyara vurma hər komponenti həmin ədədə vurur. Evklid norması vektorun uzunluğunu ölçür:

\[\|\mathbf{x}\|_2=\sqrt{\sum_{i=1}^{n}x_i^2}\]

Hesab nümunəsi

a=(2,−1,3), b=(1,4,0). a+b=(3,3,3); 2a=(4,−2,6); ‖a‖₂=√(4+1+9)=√14≈3.742. Normallaşdırılmış vektor x/‖x‖₂ uzunluğu 1 olan istiqamət vektorudur.

Oxşarlıq ölçməsində kosinus oxşarlığı istifadə olunur: cosθ=(a·b)/(‖a‖‖b‖). Bu göstərici mətn embedding-ləri və tövsiyə sistemlərində istiqamət uyğunluğunu qiymətləndirməyə kömək edir.

2.5. Skalyar hasil və çəkili cəm

Mövzunun əsas anlayışları və süni intellektdə tətbiqi

İki vektorun skalyar hasili uyğun komponentlərin hasilinin cəmidir:
\[\mathbf{a}\cdot\mathbf{b}=\sum_{i=1}^{n}a_i b_i=\|\mathbf{a}\|\,\|\mathbf{b}\|\cos\theta\]
. Nəticə skalyardır. Skalyar hasil həm ölçülərin uyğunluğunu, həm də vektorların istiqamət yaxınlığını xarakterizə edir.

Çəkili cəm modelin giriş əlamətlərini əhəmiyyət əmsalları ilə birləşdirir: z=w₁x₁+…+wₙxₙ+b. Bu, süni neyronun əsas xətti hesablamasıdır. Çəkilər modelin öyrəndiyi parametrlərdir, bias isə çıxışı sürüşdürür.

Ətraflı nümunə

x=(2,5,1), w=(0.4,−0.2,1.5), b=0.3. Skalyar hasil 0.4·2+(−0.2)·5+1.5·1=0.8−1+1.5=1.3. Bias əlavə etdikdə z=1.6. Əgər sigmoid aktivasiya tətbiq edilirsə, σ(z)=1/(1+e⁻ᶻ)≈0.832. Bu qiymət ikili təsnifatda müsbət sinif üçün model çıxışı kimi şərh oluna bilər; ehtimal şərhi modelin kalibrlənməsindən də asılıdır.

2.6. Matrislər və matris əməliyyatları

Mövzunun əsas anlayışları və süni intellektdə tətbiqi

Matris sətir və sütunlardan ibarət ədədlər cədvəlidir. A∈Rᵐˣⁿ yazılışı A matrisinin m sətrə və n sütuna malik olduğunu bildirir. MÖ-də sətirlər müşahidələri, sütunlar əlamətləri göstərə bilər.

Eyni ölçülü matrislər toplanır və çıxılır. Skalyara vurma bütün elementlərə tətbiq olunur. Transponirləmə sətir və sütunları dəyişir: Aᵀ. Matrisin ölçüləri əməliyyatın mümkünlüyünü müəyyən edir.

Nümunə

\(A=\begin{bmatrix}1&2\\3&4\end{bmatrix},\quad B=\begin{bmatrix}2&0\\1&-1\end{bmatrix}\). Toplama: \(A+B=\begin{bmatrix}3&2\\4&3\end{bmatrix}\). Transponirləmə: \(A^T=\begin{bmatrix}1&3\\2&4\end{bmatrix}\). Skalyara vurma: \(2A=\begin{bmatrix}2&4\\6&8\end{bmatrix}\). Matrislər üzərində elementar əməliyyatlar verilənlərin çevrilməsi və parametr yenilənməsinin əsasını təşkil edir.

Ölçü intizamı: Matris vurulmasında daxili ölçülər uyğun olmalıdır. (m×n)·(n×p) nəticəsində (m×p) ölçülü matris alınır.

2.7. Matris vurulması və neyron şəbəkələrində tətbiqi

Mövzunun əsas anlayışları və süni intellektdə tətbiqi

Matris vurulması yalnız daxili ölçülər uyğun olduqda mümkündür. Əgər \(A\in\mathbb{R}^{m\times n}\) və \(B\in\mathbb{R}^{n\times p}\) olarsa, hasil \(C=AB\in\mathbb{R}^{m\times p}\) ölçülü olur. Hasilin hər elementi A matrisinin i-ci sətri ilə B matrisinin j-ci sütununun skalyar hasilidir:

\[C_{ij}=\sum_{k=1}^{n}A_{ik}B_{kj}\]

Neyron şəbəkəsinin tam əlaqəli qatında X giriş matrisi, W öyrənilən çəkilər matrisi, b bias vektoru, Z isə aktivasiya öncəsi nəticədir. Bu fəsildə X sətirləri müşahidələri, sütunları əlamətləri göstərən matris kimi qəbul edilir:

\[X_{m\times n}W_{n\times p}+\mathbf{1}_{m\times1}\mathbf{b}_{1\times p}=Z_{m\times p}\]

Burada bias vektoru \(\mathbf b\in\mathbb{R}^{1\times p}\) hər müşahidəyə əlavə edilir. Aktivasiya funksiyası elementlər üzrə tətbiq olunur: \(H=f(Z)\). Ölçülər: X — m×n, W — n×p, b — 1×p, Z və H — m×p.

Hesablanmış nümunə

İki müşahidə, iki giriş əlaməti və iki neyron götürək:

\[X=\begin{bmatrix}1&2\\3&1\end{bmatrix},\quad W=\begin{bmatrix}0.5&1\\-1&2\end{bmatrix},\quad \mathbf b=\begin{bmatrix}0.1&-0.2\end{bmatrix}\]

Əvvəl XW hasilini hesablayaq:

\[XW=\begin{bmatrix}1(0.5)+2(-1)&1(1)+2(2)\\3(0.5)+1(-1)&3(1)+1(2)\end{bmatrix}=\begin{bmatrix}-1.5&5\\0.5&5\end{bmatrix}\]

İndi bias vektorunu hər sətrə əlavə edirik:

\[Z=\begin{bmatrix}-1.5+0.1&5-0.2\\0.5+0.1&5-0.2\end{bmatrix}=\begin{bmatrix}-1.4&4.8\\0.6&4.8\end{bmatrix}\]

Beləliklə, birinci müşahidə üçün neyronların xalis girişləri −1.4 və 4.8, ikinci müşahidə üçün isə 0.6 və 4.8-dir. ReLU aktivasiya funksiyası \(f(z)=\max(0,z)\) tətbiq edilərsə:

\[H=\begin{bmatrix}0&4.8\\0.6&4.8\end{bmatrix}\]
Yoxlama qaydası: X-in sütun sayı W-nin sətir sayına bərabər olmalıdır. Nəticənin sətir sayı X-dən, sütun sayı W-dən götürülür. Ölçülər uyğun deyilsə, vurma əməliyyatı müəyyən edilməyib.

2.8. Funksiyanın törəməsi və dəyişmə sürəti

Mövzunun əsas anlayışları və süni intellektdə tətbiqi

Törəmə funksiyanın girişdəki kiçik dəyişməyə nə qədər həssas olduğunu göstərir. Geometrik baxımdan toxunanın meylidir, fiziki baxımdan ani dəyişmə sürətidir. Törəmə limiti:
\[f'(x)=\lim_{h\to 0}\frac{f(x+h)-f(x)}{h}\]

Əsas qaydalar: (c)′=0; (xⁿ)′=nxⁿ⁻¹; (cf)′=cf′; (f±g)′=f′±g′. Məsələn, f(x)=3x²+2x−5 üçün f′(x)=6x+2. x=2 nöqtəsində meyl 14-dür.

Gradient descent ilə əlaqə

İtki funksiyası L(w) parametrdən asılıdır. Törəmə L-nin artma istiqamətini göstərir; minimuma yaxınlaşmaq üçün əks istiqamətdə addım atılır:

\[w_{t+1}=w_t-\eta L'(w_t)\]
Burada η öyrənmə sürətidir. Çox böyük η minimumun ətrafında sıçrayışa, çox kiçik η isə yavaş öyrənməyə səbəb ola bilər.

2.9. Qismən törəmələr və çoxdəyişənli funksiyalar

Mövzunun əsas anlayışları və süni intellektdə tətbiqi

Çoxdəyişənli funksiya bir neçə girişdən asılıdır: z=f(x,y). Qismən törəmə digər dəyişənləri sabit saxlayaraq yalnız bir dəyişən üzrə dəyişmə sürətini ölçür: ∂f/∂x və ∂f/∂y.

Nümunə: f(x,y)=x²+3xy+2y². ∂f/∂x=2x+3y, ∂f/∂y=3x+4y. (x,y)=(1,2) nöqtəsində gradient ∇f=(8,11). Gradient funksiyanın ən sürətli artım istiqamətini göstərir; mənfi gradient azalma istiqamətidir.

Çoxparametrli modeldə w=(w₁,…,wₙ) vektoru var. Gradient bütün qismən törəmələri bir vektorda birləşdirir. Hər parametr üçün ayrıca törəmə hesablamaq modelin öyrədilməsinin əsas mexanizmidir.

2.10. Zəncir qaydası və onun maşın öyrənməsində tətbiqi

Mövzunun əsas anlayışları və süni intellektdə tətbiqi

Zəncir qaydası mürəkkəb funksiyanın törəməsini daxili funksiyaların törəmələrinin hasili kimi hesablayır. Əgər y=f(u), u=g(x), onda dy/dx=(dy/du)(du/dx). Neyron şəbəkəsi ardıcıl qatların kompozisiyası olduğuna görə geriyə yayılma (backpropagation) bu qaydaya əsaslanır.

Sadə hesab

u=2x+1, y=u². dy/du=2u, du/dx=2. Deməli dy/dx=4u=4(2x+1). x=3 üçün u=7 və dy/dx=28. Birbaşa y=(2x+1)²=4x²+4x+1 törəməsi 8x+4 verir; x=3 üçün 28. Hər iki yol eyni nəticəni verir.

Bir neyron üçün z=wx+b, a=σ(z), L=½(a−t)². Zəncir qaydası ilə ∂L/∂w=(a−t)·σ′(z)·x. Bu düstur itkinin çəkiyə görə dəyişməsini hesablayır və çəkini yeniləməyə imkan verir.

2.11. Ehtimal nəzəriyyəsinin əsasları

Mövzunun əsas anlayışları və süni intellektdə tətbiqi

Ehtimal hadisənin baş vermə qeyri-müəyyənliyini 0 və 1 arasında ədədlə ifadə edir. Ω nümunə fəzası bütün mümkün nəticələr çoxluğudur, A⊆Ω hadisədir. P(A) ehtimalı 0≤P(A)≤1 şərtini ödəyir; P(Ω)=1.

Əsas qaydalar: P(Aᶜ)=1−P(A); P(A∪B)=P(A)+P(B)−P(A∩B). Əgər A və B müstəqildirsə, P(A∩B)=P(A)P(B). Şərti ehtimal P(A|B)=P(A∩B)/P(B), P(B)>0.

Bayes qaydası

P(A|B)=P(B|A)P(A)/P(B). Tibbi test nümunəsində xəstəliyin ilkin ehtimalı, testin həssaslığı və spesifikliyi birlikdə nəticənin şərhini dəyişir. Müsbət test həmişə xəstəliyin yüksək ehtimalı demək deyil; nadir hadisələrdə yanlış müsbət nəticələrin payı əhəmiyyətli ola bilər.

2.12. Təsadüfi dəyişənlər və ehtimal paylanmaları

Mövzunun əsas anlayışları və süni intellektdə tətbiqi

Təsadüfi dəyişən təsadüfi təcrübənin nəticələrini ədədlərlə ifadə edən funksiyadır. Diskret dəyişən sayılan qiymətlər, fasiləsiz dəyişən intervaldakı qiymətlər ala bilər. Diskret halda ehtimal kütlə funksiyası, fasiləsiz halda sıxlıq funksiyası istifadə edilir.

Bernoulli paylanması iki nəticəli hadisəni modelləşdirir: P(X=1)=p, P(X=0)=1−p. Binomial paylanma n müstəqil Bernoulli sınağında uğurların sayını modelləşdirir. Normal paylanma μ orta və σ standart kənarlaşma ilə müəyyən edilir; bir çox ölçmə və xətaların təxmini modelləşdirilməsində istifadə olunur.

Gözlənilən qiymət diskret halda E[X]=ΣxP(X=x), dispersiya Var(X)=E[(X−μ)²]. Paylanma modelin qeyri-müəyyənliyini və proqnozların dəyişkənliyini təsvir etməyə imkan verir.

2.13. Riyazi statistika, dispersiya və standart kənarlaşma

Mövzunun əsas anlayışları və süni intellektdə tətbiqi

Statistika nümunə verilənlərindən ümumi populyasiya haqqında nəticə çıxarır. Populyasiya bütün maraq obyektləri, nümunə isə onun seçilmiş hissəsidir. Seçmə üsulu qərəz yarada bilər; böyük nümunə sistematik qərəzi avtomatik aradan qaldırmır.

Ədədi orta x̄=Σxᵢ/n, median sıralanmış verilənlərin ortasında yerləşən qiymətdir. Nümunə dispersiyası s²=Σ(xᵢ−x̄)²/(n−1), standart kənarlaşma s=√s². Dispersiya kvadrat vahidlə, standart kənarlaşma ilkin dəyişənin vahidi ilə ifadə olunur.

Hesab nümunəsi

Verilənlər 2, 4, 4, 6 olsun. Orta 4, median 4. Kvadrat fərqlər 4,0,0,4; cəm 8. Populyasiya dispersiyası 8/4=2, standart kənarlaşma √2≈1.414. Nümunə dispersiyası 8/3≈2.667, s≈1.633. Hansı düsturun seçilməsi verilənlərin populyasiya, yoxsa nümunə olmasından asılıdır.

Standartlaşdırma z=(x−μ)/σ əlamətləri müqayisə edilə bilən miqyasa gətirir. Təlim və test məlumatlarının ayrılması, məlumat sızmasının qarşısını almaq üçün standartlaşdırma parametrlərinin yalnız təlim dəstindən hesablanması vacibdir.

2.14. Optimallaşdırma məsələlərinin riyazi əsasları

Mövzunun əsas anlayışları və süni intellektdə tətbiqi

Optimallaşdırma müəyyən məhdudiyyətlər daxilində məqsəd funksiyasının minimum və ya maksimum qiymətini tapır. MÖ-də çox vaxt itki funksiyası minimallaşdırılır: minθ L(θ). Parametrlər θ, verilənlər isə itki funksiyasının hesablanmasına təsir edir.

Birölçülü funksiyada stasionar nöqtələr L′(θ)=0 şərtindən tapılır. İkinci törəmə L″(θ)>0 olduqda lokal minimum üçün kifayət şərt ola bilər. Çoxölçülü halda ∇L(θ)=0 və Hessian matrisinin müsbət müəyyənliyi nəzərdən keçirilir.

Gradient descent hesabı

L(w)=(w−3)², L′(w)=2(w−3). w₀=0, η=0.1. w₁=0−0.1·(−6)=0.6; w₂=0.6−0.1·(−4.8)=1.08; w₃=1.08−0.1·(−3.84)=1.464. Parametr 3 minimumuna yaxınlaşır. Bu nümunədə addım sabitdir və funksiya qabarıqdır.

Praktik modellərdə SGD, mini-batch gradient descent, momentum və Adam kimi üsullar istifadə edilir. Öyrənmə sürəti, başlanğıc parametrlər, normallaşdırma və itki səthinin quruluşu nəticəyə təsir edir.

import numpy as np
import sympy as sp
import matplotlib.pyplot as plt

# 1. Vektorlar
v = np.array([2, -1, 3], dtype=float)
u = np.array([1, 4, 0], dtype=float)
print("v + u =", v + u)
print("Skalyar hasil =", np.dot(v, u))
print("||v|| =", np.linalg.norm(v))

# 2. Matrislər
A = np.array([[1, 2], [3, 4]], dtype=float)
B = np.array([[2, 0], [1, -1]], dtype=float)
print("A + B =
", A + B)
print("A @ B =
", A @ B)

# 3. Simvolik törəmə
x, y = sp.symbols('x y')
f = 3*x**2 + 2*x - 5
print("f'(x) =", sp.diff(f, x))
g = x**2 + 3*x*y + 2*y**2
print("df/dx =", sp.diff(g, x))
print("df/dy =", sp.diff(g, y))

# 4. Statistik göstəricilər
data = np.array([2, 4, 4, 6], dtype=float)
print("Orta =", np.mean(data))
print("Median =", np.median(data))
print("Populyasiya dispersiyası =", np.var(data))
print("Nümunə dispersiyası =", np.var(data, ddof=1))
print("Standart kənarlaşma =", np.std(data))

# 5. Gradient descent: L(w) = (w - 3)^2
w = 0.0
eta = 0.1
history = []
for step in range(30):
    loss = (w - 3)**2
    grad = 2*(w - 3)
    history.append((step, w, loss))
    w = w - eta*grad
print("Yekun w =", w)
print("Minimum nöqtəyə yaxınlaşma:", history[-1])

steps = [r[0] for r in history]
losses = [r[2] for r in history]
plt.plot(steps, losses, marker='o')
plt.xlabel('İterasiya')
plt.ylabel('İtki')
plt.title('Gradient descent zamanı itkinin azalması')
plt.grid(True)
plt.show()
