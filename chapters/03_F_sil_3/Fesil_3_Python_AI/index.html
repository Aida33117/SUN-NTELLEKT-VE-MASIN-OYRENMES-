3.6. Funksiyalar və modullar

Funksiya müəyyən işi ad altında birləşdirir, təkrar istifadəni və test etməni asanlaşdırır. return funksiyanın nəticəsini çağıran hissəyə qaytarır. Modul isə Python kodunun ayrıca faylda təşkilidir.

Funksiya nümunəsi
def normalize_score(score, maximum=100):
    """Balı 0–1 intervalına normallaşdırır."""
    if maximum <= 0:
        raise ValueError("maximum müsbət olmalıdır")
    return score / maximum

print(normalize_score(84))
Nəticəni görmək üçün seçin.

Funksiya üçün girişin yoxlanılması vacibdir. Məsələn, maksimum bal sıfır və ya mənfi ola bilməz. Böyük layihədə funksiyaları src/ qovluğundakı modullara bölmək, hər modula aydın məsuliyyət vermək məqsədəuyğundur.

3.8. NumPy ilə ədədi hesablamalar

NumPy çoxölçülü massivlər və vektorlaşdırılmış ədədi əməliyyatlar üçün əsas kitabxanalardandır. ndarray massivinin shape atributu ölçüləri, ndim ölçülülüyü, dtype isə element tipini göstərir.

Şəkil 3.4. İkiölçülü NumPy massivində sıfırdan başlayan indeksləmə.
İnteraktiv kod pəncərəsi · massiv əməliyyatları 
import numpy as np
A = np.array([[2, 4, 6],
              [1, 3, 5]])

print(A.shape)       # (2, 3)
print(A[1, 2])       # 5
print(A.mean(axis=0))# sütun ortalamaları
print(A * 2)         # hər elementi 2-yə vurur
Nəticəni görmək üçün seçin.

axis=0 sütunlar üzrə, axis=1 sətirlər üzrə aqreqasiyanı ifadə edir. Bu parametrin mənası əməliyyatdan asılı olaraq diqqətlə yoxlanmalıdır.

Broadcasting

NumPy ölçüləri uyğun olan massivlər arasında bəzi əməliyyatları avtomatik genişləndirmə ilə yerinə yetirir. Məsələn, 2×3 matrisə 3 elementli sətir vektoru əlavə edilə bilər; vektor hər sətirə tətbiq olunur. Uyğunluq sağdan sola yoxlanır: ölçülər bərabər olmalı və ya onlardan biri 1 olmalıdır.

df = pd.DataFrame({

3.11. Scikit-learn kitabxanasına giriş

Scikit-learn klassik maşın öyrənməsi üçün vahid API təqdim edir. Tipik iş axını: verilənləri ayırmaq, modeli yaratmaq, fit() ilə öyrətmək, predict() ilə proqnoz almaq və uyğun metriklərlə qiymətləndirmək.

Şəkil 3.7. Scikit-learn ilə nəzarətli öyrənmənin sadələşdirilmiş iş axını.
İnteraktiv nümunə · train/test və KNN
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import accuracy_score

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42, stratify=y
)
model = KNeighborsClassifier(n_neighbors=5)
model.fit(X_train, y_train)
pred = model.predict(X_test)
print("Accuracy:", accuracy_score(y_test, pred))
Kod Python mühitində icra olunmalıdır.

Bu səhifədəki interaktiv pəncərələr brauzerdə öyrədici nəticə simulyasiyası və kod nümunəsinin gedişini göstərir. Tam Python icrası üçün kodu Google Colab və ya Jupyter Notebook-a köçürüb işə salın.

İnteraktiv neyron şəbəkəsi qurucusu

Aşağıdakı alət tam model təlim etmir; şəbəkənin arxitekturasını və parametr sayını hesablayan tədris simulyatorudur. Giriş xüsusiyyətlərinin, gizli qatların və çıxış neyronlarının sayını dəyişərək nəticəni müşahidə edin.

Düyməni seçərək arxitekturanı hesablayın.
Şəbəkə diaqramı burada görünəcək.

Fully connected (dense) qat üçün giriş ölçüsü \(n_{in}\), çıxış ölçüsü \(n_{out}\) olduqda, bias daxil edilirsə parametr sayı:

\[P=n_{in}n_{out}+n_{out}= (n_{in}+1)n_{out}\]

Bias daxil edilmirsə \(P=n_{in}n_{out}\). Bu düstur yalnız tam əlaqəli qat üçündür; konvolyusiya qatlarında parametr sayı filtr ölçülərindən və kanal sayından asılıdır.

Sadə modelin konseptual kodu

# Keras (TensorFlow backend nümunəsi)
import tensorflow as tf

model = tf.keras.Sequential([
    tf.keras.layers.Input(shape=(4,)),
    tf.keras.layers.Dense(8, activation="relu"),
    tf.keras.layers.Dense(3, activation="softmax")
])
model.summary()

4 giriş xüsusiyyəti, 8 neyronlu bir gizli qat və 3 çıxış neyronu olan təsnifat modelidir. Softmax çıxışları çoxsinifli təsnifatda sinif ehtimalları kimi şərh edilə bilər; bu şərh modelin təlim və kalibrlənmə keyfiyyətindən asılıdır.

Laboratoriya üçün kod

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

data = {
    "student": ["S1", "S2", "S3", "S4", "S5", "S6"],
    "study_hours": [1.5, 2.0, 3.0, 3.5, 4.0, 5.0],
    "score": [48, 55, 67, 72, 81, 91],
    "group": ["A", "A", "A", "B", "B", "B"]
}
df = pd.DataFrame(data)

print("İlk sətirlər:")
display(df.head())
print("\\nMəlumat tipləri:")
print(df.dtypes)
print("\\nTəsviri statistika:")
display(df[["study_hours", "score"]].describe())

scores = df["score"].to_numpy()
print("Orta bal:", np.mean(scores))
print("Standart kənarlaşma (population):", np.std(scores, ddof=0))
print("Qruplar üzrə orta bal:")
display(df.groupby("group")["score"].mean())

plt.figure(figsize=(7, 4))
plt.hist(df["score"], bins=5, edgecolor="black")
plt.xlabel("İmtahan balı")
plt.ylabel("Tələbə sayı")
plt.title("İmtahan ballarının paylanması")
plt.show()

plt.figure(figsize=(7, 4))
plt.scatter(df["study_hours"], df["score"])
plt.xlabel("Təlim saatı")
plt.ylabel("İmtahan balı")
plt.title("Təlim saatı və imtahan balı")
plt.grid(True)
plt.show()

Gözlənilən nəticələrin təhlili

Verilənlərdə 6 müşahidə var. Orta bal 69-dir. Population standart kənarlaşması np.std(..., ddof=0) ilə hesablanır; seçmə standart kənarlaşması üçün ddof=1 istifadə edilməlidir. Qruplar üzrə ortalama A qrupunda 56.67, B qrupunda 81.33-dür. Bu kiçik sintetik nümunə səbəb-nəticə əlaqəsini sübut etmir.
