4.1. Verilən anlayışı və süni intellektdə verilənlərin əhəmiyyəti

Verilən (data) müşahidə, ölçmə, qeydiyyat və ya hesablama nəticəsində əldə olunan faktların simvol, rəqəm, mətn, səs, şəkil və digər formalarda təqdimatıdır. Verilənlər kontekstə və şərh qaydasına qoşulduqda informasiya yaradır. Süni intellekt sistemi verilənlərdəki nümunə və qanunauyğunluqları öyrənərək proqnoz, təsnifat və ya qərar dəstəyi yarada bilər.

Verilən → informasiya → bilik

Şəkil 4.2. Xam veriləndən şərh edilən biliyə keçid.

AI modelinin performansı verilənlərin həcmi ilə yanaşı, təmsilçilik, etiketlərin keyfiyyəti, ölçmə xətası, sinif balansı və məlumatların zaman/məkan uyğunluğundan asılıdır. Böyük dataset avtomatik olaraq keyfiyyətli dataset demək deyil.

Nümunə: “23” rəqəmi təkbaşına məna daşımır. “Tələbənin yaşı 23” və “sensorun temperatur göstəricisi 23 °C” fərqli dəyişənlərdir. Ölçü vahidi, mənbə və kontekst mütləq saxlanmalıdır.

4.3. Dataset, müşahidə, xüsusiyyət və hədəf dəyişəni

Dataset müəyyən tədqiqat və ya analitik məqsəd üçün toplanmış müşahidələr toplusudur. Cədvəl formasında hər sətir müşahidəni, sütun isə dəyişəni ifadə edə bilər. Bu, bütün verilənlərə aid universal qayda deyil; şəkil, audio və mətn datasetlərində struktur fərqli ola bilər.

Şəkil 4.4. Cədvəl datasetində müşahidə və dəyişən anlayışları.

Datasetin ölçüsü çox vaxt \(n\times p\) kimi yazılır: \(n\) müşahidələrin, \(p\) xüsusiyyətlərin sayıdır. Hədəf sütunu ayrıca saxlanırsa, \(X\in\mathbb{R}^{n\times p}\) xüsusiyyət matrisi, \(y\in\mathbb{R}^{n}\) isə hədəf vektoru kimi göstərilə bilər (hədəfin kateqorial olması halında \(y\) kateqoriyalar ardıcıllığıdır).

Məsələn, 500 tələbə və 12 xüsusiyyət varsa, xüsusiyyət matrisi 500×12 ölçülüdür. Hədəf “imtahandan keçdi/keçmədi” olduqda 500 etiketdən ibarət vektor alınır.

4.4. Feature və Label anlayışları

Feature (xüsusiyyət) modelin girişində istifadə olunan dəyişəndir. Label/target (etiket/hədəf) nəzarətli öyrənmədə modelin proqnozlaşdırmalı olduğu cavabdır. Bir dəyişənin feature və ya label olması tədqiqat sualından asılıdır.

Şəkil 4.5. Nəzarətli öyrənmədə feature və label əlaqəsi.

Modelin hədəfi dolayı yolla açıqlayan sütun (məsələn, imtahan nəticəsi artıq hesablandıqdan sonra yaradılan “keçdi” statusunu müəyyən edən yekun qərar sütunu) feature kimi daxil edilərsə, target leakage yarana bilər. Feature seçimi yalnız korrelyasiyaya deyil, zaman ardıcıllığına, mövcudluq anına və tətbiq ssenarisinə əsaslanmalıdır.

4.8. Exploratory Data Analysis (EDA)

Exploratory Data Analysis (kəşfiyyat xarakterli verilən təhlili) datasetin strukturunu, paylanmalarını, dəyişənlərarası əlaqələri, qeyri-adi müşahidələri və mümkün keyfiyyət problemlərini araşdıran iterativ prosesdir. EDA yekun hipotez testini əvəz etmir və qrafikdə görünən əlaqəni səbəbiyyət kimi sübut etmir.

Şəkil 4.6. EDA-nın iterativ təhlil dövrü.

EDA üçün praktik yoxlama ardıcıllığı

  1. Datasetin mənbəyini və tədqiqat sualını müəyyənləşdirin.
  2. Ölçü, sütun tipləri, unikal qiymətlər və etiket paylanmasını yoxlayın.
  3. Çatışmayan və təkrarlanan qeydləri araşdırın.
  4. Ədədi dəyişənlərin histogram və boxplot-larını qurun.
  5. Kateqorial dəyişənlərin tezliklərini müqayisə edin.
  6. Korrelyasiya və qruplar arasındakı əlaqələri araşdırın.
  7. Müşahidələri kontekstlə şərh edin və emal qərarlarını sənədləşdirin.
EDA nəticəsi: “dataset təmizdir” kimi ümumi hökm deyil, konkret müşahidə və sübut olmalıdır: məsələn, “attendance sütununda 6 qeyddən 1-də qiymət yoxdur; bu qeyd ilkin mənbə ilə tutuşdurulacaq”.

4.9. Korrelyasiya və dəyişənlərarası əlaqələr

Korrelyasiya iki dəyişənin birlikdə dəyişmə dərəcəsini ölçür. Pearson korrelyasiya əmsalı xətti əlaqəni ölçür və \(-1\le r\le 1\) intervalındadır. \(r>0\) müsbət, \(r<0\) mənfi xətti əlaqəni, \(r\approx0\) isə xətti əlaqənin zəifliyini göstərir; bu, heç bir əlaqənin olmaması demək deyil.

\[r_{XY}=\frac{\sum_{i=1}^{n}(x_i-\bar{x})(y_i-\bar{y})}{\sqrt{\sum_{i=1}^{n}(x_i-\bar{x})^2}\sqrt{\sum_{i=1}^{n}(y_i-\bar{y})^2}}\]

Spearman korrelyasiyası qiymətlərin özündən deyil, sıralarından istifadə edərək monoton əlaqəni qiymətləndirir. Korrelyasiya səbəbiyyət demək deyil: üçüncü dəyişən, seçim qərəzi və zaman amili əlaqəni izah edə bilər.

İnteraktiv korrelyasiya nöqtə qrafiki

4.10. Çatışmayan qiymətlər və təkrarlanan qeydlər

Çatışmayan qiymət (missing value) ölçmənin aparılmaması, ötürülmə xətası, sensor nasazlığı və ya məlumatın paylaşılmaması səbəbindən yarana bilər. Pandas-da NaN ədədi çatışmayan qiymətləri, None isə obyekt sütunlarında çatışmayan dəyərləri təmsil edə bilər.

Çatışmayanlığın mexanizmləri

  • MCAR: çatışmazlıq müşahidə olunan və müşahidə olunmayan dəyişənlərdən asılı deyil.
  • MAR: çatışmazlıq müşahidə olunan dəyişənlərlə əlaqəlidir.
  • MNAR: çatışmazlıq çatışmayan qiymətin özündən və ya müşahidə olunmayan amildən asılı ola bilər.

Bu mexanizmlərin fərqləndirilməsi emal strategiyasına təsir edir. Sətiri silmək, orta/medianla doldurmaq və ya model əsaslı imputasiya seçmək kontekstdən asılıdır. Hədəf dəyişəninin çatışmayan qiymətlərini kor-koranə doldurmaq olmaz.

Pandas · missing və duplicate yoxlaması
missing_count = df.isna().sum()
missing_rate = df.isna().mean() * 100
duplicate_count = df.duplicated().sum()

print(missing_count)
print(missing_rate.round(1))
print("Duplicates:", duplicate_count)
Düyməni seçin.
Data leakage-dən qorunma: median/orta ilə doldurma parametrini yalnız təlim hissəsində öyrənin; sonra həmin parametr train və test çevirməsinə tətbiq edilsin. Scikit-learn Pipeline və SimpleImputer bu iş üçün uyğundur.

4.11. Kənar qiymətlərin ilkin aşkarlanması

Kənar qiymət (outlier) müşahidələrin əsas hissəsindən nəzərəçarpacaq dərəcədə fərqlənən qiymətdir. Kənar müşahidə səhv ölçmə, məlumat daxil etmə xətası və ya real nadir hadisə ola bilər. Buna görə outlier-i avtomatik silmək düzgün yanaşma deyil.

IQR üsulu

\[IQR=Q_3-Q_1\]
\[\text{Aşağı sərhəd}=Q_1-1.5\times IQR\]
\[\text{Yuxarı sərhəd}=Q_3+1.5\times IQR\]

Bu sərhədlər Tukey qaydasına əsaslanan ilkin aşkarlama meyarıdır; universal “səhv qiymət” sərhədi deyil.

Şəkil 4.7. Boxplot-un əsas hissələri və mümkün kənar müşahidələr.
Python · IQR ilə kənar qiymətləri tap
Q1 = df["score"].quantile(0.25)
Q3 = df["score"].quantile(0.75)
IQR = Q3 - Q1

lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR

outliers = df[(df["score"] < lower) |
              (df["score"] > upper)]
print(outliers)
Düyməni seçin.

Alternativ olaraq z-score istifadə edilə bilər: \(z=(x-\mu)/\sigma\). Paylanma normal deyilsə və ya outlier-lər orta və standart kənarlaşmanı ciddi dəyişirsə, z-score həssas ola bilər.

Laboratoriya işi №4

Real dataset · Statistik təsvir · EDA · Korrelyasiya heatmap

Mövzu

Real dataset əsasında ilkin statistik təhlil, EDA və korrelyasiya xəritəsinin yaradılması.

Məqsəd

Real açıq dataset seçmək, onun mənşəyini və strukturunu sənədləşdirmək, Pandas ilə ilkin təhlil aparmaq, keyfiyyət problemlərini aşkarlamaq, uyğun qrafiklər və korrelyasiya heatmap-i qurmaq.

Proqram təminatı

  • Google Colab və ya Jupyter Notebook;
  • Python, Pandas, NumPy;
  • Matplotlib və Seaborn;
  • UCI Repository və ya başqa lisenziyası aydın açıq dataset.

Dataset seçimi

İlk icra üçün UCI Iris datasetindən istifadə etmək olar: UCI Iris dataset səhifəsi. Iris datasetində dörd ədədi ölçü və növ etiketi mövcuddur. Datasetin öz səhifəsindəki mənbə və lisenziya məlumatını hesabatda qeyd edin.

İcra addımları

  1. Colab-da yeni Notebook yaradın.
  2. Kitabxanaları import edin və datasetin mənbəsini qeyd edin.
  3. Datasetin ölçüsünü, sütunlarını və tiplərini yoxlayın.
  4. Missing və duplicate qeydləri araşdırın.
  5. Təsviri statistika və sinif tezliklərini hesablayın.
  6. Histogram, boxplot və scatter plot qurun.
  7. Ədədi dəyişənlər üçün Pearson korrelyasiya heatmap-i yaradın.
  8. Nəticələri, məhdudiyyətləri və istifadə olunan lisenziyanı hesabatda yazın.

Laboratoriya kodu

import pandas as pd
import numpy as np
import seaborn as sns
import matplotlib.pyplot as plt
from sklearn.datasets import load_iris

# Açıq Iris datasetini sklearn vasitəsilə yükləyirik
iris = load_iris(as_frame=True)
df = iris.frame.copy()
df["species"] = df["target"].map(
    dict(enumerate(iris.target_names))
)

# 1. Struktur
print("Ölçü:", df.shape)
print(df.head())
df.info()

# 2. Keyfiyyət yoxlaması
print("Missing:")
print(df.isna().sum())
print("Duplicate rows:", df.duplicated().sum())

# 3. Statistik təsvir
display(df.describe())

# 4. Sinif tezlikləri
print(df["species"].value_counts())

# 5. Histogramlar
df[iris.feature_names].hist(figsize=(10, 7), bins=15)
plt.tight_layout()
plt.show()

# 6. Boxplot
plt.figure(figsize=(9, 5))
sns.boxplot(data=df[iris.feature_names])
plt.xticks(rotation=25)
plt.title("Iris ölçülərinin boxplot-u")
plt.tight_layout()
plt.show()

# 7. Scatter plot
sns.scatterplot(data=df, x="sepal length (cm)",
                y="petal length (cm)", hue="species")
plt.title("Sepal length və petal length")
plt.show()

# 8. Korrelyasiya xəritəsi: yalnız ədədi feature-lər
corr = df[iris.feature_names].corr(method="pearson")
plt.figure(figsize=(8, 6))
sns.heatmap(corr, annot=True, cmap="coolwarm",
            vmin=-1, vmax=1, center=0, fmt=".2f")
plt.title("Iris: Pearson korrelyasiya matrisi")
plt.tight_layout()
plt.show()

Metodoloji izah

  • load_iris(as_frame=True) datasetin Pandas formatında əldə edilməsini asanlaşdırır.
  • target ədədi kodunu növ adları ilə ayrıca species sütununa çeviririk.
  • Korrelyasiya hesabında target kodunu daxil etmirik, çünki sinif kodlarının ədədi sırası nominal siniflər arasında məsafə mənası daşımır.
  • Histogramlar hər ədədi dəyişənin paylanmasını, scatter plot iki xüsusiyyətin birgə dəyişməsini, heatmap isə Pearson əlaqələrini göstərir.
