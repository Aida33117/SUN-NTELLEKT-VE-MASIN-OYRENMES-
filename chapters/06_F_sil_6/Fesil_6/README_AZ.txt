Mingəçevir Dövlət Universiteti — Riyaziyyat və İnformasiya Texnologiyaları fakültəsi

İSTİFADƏ
1. ZIP arxivini kompüterə çıxarın.
2. index.html faylını Chrome, Edge və ya Firefox brauzerində açın.
3. Sol menyudan bölmələrə keçin; interaktiv kalkulyator, K-Means vizual simulyasiyası,
   Q-learning mini-simulyatoru, ümumiləşdirmə qrafiki və 10 suallıq quiz brauzerdə işləyir.
4. Python kod nümunələri ayrıca Google Colab və ya Jupyter Notebook mühitində icra edilməlidir.

LABORATORİYA
Tövsiyə olunan mühit: Google Colab / Jupyter Notebook, Python 3.10+.
Kitabxanalar: numpy, pandas, matplotlib, scikit-learn.
Quraşdırma: pip install numpy pandas matplotlib scikit-learn

METODİK QEYDLƏR
- K-Means SVG nümayişi konseptual vizual simulyasiyadır; Python kodundakı sklearn KMeans
  isə faktiki alqoritm tətbiqidir.
- RL mini-simulyatoru kiçik diskret mühitdə Q-learning məntiqini nümayiş etdirir.
- Iris laboratoriyasında supervised, unsupervised və semi-supervised yanaşmalar
  eyni mənbə dataset üzərində fərqli öyrənmə siqnalları ilə tətbiq olunur.
- Reinforcement Learning statik Iris təsnifatından metodoloji baxımdan fərqli olduğu üçün
  ayrıca diskret mühitdə göstərilir.
- Dəqiq nəticələr kitabxana versiyası, təsadüfi toxum və mühitdən asılı ola bilər.
