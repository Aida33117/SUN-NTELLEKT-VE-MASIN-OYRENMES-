6.1. Maşın öyrənməsi anlayışı və əsas prinsipləri

Maşın öyrənməsi (Machine Learning, ML) kompüter sistemlərinin hər bir mümkün vəziyyət üçün qaydaların proqramçı tərəfindən ayrıca yazılmasına ehtiyac qalmadan, verilənlərdəki nümunələri öyrənərək proqnoz və ya qərar verməsini təmin edən süni intellekt istiqamətidir. Model müşahidələrdən statistik əlaqələr öyrənir; öyrəndiyi əlaqəni əvvəllər görmədiyi nümunələrə tətbiq edir.

ML-in klassik tərifində Tom Mitchell öyrənməni tapşırıq (T), təcrübə (E) və performans ölçüsü (P) ilə əlaqələndirir: kompüter proqramının T tapşırıqları üzrə P performansı E təcrübəsi ilə yaxşılaşırsa, proqram öyrənmiş hesab olunur. Məsələn, spam filtri üçün T — e-poçtları spam/spam deyil kimi təsnif etmək, E — etiketlənmiş məktublar, P — düzgün təsnifat göstəricisidir.

Model: fθ: X → Ŷ    və    θ* = arg minθ (1/n) Σ L(fθ(xᵢ), yᵢ)

Burada X giriş xüsusiyyətləri, Ŷ proqnoz, θ model parametrləri, L itki funksiyası, n müşahidələrin sayıdır. Təlimin məqsədi seçilmiş itki funksiyasını verilənlər üzərində azaltmaqdır. Lakin yalnız təlim itkisini azaltmaq kifayət deyil: əsas meyar modelin yeni verilənlərdə davranışıdır.

ML-in əsas prinsipləri

Verilənlər

Keyfiyyət, təmsilçilik, etiketlərin etibarlılığı.

Model fərziyyəsi

Alqoritmin öyrənə biləcəyi funksiyalar sinfi.

Optimallaşdırma

İtkinin minimallaşdırılması və ya mükafatın maksimallaşdırılması.

Qiymətləndirmə

Uyğun metrik və müstəqil test.

Ümumiləşdirmə

Yeni nümunələrdə sabit performans.

Etik və məsuliyyətli istifadə

Qərəz, məxfilik, izaholunma və təhlükəsizlik.

Elmi qeyd: ML “kompüterin insan kimi düşünməsi” demək deyil. Model konkret verilənlər, məqsəd funksiyası və qiymətləndirmə çərçivəsi daxilində nümunələri öyrənir. Nəticə verilənlərin paylanması dəyişdikdə zəifləyə bilər.

Sadə öyrənmə nümunəsi: xətti reqressiya

Tələbənin həftəlik çalışma saatı ilə imtahan balı arasında əlaqəni sadə model ilə təsvir edək: ŷ = w·x + b. Təlim zamanı w və b verilənlərə uyğun seçilir. Modelin proqnozu səbəb-nəticə sübutu deyil; korrelyasiya və müşahidə olunan əlaqə səbəbiyyət kimi təqdim edilməməlidir.

Proqnoz burada görünəcək.
Python — ən sadə xətti modelscikit-learn
import numpy as np
from sklearn.linear_model import LinearRegression

# X: həftəlik çalışma saatları, y: imtahan balları
X = np.array([[1], [2], [3], [4], [5], [6]])
y = np.array([42, 48, 55, 61, 67, 73])

model = LinearRegression()
model.fit(X, y)                 # parametrləri verilənlərdən öyrənir
y_pred = model.predict([[7]])   # yeni müşahidə üçün proqnoz
print("Əmsal:", model.coef_[0])
print("Sərbəst hədd:", model.intercept_)
print("7 saat üçün bal:", y_pred[0])

6.3. Maşın öyrənməsinin əsas növləri

Öyrənmə paradiqması modelin hansı siqnaldan istifadə etməsi ilə müəyyən olunur: etiket, etiketsiz müşahidələr, qismən etiket və ya mühitdən alınan mükafat. Yarı nəzarətli öyrənmə nəzarətli və nəzarətsiz üsullar arasında hibrid yanaşmadır; bəzi mənbələr əsas üç paradiqmanı (nəzarətli, nəzarətsiz, möhkəmləndirmə) vurğulayır.

Eyni real sistemdə bir neçə paradiqma birləşdirilə bilər. Məsələn, klasterləşdirmə ilə istifadəçi qrupları tapılır, sonra nəzarətli model hər qrupda davranışı proqnozlaşdırır.

6.4. Nəzarətli öyrənmə (Supervised Learning)

Nəzarətli öyrənmədə hər təlim nümunəsi giriş xüsusiyyətləri və gözlənilən cavabdan ibarətdir: D = {(xᵢ, yᵢ)}. Alqoritm X-dən y-yə uyğunlaşdırma funksiyasını öyrənir. Hədəf dəyişənin növünə görə iki əsas məsələ ayrılır.

Təsnifat (Classification)

Hədəf kateqoriyadır: spam/spam deyil, riskli/riskli deyil, bitki növü.

Metriklər: accuracy, precision, recall, F1, ROC-AUC.

Reqressiya (Regression)

Hədəf kəmiyyət qiymətidir: enerji sərfi, qiymət, temperatur, tələbə balı.

Metriklər: MAE, MSE, RMSE, R².

İnteraktiv qərar: hansı tapşırıqdır?

Tapşırıq növünü seçin.

İtki funksiyası və öyrənmə

Reqressiyada kvadratik xəta funksiyası tez-tez istifadə olunur:

MSE = (1/n) Σ (yᵢ − ŷᵢ)²

İkili təsnifatda log-loss ehtimal proqnozunun keyfiyyətini qiymətləndirir. Optimallaşdırma alqoritmi (məsələn, gradient descent) parametrləri elə yeniləyir ki, təlim itkisi azalsın.

Python — Iris verilənlərində təsnifatscikit-learn
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, classification_report

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, stratify=y, random_state=42
)
model = make_pipeline(StandardScaler(),
                      LogisticRegression(max_iter=1000))
model.fit(X_train, y_train)
pred = model.predict(X_test)
print("Accuracy:", accuracy_score(y_test, pred))
print(classification_report(y_test, pred))

İzah: stratify=y sinif nisbətlərinin bölmələrdə qorunmasına kömək edir; StandardScaler yalnız Pipeline daxilində fit edilir və test məlumatından statistik məlumat sızmasının qarşısını alır.

6.5. Nəzarətsiz öyrənmə (Unsupervised Learning)

Nəzarətsiz öyrənmədə hədəf etiket əvvəlcədən verilmir. Alqoritm müşahidələrin daxili strukturunu, oxşarlıq və fərqlərini, aşağıölçülü təsvirini və ya qeyri-adi nümunələri araşdırır. Nəticədə alınan klasterlər avtomatik olaraq “doğru siniflər” hesab edilmir; onların mənası domen biliyi ilə şərh edilməlidir.

Klasterləşdirmə: K-Means ideyası

K-Means hər müşahidəni ən yaxın mərkəzə aid edir və klasterdaxili kvadrat məsafələrin cəmini minimallaşdırmağa çalışır:

J = Σk=1K Σxᵢ∈Cₖ ||xᵢ − μₖ||²

Alqoritmin əsas addımları: K mərkəzi seçilir → nümunələr ən yaxın mərkəzə təyin edilir → mərkəzlər yenilənir → dəyişiklik dayanana qədər təkrarlanır. K əvvəlcədən seçilməlidir; miqyas fərqləri məsafə hesabına təsir etdiyindən standartlaşdırma çox vaxt vacibdir.

İnteraktiv K-Means ideya laboratoriyası

Aşağıdakı nöqtələr iki xüsusiyyətə görə klasterləşdirilmiş sintetik müşahidələrdir. K sayını dəyişin; nümayiş sadələşdirilmiş vizual simulyasiyadır, elmi nəticə kimi qəbul edilməməlidir.

2
K-Means simulyasiyasını başladın.

Nəzarətsiz öyrənmənin digər istiqamətləri: PCA ilə ölçülərin azaldılması, DBSCAN ilə sıxlıq əsaslı klasterləşdirmə, anomaliya aşkarlanması və assosiasiya qaydaları. Klaster keyfiyyəti üçün silhouette score kimi daxili metriklərdən istifadə edilə bilər, lakin heç bir daxili metrik biznes mənasını təkbaşına təsdiqləmir.

Python — K-Means klasterləşdirməscikit-learn
from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

X, _ = load_iris(return_X_y=True)  # etiketlər klasterləşdirməyə verilmir
X_scaled = StandardScaler().fit_transform(X)
km = KMeans(n_clusters=3, n_init=10, random_state=42)
clusters = km.fit_predict(X_scaled)
print("Silhouette:", silhouette_score(X_scaled, clusters))

6.6. Yarı nəzarətli öyrənmə (Semi-Supervised Learning)

Yarı nəzarətli öyrənmə az sayda etiketli, çox sayda etiketsiz nümunənin olduğu şəraitdə tətbiq edilir. Etiketləmə ekspert vaxtı və maliyyə tələb etdikdə — tibbi görüntülər, peyk təsvirləri, sənədlərin təsnifatı — bu yanaşma faydalı ola bilər.

D = DL ∪ DU,   |DL| ≪ |DU|

Əsas metodlar: self-training (modelin yüksək əminlikli proqnozlarını pseudo-label kimi istifadə etməsi), label propagation (qonşuluq qrafında etiketin yayılması), consistency regularization (müxtəlif çevrilmələrdə sabit proqnoz təşviqi). Pseudo-label səhvləri dövr ərzində güclənə bilər; etibarlılıq həddi və insan yoxlaması vacibdir.

Risk: Modelin öz səhv proqnozlarını etiket kimi qəbul etməsi “confirmation bias” yarada bilər. Pseudo-label-lər yalnız etibarlılıq həddi, balans və müstəqil qiymətləndirmə ilə tətbiq edilməlidir.
Python — Self-training nümunəsiscikit-learn
from sklearn.datasets import load_iris
from sklearn.semi_supervised import SelfTrainingClassifier
from sklearn.svm import SVC
import numpy as np

X, y = load_iris(return_X_y=True)
rng = np.random.default_rng(7)
y_partial = y.copy()
# Nümunələrin yalnız 20%-nin etiketi saxlanılır
keep = rng.choice(len(y), size=int(0.2 * len(y)), replace=False)
mask = np.ones(len(y), dtype=bool)
mask[keep] = False
y_partial[mask] = -1  # scikit-learn: -1 etiketsiz nümunə

base = SVC(probability=True, gamma="scale")
semi = SelfTrainingClassifier(base, threshold=0.80)
semi.fit(X, y_partial)
print("Etiketsiz nümunələrdən qəbul edilənlər:",
      np.sum(semi.transduction_ != -1))

6.7. Möhkəmləndirmə yolu ilə öyrənmə (Reinforcement Learning)

Möhkəmləndirmə öyrənməsində agent mühitlə ardıcıl qarşılıqlı əlaqədə olur. Agent vəziyyəti (state) müşahidə edir, hərəkət (action) seçir, mühitdən mükafat (reward) və növbəti vəziyyət alır. Məqsəd tək addımda ən böyük mükafatı deyil, uzunmüddətli yığılmış mükafatı maksimallaşdıran siyasəti (policy) tapmaqdır.

Markov qərar prosesi (MDP) adətən (S, A, P, R, γ) beşliyi ilə təsvir edilir: S — vəziyyətlər, A — hərəkətlər, P — keçid ehtimalları, R — mükafat funksiyası, γ — gələcək mükafatların diskont əmsalı.

Gₜ = Rₜ₊₁ + γRₜ₊₂ + γ²Rₜ₊₃ + …

Q-learning üçün əsas yenilənmə qaydası:

Q(s,a) ← Q(s,a) + α [r + γ maxa′ Q(s′,a′) − Q(s,a)]

α — öyrənmə sürəti, γ — diskont əmsalı. Q(s,a) vəziyyət-hərəkət cütü üçün gözlənilən gələcək faydanı qiymətləndirir. Exploration (yeni hərəkətləri yoxlama) və exploitation (indiyə qədər ən yaxşı bilinən hərəkəti seçmə) arasında tarazlıq vacibdir.

İnteraktiv Q-learning mini-simulyatoru

Sadələşdirilmiş xətti mühitdə agent başlanğıcdan hədəfə çatmağa çalışır. “Təlim et” düyməsi ε-greedy seçimlə Q-cədvəlini yeniləyir.

Agent hələ təlim keçməyib.
Python — Q-learning-in əsas yenilənməsipsevdokod / NumPy
q[state, action] += alpha * (
    reward
    + gamma * np.max(q[next_state])
    - q[state, action]
)
# epsilon-greedy:
if rng.random() < epsilon:
    action = rng.choice(actions)       # exploration
else:
    action = np.argmax(q[state])       # exploitation

RL tətbiqləri robototexnika, resurs bölgüsü, enerji idarəetməsi, oyunlar və dinamik marşrut planlaşdırılmasını əhatə edir. Təhlükəsizlik-kritik sistemlərdə simulyasiya, məhdudiyyətlər və təhlükəsiz sınaq protokolları tələb olunur.

6.9. Təlim prosesi və proqnozlaşdırma

Modelin təlimi verilənlərin təqdim edilməsi, proqnozun hesablanması, itkinin ölçülməsi və parametrlərin yenilənməsi dövrüdür. Təlim bitdikdən sonra model yeni giriş üçün proqnoz verir. Təlim və inferensiya (prediction/inference) fərqli mərhələlərdir.

Training set

Model parametrlərini öyrənmək üçün.

Validation set

Hiperparametrləri seçmək və model variantlarını müqayisə etmək üçün.

Test set

Yekun, mümkün qədər qərəzsiz performans qiymətləndirilməsi üçün.

Cross-validation

Məlumat az olduqda bir neçə bölünmə üzrə daha sabit qiymətləndirmə üçün.

Tipik bölünmə 70/15/15 və ya 80/10/10 ola bilər, lakin bu universal qanun deyil. Zaman sıralarında təsadüfi qarışdırma əvəzinə zaman ardıcıllığını qorumaq, qruplaşdırılmış məlumatlarda isə eyni subyektin nümunələrinin müxtəlif bölmələrə düşməməsi vacibdir.

Python — təlim və qiymətləndirmə axınıscikit-learn
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import roc_auc_score

X, y = load_breast_cancer(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42
)
model = RandomForestClassifier(
    n_estimators=300, max_depth=6, random_state=42
)
model.fit(X_train, y_train)
prob = model.predict_proba(X_test)[:, 1]
print("ROC-AUC:", roc_auc_score(y_test, prob))

Tibbi məlumat nümunəsi yalnız tədris üçündür; model klinik qərar üçün təsdiqlənmiş tibbi vasitə hesab edilmir.

6.10. Maşın öyrənməsi məsələlərinin təsnifatı

ML tapşırığı hədəfin növünə, verilənlərin quruluşuna və qərarın xarakterinə görə təsnif edilir. Eyni domen problemi müxtəlif formalarda qurula bilər: enerji sərfinin proqnozu reqressiya, enerji istifadəçilərinin qruplaşdırılması klasterləşdirmə, avadanlıq nasazlığının “var/yox” aşkarlanması təsnifat, enerji sisteminin dinamik idarəsi isə RL ola bilər.

Problem quruluşu metrik seçimini müəyyən edir. Siniflər balanssız olduqda accuracy yüksək görünsə də azsaylı kritik sinfi aşkarlamaya bilər. Reqressiyada RMSE böyük xətaları daha çox cəzalandırır; MAE isə orta mütləq xətanı birbaşa şərh etməyə imkan verir.

6.11. Maşın öyrənməsi layihəsinin həyat dövrü

ML layihəsi yalnız alqoritm seçməkdən ibarət deyil. Problem tərifi, verilənlərin idarə olunması, təlim, qiymətləndirmə, yerləşdirmə və monitorinq bir-biri ilə əlaqəli mərhələlərdir.

  1. Problem tərifi: istifadəçi ehtiyacı, hədəf dəyişən, məhdudiyyətlər və uğur meyarı müəyyən edilir.
  2. Verilənlərin toplanması: mənbə, hüquqi əsas, məxfilik, reprezentativlik və etiket keyfiyyəti yoxlanılır.
  3. EDA və hazırlıq: çatışmayan qiymətlər, anomaliyalar, kodlaşdırma, miqyaslama və data leakage riskləri araşdırılır.
  4. Model qurulması: sadə baseline yaradılır, bir neçə alqoritm müqayisə edilir, hiperparametrlər validasiya ilə seçilir.
  5. Yerləşdirmə: API, batch və ya edge mühitinə inteqrasiya; versiyalaşdırma və geri dönüş planı.
  6. Monitorinq: performans, data drift, concept drift, gecikmə, xərc və ədalətlilik göstəriciləri izlənilir.
Modelin laboratoriyada yüksək nəticə göstərməsi istehsalatda eyni nəticəyə zəmanət vermir. Verilənlərin paylanması, istifadəçi davranışı və proseslər zamanla dəyişə bilər; monitorinq və yenidən təlim həyat dövrünün ayrılmaz hissəsidir.

6.12. Modelin ümumiləşdirmə qabiliyyəti

Ümumiləşdirmə (generalization) modelin təlimdə iştirak etməmiş yeni müşahidələrdə düzgün işləmək qabiliyyətidir. Model yalnız təlim nümunələrini əzbərləyirsə, təlim nəticəsi yüksək olsa da real tətbiqdə zəif ola bilər.

Underfitting

Model çox sadədir; həm təlim, həm test xətası yüksəkdir.

Yaxşı uyğunlaşma

Təlim və test xətaları münasib səviyyədə, aralarındakı fərq məqbuldur.

Overfitting

Təlim xətası çox aşağı, test/validasiya xətası xeyli yüksəkdir.

İnteraktiv ümumiləşdirmə qrafiki

Model mürəkkəbliyini dəyişin. Qrafik konseptualdır: real ölçmələr deyil, bias–variance münasibətini göstərir.

5

Bias–variance tarazlığı modelin sadələşdirilməsi və ya mürəkkəbləşdirilməsi zamanı yaranan kompromisi izah edir. Yüksək bias modelin əsas əlaqəni tuta bilməməsi, yüksək variance isə verilənlərdəki təsadüfi dəyişikliklərə həddindən artıq həssaslıq deməkdir.

Ümumiləşdirməni yaxşılaşdırma üsulları

  • reprezentativ və kifayət qədər böyük verilənlər toplamaq;
  • train/validation/test bölmələrini düzgün qurmaq;
  • çarpaz validasiya və uyğun hiperparametr axtarışından istifadə etmək;
  • regularization (L1/L2), pruning, dropout və early stopping tətbiq etmək;
  • data leakage və dublikat müşahidələri aradan qaldırmaq;
  • məlumat paylanmasının zamanla dəyişməsini monitorinq etmək.
Etest ≈ Etrain + ümumiləşdirmə boşluğu

Bu ifadə konseptualdır, dəqiq universal bərabərlik deyil. Test xətası yalnız seçilmiş test nümunəsi və qiymətləndirmə proseduru çərçivəsində ümumiləşdirmə qabiliyyətinin təxmini göstəricisidir.

Addım 2. Verilənlərin yüklənməsi və bölünməsi

import numpy as np
import pandas as pd
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

iris = load_iris(as_frame=True)
X = iris.data
y = iris.target

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42, stratify=y
)
scaler = StandardScaler()
X_train_s = scaler.fit_transform(X_train)
X_test_s = scaler.transform(X_test)

print("Təlim:", X_train.shape, "Test:", X_test.shape)
print("Sinif payları:", y.value_counts(normalize=True).sort_index())

Addım 3. Nəzarətli öyrənmə — Logistic Regression

from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, f1_score, classification_report

sup = LogisticRegression(max_iter=1000, random_state=42)
sup.fit(X_train_s, y_train)
pred_sup = sup.predict(X_test_s)

print("Accuracy:", accuracy_score(y_test, pred_sup))

Addım 4. Nəzarətsiz öyrənmə — K-Means

from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, adjusted_rand_score

unsup = KMeans(n_clusters=3, n_init=20, random_state=42)
cluster_id = unsup.fit_predict(X_train_s)

print("Silhouette:", silhouette_score(X_train_s, cluster_id))

print("ARI (təhlil üçün):", adjusted_rand_score(y_train, cluster_id))

ARI hesablanarkən y_train K-Means modelinin təliminə daxil edilmir; yalnız klaster nəticələrinin sonrakı xarici müqayisəsi üçün istifadə edilir. Bu fərq nəzarətsiz öyrənmənin düzgün nümayişi baxımından vacibdir.

Addım 5. Yarı nəzarətli öyrənmə — Self-training

from sklearn.semi_supervised import SelfTrainingClassifier
from sklearn.svm import SVC
from sklearn.metrics import accuracy_score

rng = np.random.default_rng(21)
y_partial = y_train.to_numpy().copy()
labeled_idx = rng.choice(len(y_partial), size=25, replace=False)
unlabeled_mask = np.ones(len(y_partial), dtype=bool)
unlabeled_mask[labeled_idx] = False
y_partial[unlabeled_mask] = -1

base = SVC(probability=True, random_state=21)
semi = SelfTrainingClassifier(base, threshold=0.80)
semi.fit(X_train_s, y_partial)
pred_semi = semi.predict(X_test_s)
print("Self-training accuracy:", accuracy_score(y_test, pred_semi))
print("Etiketsizdən qəbul edilən pseudo-label:",
      np.sum(semi.transduction_ != -1))

Addım 6. Möhkəmləndirmə öyrənməsi — Q-learning mini-mühiti

Bu nümunədə agent 5 vəziyyətli xətti mühitdə 4-cü vəziyyətə çatmağa çalışır. Hədəfə çatmaq mükafat, digər addımlar kiçik cərimə verir.

import numpy as np

n_states, n_actions = 5, 2  # 0: sola, 1: sağa
Q = np.zeros((n_states, n_actions))
alpha, gamma, epsilon = 0.2, 0.95, 0.15
rng = np.random.default_rng(3)

def step(state, action):
    nxt = max(0, min(4, state + (1 if action == 1 else -1)))
    done = (nxt == 4)
    reward = 10 if done else -1
    return nxt, reward, done

for episode in range(500):
    state = 0
    for _ in range(20):
        action = (rng.integers(2) if rng.random() < epsilon
                  else np.argmax(Q[state]))
        nxt, reward, done = step(state, action)
        target = reward if done else reward + gamma * np.max(Q[nxt])
        Q[state, action] += alpha * (target - Q[state, action])
        state = nxt
        if done:
            break

# Öyrənilmiş siyasət
policy = np.argmax(Q, axis=1)
print("Siyasət (0=sol, 1=sağ):", policy)
print("Q cədvəli:\\n", np.round(Q, 2))
