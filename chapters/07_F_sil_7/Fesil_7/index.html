7.1. Reqressiya anlayışı və tətbiq sahələri

Reqressiya (Regression) — bir və ya bir neçə giriş xüsusiyyətindən istifadə etməklə kəmiyyət xarakterli hədəf dəyişənin şərti gözlənilən qiymətini modelləşdirən nəzarətli öyrənmə metodları ailəsidir. Məsələn, günəş panelinin gücü, elektrik enerjisi sərfi, hava temperaturu, evin qiyməti və ya tələbənin imtahan balı reqressiya hədəfi ola bilər.

Reqressiya yalnız “iki dəyişən arasında düz xətt çəkmək” deyil. O, verilənlərdəki əlaqənin formasını seçmək, parametrləri təxmin etmək, qeyri-müəyyənliyi nəzərə almaq və modelin yeni müşahidələrdə proqnoz keyfiyyətini yoxlamaq prosesidir.

Tələb, satış, qiymət və gəlir göstəricilərinin proqnozu.

7.2. Xətti reqressiyanın riyazi modeli

Xətti reqressiyada hədəf dəyişənin şərti orta qiyməti giriş xüsusiyyətlərinin xətti kombinasiyası ilə təsvir edilir. Bir xüsusiyyət üçün model:

ŷ = β₀ + β₁x

Çox xüsusiyyət üçün:

ŷ = β₀ + β₁x₁ + β₂x₂ + … + βₚxₚ

Burada ŷ proqnozlaşdırılan hədəf, β₀ sərbəst hədd (intercept), βⱼ isə j-ci xüsusiyyətin reqressiya əmsalıdır. “Xətti” sözü modelin parametrlər üzrə xətti olmasını bildirir; xüsusiyyətlər polinom, logaritm və ya qarşılıqlı təsir kimi çevrilə bilər.

Matris forması

y = Xβ + ε     ;     ŷ = Xβ̂

X — dizayn matrisi, β — parametrlər vektoru, ε — müşahidə olunmayan xəta komponentidir. Birinci sütuna 1-lər əlavə edildikdə β₀ sərbəst həddi matris yazılışına daxil edilir.

Model fərziyyələri

  • Xəttilik: hədəfin şərti orta qiyməti parametrlər üzrə xətti model ilə təsvir edilə bilir.
  • Müşahidələrin müstəqilliyi: xətalar arasında sistematik asılılıq olmamalıdır (dizayndan asılıdır).
  • Homoskedastiklik: xətaların dispersiyası proqnoz səviyyəsi boyunca təxminən sabitdir.
  • Multikollinearlığın idarəsi: xüsusiyyətlər arasında güclü xətti asılılıq əmsalların qeyri-sabitliyini artıra bilər.
  • Xətaların normallığı: əmsalların klassik inferensiyası və intervallar üçün müəyyən şəraitdə əhəmiyyətlidir; proqnoz qurmaq üçün hər zaman mütləq şərt deyil.
Xətti reqressiyanın fərziyyələri “məlumat mütləq normal paylanmalıdır” demək deyil. Klassik xətti modeldə normallıq fərziyyəsi əsasən xəta terminlərinə və inferensiyaya aiddir, bütün X dəyişənlərinə yox.

7.3. Bir dəyişənli xətti reqressiya

Bir dəyişənli (sadə) xətti reqressiyada bir giriş dəyişəni x ilə hədəf y arasındakı xətti əlaqə modelləşdirilir. Məsələn, günəş panelinə düşən şüalanma intensivliyi artdıqca çıxış gücü də arta bilər. Bu əlaqə temperatur, panelin bucağı, kölgələnmə və avadanlıq səmərəliliyi kimi digər amillərdən də asılıdır; tək dəyişənli model həmin amilləri nəzərə almır.

Əmsallar:

β̂₁ = Σ(xᵢ−x̄)(yᵢ−ȳ) / Σ(xᵢ−x̄)²    ;    β̂₀ = ȳ − β̂₁x̄

Bu nümunədə x̄=3, ȳ=64; β̂₁=7.5, β̂₀=41.5. Deməli, model ŷ=41.5+7.5x. Bu model daxilində çalışma vaxtının bir saat artması proqnoz balını orta hesabla 7.5 vahid artırır; bu, müşahidə verilənlərinin xətti assosiasiyasıdır, səbəbiyyət sübutu deyil.

İnteraktiv bir dəyişənli model

ŷ = 41.5 + 7.5×6 = 86.5
Modeli yalnız müşahidə olunan diapazondan kənara tətbiq etmək (ekstrapolyasiya) risklidir. 1–5 saat aralığında qurulmuş xətti əlaqə 20 saatda da eyni qalacaq deyə zəmanət yoxdur.

7.4. Çoxdəyişənli xətti reqressiya

Çoxdəyişənli xətti reqressiya (Multiple Linear Regression) bir neçə xüsusiyyətdən istifadə etməklə kəmiyyət hədəfi proqnozlaşdırır. Günəş panelinin gücünü şüalanma, panel temperaturu, külək sürəti və panel bucağı ilə modelləşdirmək olar:

P̂ = β₀ + β₁G + β₂T + β₃V + β₄A

Burada G — şüalanma, T — temperatur, V — külək sürəti, A — panel bucağıdır. βⱼ əmsalı digər daxil edilmiş xüsusiyyətlər sabit saxlanıldıqda xⱼ-də bir vahid dəyişməyə uyğun proqnoz fərqini ifadə edir.

Əmsalın düzgün şərhi

Çoxdəyişənli modeldə β₁-in şərhi “G ilə P arasında sadə korrelyasiya” deyil. Bu, modelə daxil edilmiş digər xüsusiyyətlər sabit olduqda G-də bir vahid artım üçün gözlənilən P dəyişməsidir. Güclü multikollinearlıq olduqda əmsalların işarəsi və böyüklüyü qeyri-sabit ola bilər.

7.5. Ən kiçik kvadratlar üsulu

Ən kiçik kvadratlar (Ordinary Least Squares, OLS) müşahidə olunan yᵢ qiymətləri ilə modelin proqnozu ŷᵢ arasındakı qalıqların kvadratları cəmini minimum edən əmsalları seçir.

SSE(β) = Σᵢ₌₁ⁿ (yᵢ − ŷᵢ)² = ||y − Xβ||²₂

Qalıq (residual) eᵢ = yᵢ − ŷᵢ-dir. Kvadratlaşdırma müsbət və mənfi xətaların bir-birini ləğv etməsinin qarşısını alır və böyük xətalara daha çox çəki verir.

Geometrik məna

Normal tənlik

Əgər XᵀX tərs çevriləndirsə, OLS həlli:

β̂ = (XᵀX)⁻¹Xᵀy

Praktik hesablamada birbaşa matris tərsini hesablamaq əvəzinə QR/SVD parçalanmaları və ya sabit ədədi alqoritmlərdən istifadə etmək daha məqsədəuyğundur. XᵀX pis şərtlənmiş olduqda ədədi qeyri-sabitlik yarana bilər.

OLS və MSE: OLS adətən kvadrat qalıqlar cəmini minimallaşdırır. MSE = SSE/n olduğundan eyni verilənlər və eyni model üçün minimizator dəyişmir; lakin optimallaşdırmada sabit əmsal və normallaşdırma konvensiyaları fərqlənə bilər.

7.6. Reqressiya əmsalları və onların hesablanması

Bir dəyişənli modeldə β̂₁ meyl əmsalı, β̂₀ isə sərbəst həddir. Orta qiymətlərdən istifadə etməklə β̂₀=ȳ−β̂₁x̄ hesablanır. Çoxdəyişənli modeldə əmsallar bütün xüsusiyyətlərin birgə təsirini nəzərə alaraq qiymətləndirilir.

Əl ilə hesablama kalkulyatoru

İstənilən üç və ya daha çox (x,y) nöqtəsini daxil edin. Kalkulyator meyl, sərbəst hədd və R²-ni sadə OLS düsturu ilə hesablayır.

β₀=41.5; β₁=7.5 nümunəsini yoxlayın.

Əmsalın ölçü vahidi xüsusiyyətin vahidindən asılıdır. Məsələn, temperatur °C əvəzinə K ilə ölçülərsə, sərbəst hədd dəyişə bilər; meylin interpretasiyası da vahid çevrilməsinə uyğun dəyişər. Standartlaşdırılmış xüsusiyyətlərdən istifadə ediləndə əmsalların ölçü miqyası dəyişir və müqayisə asanlaşa bilər, lakin standartlaşdırılmış əmsal avtomatik olaraq səbəb təsiri deyil.

Multikollinearlıq

İki və ya daha çox xüsusiyyət güclü xətti əlaqədə olduqda əmsalların dispersiyası arta, işarələri dəyişə və şərhi çətinləşə bilər. VIF, korrelyasiya matrisi, condition number və domen biliyi diaqnostikada istifadə olunur. Sadəcə yüksək korrelyasiyalı xüsusiyyəti silmək həmişə düzgün qərar deyil; proqnoz məqsədi və nəzəri məna nəzərə alınmalıdır.

7.7. Polinomial reqressiya

Əgər x ilə y arasındakı əlaqə düz xətt deyil, əyri xarakterlidirsə, polinomial xüsusiyyətlər əlavə edilə bilər:

ŷ = β₀ + β₁x + β₂x² + … + βₘxᵐ

Model x-in polinomu üzrə qeyri-xətti əyri yaratsa da, β parametrləri üzrə xətti qalır. Buna görə polinomial reqressiya xətti model ailəsinin xüsusiyyət çevrilməsi ilə genişləndirilməsidir.

Python — PolynomialFeatures + LinearRegressionscikit-learn
from sklearn.pipeline import make_pipeline

7.8. Ridge və Lasso reqressiyası

Adi OLS xüsusiyyətlər çox olduqda, xüsusiyyətlər arasında güclü asılılıq olduqda və ya model həddən artıq uyğunlaşdıqda qeyri-sabit əmsallar verə bilər. Regularizasiya əmsalların böyüklüyünə cərimə əlavə edərək modelin mürəkkəbliyini nəzarətdə saxlayır.

Ridge — L2 regularizasiya
SSE + αΣβⱼ²

Əmsalları sıfıra doğru kiçildir, lakin adətən tam sıfırlamır. Multikollinearlıq və çoxsaylı zəif xüsusiyyətlər olduqda faydalıdır.

Lasso — L1 regularizasiya
SSE + αΣ|βⱼ|

Bəzi əmsalları dəqiq sıfıra endirə bilər; xüsusiyyət seçimi effekti yaradır. Güclü korrelyasiyalı xüsusiyyətlər arasında seçim qeyri-sabit ola bilər.

α (alpha) cərimənin gücünü idarə edir: α artdıqca əmsallar daha çox sıxılır. α=0 halı uyğun normallaşdırma konvensiyasında OLS-ə yaxınlaşır. Intercept adətən cərimələnmir; tətbiq detallarını kitabxana sənədləri müəyyən edir.

Python — OLS, Ridge və Lasso müqayisəsiscikit-learn
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LinearRegression, Ridge, Lasso

models = {
    "OLS": make_pipeline(StandardScaler(), LinearRegression()),
    "Ridge": make_pipeline(StandardScaler(), Ridge(alpha=1.0)),
    "Lasso": make_pipeline(StandardScaler(), Lasso(alpha=0.05, max_iter=10000))
}
for name, model in models.items():
    model.fit(X_train, y_train)
    pred = model.predict(X_test)
    print(name, mean_absolute_error(y_test, pred))

7.9. Reqressiya modelinin Python ilə qurulması

Scikit-learn kitabxanasında LinearRegression OLS xətti reqressiyasını qurur. Əsas ardıcıllıq: verilənlərin seçilməsi → train/test bölgüsü → modelin fit edilməsi → proqnoz → metriklərin hesablanması → qalıqların təhlili.

Tam minimal nümunəPython 3 · scikit-learn
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
import numpy as np

# df: hazırlanmış DataFrame
features = ["irradiance", "panel_temp", "wind_speed"]
target = "power_kw"

X = df[features]
y = df[target]

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.20, random_state=42
)

model = LinearRegression()
model.fit(X_train, y_train)

y_pred = model.predict(X_test)

mae = mean_absolute_error(y_test, y_pred)
mse = mean_squared_error(y_test, y_pred)
rmse = np.sqrt(mse)
r2 = r2_score(y_test, y_pred)

print("Intercept:", model.intercept_)
print("Coefficients:", dict(zip(features, model.coef_)))
print(f"MAE={mae:.3f}, RMSE={rmse:.3f}, R2={r2:.3f}")

Hər sətirin metodoloji mənası

  1. features giriş dəyişənlərini, target proqnozlaşdırılacaq kəmiyyət hədəfi müəyyən edir.
  2. train_test_split test müşahidələrini modelin təlimindən kənarda saxlayır.
  3. fit() parametrləri təlim məlumatlarından qiymətləndirir.
  4. predict() modelə əvvəldən göstərilməmiş test girişləri üçün proqnoz verir.
  5. Metriklər proqnozları faktiki hədəflərlə müqayisə edir.
Əgər verilənlər zaman sırasıdırsa, təsadüfi bölünmə əvəzinə zaman ardıcıllığına əsaslanan bölünmə tətbiq edin. Eyni cihazın və ya subyektin çoxsaylı ölçmələri varsa, qrup əsaslı bölünmə də tələb oluna bilər.

R²1−SSE/SSTModelin orta proqnoz baseline-ına nisbətən uyğunluğunu ölçür.Yüksək R² avtomatik yaxşı proqnoz və ya səbəbiyyət demək deyil.
SST = Σ(yᵢ−ȳ)²    ;    SSE = Σ(yᵢ−ŷᵢ)²

R² test dəstində mənfi də ola bilər: bu, modelin həmin test nümunələrində hədəfin orta qiymətini proqnozlaşdıran baseline-dan daha zəif olduğunu göstərir. R²-ni “model bütün dəyişkənliyin bu qədər faizini səbəb olaraq izah edir” kimi şərh etmək düzgün deyil.

Addım 4. Bir dəyişənli xətti reqressiya

Əvvəlcə hədəflə korrelyasiyası daha yüksək olan xüsusiyyət seçilir. Seçim yalnız təlim məlumatı və ya əvvəlcədən müəyyən edilmiş metodoloji qayda əsasında aparılmalıdır; test nəticəsinə baxaraq xüsusiyyət seçmək olmaz.

from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

feature = "bmi"  # əvvəlcədən seçilmiş nümunə xüsusiyyət
simple = LinearRegression()
simple.fit(X_train[[feature]], y_train)
pred_simple = simple.predict(X_test[[feature]])

def regression_metrics(y_true, y_pred):
    mse = mean_squared_error(y_true, y_pred)
    return {
        "MAE": mean_absolute_error(y_true, y_pred),
        "MSE": mse,
        "RMSE": np.sqrt(mse),
        "R2": r2_score(y_true, y_pred)
    }

print("Intercept:", simple.intercept_)
print("Slope:", simple.coef_[0])
print(regression_metrics(y_test, pred_simple))

Addım 6. Ridge və Lasso müqayisəsi

from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import Ridge, Lasso

ridge = make_pipeline(StandardScaler(), Ridge(alpha=1.0))
lasso = make_pipeline(StandardScaler(), Lasso(alpha=0.05, max_iter=20000))

ridge.fit(X_train, y_train)
lasso.fit(X_train, y_train)

pred_ridge = ridge.predict(X_test)
pred_lasso = lasso.predict(X_test)

results = pd.DataFrame([
    {"Model": "Simple OLS", **regression_metrics(y_test, pred_simple)},

])
display(results.round(3))
