Fəsli tamamlayan tələbə ikili və çoxsinifli təsnifat problemini qurur; altı alqoritmi tətbiq edir; Confusion Matrix, Precision, Recall, F1 və ROC–AUC nəticələrini şərh edir; balanssızlığın təsirini qiymətləndirir.

8.1. Təsnifat məsələsinin mahiyyəti

Təsnifat giriş xüsusiyyətləri vektoru x əsasında sinif etiketini y təyin edir. Təlim datasetində müşahidələrin xüsusiyyətləri (features) və məlum etiketləri (labels) olur. Alqoritm nümunələrdən qərar qaydası və ya ehtimal modeli öyrənir, sonra yeni müşahidənin sinfini proqnozlaşdırır.

f : X → Y   ;   ŷ = f(x)

X xüsusiyyətlər fəzası, Y mümkün siniflər çoxluğu, f öyrənilmiş təsnifat funksiyasıdır. Bir çox model əvvəlcə sinif ehtimalı və ya qərar skoru hesablayır, sonra threshold və ya maksimum ehtimala əsasən etiket seçir.

Kibertəhlükəsizlik

Şəbəkə trafikinin normal və zərərli kimi təsnifatı.

Təhsil analitikası

Tələbənin risk qrupuna aid olub-olmaması.

IoT

Sensor vəziyyətinin normal, xəbərdarlıq və kritik sinifləri.

Maliyyə

Əməliyyatın şübhəli və ya normal olması.

Computer Vision

Obyektin kateqoriyasının tanınması.

Tibbi görüntü

Şəkillərin siniflərə ayrılması; klinik qərarı əvəz etmir.

Təsnifatla klasterləşdirməni qarışdırmayın: təsnifatda etiketlər təlimdə məlumdur; klasterləşdirmə adətən etiketsiz verilənlərdə qruplar axtarır.

8.2. İkili və çoxsinifli təsnifat

İkili təsnifat iki sinifdən birini seçir (spam / spam deyil). Çoxsinifli təsnifat üç və daha çox qarşılıqlı istisna edən sinifdən birini seçir (məsələn, sensor statusu: normal, xəbərdarlıq, kritik). Çoxetiketli təsnifat bir müşahidəyə eyni vaxtda bir neçə etiket verə bilər.

TipEtiket quruluşuNümunə
Binary0 və ya 1Spam / qeyri-spam
MulticlassYalnız bir neçə sinifdən biriIris: setosa, versicolor, virginica
MultilabelBirdən çox etiket mümkündürŞəkildə insan, avtomobil, yol nişanı

Çoxsinifli problemlər OvR (hər sinifə qarşı qalanları) və OvO (sinif cütləri) strategiyaları ilə ikili məsələlərə parçalana bilər. Bəzi alqoritmlər çoxsinifli təsnifatı birbaşa dəstəkləyir.

Sinifləri 0, 1, 2 kimi kodlaşdırmaq onların ədədi sırası olduğunu göstərmir. Nominal siniflərdə bu rəqəmlər sadəcə etiket kodlarıdır.

8.3. Logistic Regression

Adına baxmayaraq Logistic Regression təsnifat üçün istifadə olunan xətti qərar modelidir. Əvvəlcə z=β₀+βᵀx xətti skoru hesablanır, sonra sigmoid funksiyası onu 0–1 aralığında ehtimala çevirir.

σ(z) = 1 / (1 + e⁻ᶻ)   ;   P(y=1|x)=σ(β₀+βᵀx)

Standart qaydada ehtimal threshold=0.5-dən böyükdürsə müsbət sinif seçilir. Bu hədd universal deyil: yanlış müsbət və yanlış mənfi nəticələrin qiyməti fərqlidirsə, threshold validasiya məlumatında seçilə bilər.

Binary cross-entropy / Log-loss

L = −(1/n) Σ [yᵢ log(pᵢ) + (1−yᵢ)log(1−pᵢ)]

Model doğru sinfə yüksək ehtimal verdikdə itki kiçik, yanlış sinfə yüksək inam verdikdə böyük olur. Regularizasiya modelin əmsallarına nəzarət edir; scikit-learn-də C cərimənin tərs gücüdür: C kiçildikcə regularizasiya güclənir.

1.20.50
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

model = make_pipeline(
    StandardScaler(),
    LogisticRegression(C=1.0, max_iter=2000)
)
model.fit(X_train, y_train)
prob = model.predict_proba(X_test)[:, 1]
pred = (prob >= 0.50).astype(int)

8.4. K-Nearest Neighbors (KNN)

KNN yeni müşahidənin sinfini təlim nümunələri arasında ona ən yaxın k qonşunun etiketlərinə əsasən təyin edir. Bu, instance-based və lazy learning metodudur: nümunələr saxlanılır, proqnoz zamanı məsafələr hesablanır.

d(x,z) = √[Σⱼ (xⱼ−zⱼ)²]   (Euclidean)
3

Kiçik k səs-küyə həssas, böyük k isə qərar sərhədini həddən artıq hamar edə bilər. Məsafə kimi Euclidean, Manhattan və Minkowski istifadə oluna bilər. Xüsusiyyət miqyası məsafəyə təsir etdiyindən standartlaşdırma adətən vacibdir.

Yüksək ölçülü fəzalarda məsafələrin fərqləndiriciliyi zəifləyə bilər (curse of dimensionality). Böyük datasetlərdə proqnoz hesablama baxımından bahalı ola bilər.
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsClassifier

knn = make_pipeline(
    StandardScaler(),
    KNeighborsClassifier(n_neighbors=5, weights="distance")
)
knn.fit(X_train, y_train)

8.5. Naive Bayes alqoritmi

Naive Bayes Bayes teoreminə və xüsusiyyətlərin sinif verildikdə şərti müstəqilliyi fərziyyəsinə əsaslanır. “Naive” adı bu sadələşdirici fərziyyədən gəlir. Fərziyyə real verilənlərdə tam doğru olmasa da, metod sürətli və bəzi yüksəkölçülü məsələlərdə faydalıdır.

P(C|x) = P(x|C)P(C) / P(x)

P(C) prior, P(x|C) likelihood, P(C|x) posterior ehtimaldır. Təsnifat zamanı hər sinifin posterioru müqayisə olunur. Sadələşdirilmiş müstəqillik fərziyyəsi:

P(x|C) = Πⱼ P(xⱼ|C)
VariantFərziyyə / verilən tipiTipik tətbiq
GaussianNBDavamlı xüsusiyyətlər sinif daxilində normal paylanırSensor ölçmələri
MultinomialNBSay və tezlik xüsusiyyətləriMətn, söz tezliyi
BernoulliNBİkili xüsusiyyətlərSözün var/yox olması
CategoricalNBDiskret kateqoriyalarKateqorik atributlar

Bayes teoremi — ədədi nümunə

Hadisənin ilkin ehtimalı 10%, testin həssaslığı 90%, sağlam şəxsdə yalnış müsbət ehtimalı 5% olsun. Müsbət testdən sonra:

P(A|+) = (0.90×0.10) / [(0.90×0.10)+(0.05×0.90)] = 0.667

Posterior ehtimal 66.7%-dir. Nümunə ilkin yayılma (base rate) faktorunun vacibliyini göstərir.

from sklearn.naive_bayes import GaussianNB
nb = GaussianNB()
nb.fit(X_train, y_train)
pred = nb.predict(X_test)
probabilities = nb.predict_proba(X_test)

8.6. Decision Tree

Qərar ağacı xüsusiyyətlər üzrə ardıcıl suallar verərək verilənləri alt qruplara bölür. Daxili düyün test, budaq testin nəticəsi, yarpaq isə yekun sinif proqnozudur.

Bölünmələr Gini impurity və ya entropy kimi meyarlarla seçilir. İkili siniflər üçün:

Gini = 1 − Σₖ pₖ²   ;   H = −Σₖ pₖ log₂(pₖ)

Saf düyündə Gini=0 və entropy=0. Bölünmə uşaq düyünlərdə qarışıqlığı azaltmalıdır.

0.70

Ağacın dərinliyi və yarpaq ölçüsü məhdudlaşdırılmasa overfitting yarana bilər. max_depth, min_samples_split, min_samples_leaf və pruning mürəkkəbliyi idarə edir.

from sklearn.tree import DecisionTreeClassifier
tree = DecisionTreeClassifier(
    criterion="gini", max_depth=4,
    min_samples_leaf=5, random_state=42
)
tree.fit(X_train, y_train)

8.7. Random Forest

Random Forest çoxsaylı qərar ağaclarının ansamblıdır. Hər ağac bootstrap nümunəsi və xüsusiyyətlərin təsadüfi alt çoxluğu əsasında qurulur. Təsnifatda ağacların səsləri birləşdirilir; sinif ehtimalı ağacların ehtimallarının ortası kimi hesablana bilər.

ŷ = mode{T₁(x), T₂(x), …, Tₘ(x)}

Bagging ağacların fərqli bootstrap nümunələrində təlimini təmin edir; xüsusiyyət alt çoxluğu ağaclar arasında korrelyasiyanı azaltmağa kömək edir. Tək ağacla müqayisədə variasiya və overfitting riski azala bilər.

ParametrMənasıTəsiri
n_estimatorsAğac sayıArtması sabitliyi yaxşılaşdıra bilər, hesablama vaxtını artırır.
max_depthMaksimum dərinlikDərinlik artdıqca mürəkkəblik yüksəlir.
max_featuresBölünmədə baxılan xüsusiyyət sayıAğaclar arasında müxtəlifliyə təsir edir.
class_weightSinif çəkiləriBalanssızlıqda azlıq sinfinə diqqəti artıra bilər.
from sklearn.ensemble import RandomForestClassifier
rf = RandomForestClassifier(
    n_estimators=300, min_samples_leaf=2,
    class_weight="balanced", random_state=42, n_jobs=-1
)
rf.fit(X_train, y_train)
Feature importance modeldə xüsusiyyətin proqnoz üçün istifadəsini göstərir, səbəbiyyət sübutu deyil. Permutation importance ayrıca qiymətləndirmə dəstində faydalı ola bilər.

8.8. Support Vector Machine (SVM)

SVM sinifləri ayıran hiperplanı elə seçir ki, ən yaxın təlim nöqtələrinə qədər margin maksimum olsun. Sərhədə ən yaxın müşahidələr support vectors adlanır.

wᵀx + b = 0   ;   margin = 2 / ||w||

Soft-margin SVM bəzi nöqtələrin margin daxilində və ya yanlış tərəfdə qalmasına icazə verir. C parametri pozuntuların cəzasını idarə edir: böyük C təlim xətalarını sərt cəzalandırır, kiçik C daha geniş marginə üstünlük verir.

Kernel trick

K(x,z) = exp(−γ ||x−z||²)   (RBF kernel)

Kernel açıq şəkildə yüksək ölçülü çevirmə aparmadan həmin fəzada daxili hasil hesablamağa imkan verir. γ böyük olduqda müşahidələrin təsir sahəsi daralır və sərhəd mürəkkəbləşə bilər; γ kiçik olduqda sərhəd hamarlaşır. C və γ validasiya ilə seçilməlidir.

from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC

svm = make_pipeline(
    StandardScaler(),
    SVC(C=1.0, kernel="rbf", gamma="scale", probability=True)
)
svm.fit(X_train, y_train)

SVM xüsusiyyət miqyasına həssasdır. Kernel SVC böyük datasetlərdə baha ola bilər. Ehtimal çıxışı aktivləşdirildikdə əlavə kalibrləmə prosesi tətbiq edilir.

8.9. Təsnifat modellərinin Python ilə qurulması

Model müqayisəsində eyni dataset bölgüsü, eyni ilkin emal və eyni qiymətləndirmə protokolu istifadə edilməlidir. Nümunə Iris datasetində altı alqoritmi müqayisə edir.

import pandas as pd
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.neighbors import KNeighborsClassifier
from sklearn.naive_bayes import GaussianNB
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier
from sklearn.svm import SVC
from sklearn.metrics import accuracy_score, f1_score, classification_report

data = load_iris(as_frame=True)
X, y = data.data, data.target
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, stratify=y, random_state=42
)

models = {
 "Logistic Regression": make_pipeline(StandardScaler(), LogisticRegression(max_iter=2000)),
 "KNN": make_pipeline(StandardScaler(), KNeighborsClassifier(n_neighbors=5)),
 "GaussianNB": GaussianNB(),
 "Decision Tree": DecisionTreeClassifier(max_depth=4, random_state=42),
 "Random Forest": RandomForestClassifier(n_estimators=300, random_state=42),
 "SVM-RBF": make_pipeline(StandardScaler(), SVC(kernel="rbf", probability=True))
}
rows = []
for name, model in models.items():
    model.fit(X_train, y_train)
    pred = model.predict(X_test)
    rows.append({"Model": name,
                 "Accuracy": accuracy_score(y_test, pred),
                 "Macro-F1": f1_score(y_test, pred, average="macro")})
    print(name, classification_report(y_test, pred))
display(pd.DataFrame(rows).sort_values("Macro-F1", ascending=False))

Pipeline və data leakage

Scaler, encoder və feature selection kimi transformasiyalar test məlumatından statistik məlumat öyrənməməlidir. Pipeline transformasiyaları model təliminə bağlayır; cross-validation zamanı hər fold üçün çevrilmələr yalnız həmin fold-un train hissəsində fit edilir.

from sklearn.model_selection import StratifiedKFold, cross_validate
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scores = cross_validate(
    models["SVM-RBF"], X, y, cv=cv,
    scoring=["accuracy", "f1_macro"]
)
print(scores["test_accuracy"].mean())
print(scores["test_f1_macro"].mean())

8.10. Confusion Matrix

Confusion Matrix faktiki siniflə proqnozlaşdırılmış sinfin kəsişməsini göstərir.

Proqnoz +Proqnoz −
Faktiki +TP — doğru müsbətFN — yanlış mənfi
Faktiki −FP — yanlış müsbətTN — doğru mənfi

TP müsbət nümunənin düzgün tapılması; TN mənfi nümunənin düzgün tanınması; FP mənfi nümunənin səhvən müsbət; FN müsbət nümunənin səhvən mənfi tanınmasıdır.

İnteraktiv Confusion Matrix

Çoxsinifli halda diaqonal düzgün, diaqonaldan kənar qiymətlər qarışdırılmış sinifləri göstərir. scikit-learn-də sətirlər faktiki, sütunlar proqnozlaşdırılmış siniflərdir.

8.11. Accuracy, Precision, Recall və F1-score

Accuracy = (TP+TN)/(TP+TN+FP+FN)
Precision = TP/(TP+FP)
Recall = TP/(TP+FN)
F1 = 2 × Precision × Recall / (Precision+Recall)

Accuracy ümumi düzgün proqnoz payıdır. Precision müsbət proqnozların nə qədərinin doğru olduğunu; Recall faktiki müsbətlərin nə qədərinin tapıldığını ölçür. F1 bu iki göstəricinin harmonik ortasıdır. Yanlış mənfi nəticə bahalıdırsa Recall, yanlış müsbət yoxlama bahalıdırsa Precision daha vacib ola bilər.

Çoxsinifli təsnifatda macro average hər sinifin metrikini bərabər çəkidə ortalayır; weighted average sinif support-u ilə çəkiləndir; micro average bütün siniflər üzrə TP/FP/FN cəmlərindən hesablanır.

8.12. ROC əyrisi və AUC göstəricisi

ROC əyrisi müxtəlif qərar hədlərində True Positive Rate (TPR=Recall) və False Positive Rate (FPR) arasındakı əlaqəni göstərir.

TPR = TP/(TP+FN)   ;   FPR = FP/(FP+TN)

AUC ROC əyrisinin altındakı sahədir. İkili təsnifatda AUC təsadüfi seçilmiş müsbət nümunənin mənfi nümunədən daha yüksək skor alması ehtimalı kimi şərh oluna bilər. AUC=0.5 təsadüfi sıralamaya, 1.0 ideal sıralamaya uyğundur. AUC qərar həddini seçmir və ehtimal kalibrlənməsi demək deyil.

0.50

Balanssız datasetlərdə azlıq sinfi əsasdırsa Precision–Recall əyrisi və Average Precision da nəzərdən keçirilməlidir. Çoxsinifli ROC-AUC üçün OvR/OvO və macro/weighted average seçimi açıq göstərilməlidir.

from sklearn.metrics import roc_curve, roc_auc_score
proba = model.predict_proba(X_test)[:, 1]
fpr, tpr, thresholds = roc_curve(y_test, proba)
auc_value = roc_auc_score(y_test, proba)
plt.plot(fpr, tpr, label=f"AUC={auc_value:.3f}")
plt.plot([0, 1], [0, 1], "k--")
plt.xlabel("False Positive Rate")
plt.ylabel("True Positive Rate")
plt.legend()

8.13. Sinif balanssızlığı və onun təsiri

Sinif balanssızlığı bir sinfin müşahidələrinin digərindən xeyli çox olmasıdır. Məsələn, trafik 99% normal, 1% hücum olduqda bütün nümunələri normal deyən model 99% accuracy əldə edə bilər, amma hücumların heç birini aşkarlamaya bilər.

Balanslı

Normal 500 · Hücum 500

Balanssız

Normal 990 · Hücum 10

İdarəetmə strategiyaları

  • Stratified split: bölmələrdə sinif nisbətini qorumaq.
  • Class weights: azlıq sinfinin səhvlərinə daha böyük çəki vermək.
  • Oversampling: azlıq sinfi nümunələrini artırmaq; SMOTE yalnız train fold daxilində.
  • Undersampling: çoxluq sinfini azaltmaq; informasiya itkisi riski.
  • Threshold tuning: tətbiq xərclərinə uyğun qərar həddi seçmək.
  • Metriklər: balanced accuracy, macro-F1, Recall, Precision–Recall curve.
Resampling bütün datasetə bölünmədən əvvəl tətbiq edilərsə data leakage yarana bilər. Resampling yalnız train məlumatında və CV pipeline daxilində aparılmalıdır.

Addım 1. Dataset və ilkin təhlil

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.datasets import load_breast_cancer

data = load_breast_cancer(as_frame=True)
X, y = data.data, data.target
print("Ölçü:", X.shape)
print("Sinif payı:", y.value_counts(normalize=True))
display(X.head())
display(X.describe().T)

Addım 2. Stratified train/test bölgüsü

from sklearn.model_selection import train_test_split
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42, stratify=y
)

Addım 3. Ən azı üç model

from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.neighbors import KNeighborsClassifier
from sklearn.svm import SVC
from sklearn.ensemble import RandomForestClassifier

models = {
 "Logistic Regression": make_pipeline(StandardScaler(), LogisticRegression(max_iter=3000)),
 "KNN": make_pipeline(StandardScaler(), KNeighborsClassifier(n_neighbors=5)),
 "SVM": make_pipeline(StandardScaler(), SVC(kernel="rbf", probability=True)),
 "Random Forest": RandomForestClassifier(
     n_estimators=300, class_weight="balanced", random_state=42)
}

Addım 4. Təlim və metriklər

from sklearn.metrics import (
 accuracy_score, precision_score, recall_score,
 f1_score, confusion_matrix, classification_report, roc_auc_score
)
rows, predictions, probabilities = [], {}, {}
for name, model in models.items():
    model.fit(X_train, y_train)
    pred = model.predict(X_test)
    proba = model.predict_proba(X_test)[:, 1]
    predictions[name], probabilities[name] = pred, proba
    rows.append({
      "Model": name,
      "Accuracy": accuracy_score(y_test, pred),
      "Precision": precision_score(y_test, pred),
      "Recall": recall_score(y_test, pred),
      "F1": f1_score(y_test, pred),
      "ROC_AUC": roc_auc_score(y_test, proba)
    })
display(pd.DataFrame(rows).sort_values("F1", ascending=False).round(3))

Addım 5. Confusion Matrix və ROC

from sklearn.metrics import ConfusionMatrixDisplay, RocCurveDisplay
for name, pred in predictions.items():
    ConfusionMatrixDisplay.from_predictions(
        y_test, pred, display_labels=data.target_names,
        values_format="d"
    )
    plt.title(name); plt.show()

fig, ax = plt.subplots(figsize=(7, 6))
for name, proba in probabilities.items():
    RocCurveDisplay.from_predictions(y_test, proba, name=name, ax=ax)
ax.plot([0,1],[0,1],"k--",label="Random baseline")
ax.legend(); plt.show()
