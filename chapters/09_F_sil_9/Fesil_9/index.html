9.2. Klasterləşdirmə anlayışı

Klasterləşdirmə (Clustering) obyektləri elə qruplara ayırmaqdır ki, eyni klasterdə yerləşən obyektlər bir-birinə mümkün qədər oxşar, müxtəlif klasterlərdə yerləşən obyektlər isə nisbətən fərqli olsun.

Daxili klaster məsafəsi ↓    Klasterlərarası fərq ↑

Klasterləşdirmənin nəticəsi etiketlərin əvvəlcədən məlum olmasını tələb etmir. Klaster nömrəsi (0, 1, 2 və s.) yalnız texniki identifikatordur; “Klaster 0” avtomatik olaraq “yaxşı müştərilər” demək deyil.

İnteraktiv klaster nümunəsi

Aşağıdakı nöqtələr iki ölçülü müstəvidə verilmişdir. Klaster sayını dəyişərək qruplaşdırmanın necə dəyişdiyini müşahidə edin.

Tədris vizualizasiyasıdır: rənglər nümunə qrupları göstərir, real alqoritm nəticəsi kimi qəbul edilməməlidir.

9.4. Evklid və Manhattan məsafələri

İki nöqtə A(x₁,y₁) və B(x₂,y₂) üçün Evklid məsafəsi koordinatlar arasındakı düz xətt məsafəsidir.

dE(A,B) = √[(x₂−x₁)² + (y₂−y₁)²]

Manhattan məsafəsi koordinat fərqlərinin mütləq qiymətlərinin cəmidir.

dM(A,B) = |x₂−x₁| + |y₂−y₁|

Məsafə kalkulyatoru

Nəticə: Evklid = 5, Manhattan = 7

Hesablama nümunəsi: A(1,2), B(4,6). Evklid məsafəsi √(3²+4²)=5; Manhattan məsafəsi |3|+|4|=7.

Vacib: məsafə hesablamasından əvvəl xüsusiyyətlərin miqyasını yoxlayın. Məsələn, “gəlir” minlərlə, “yaş” onluqlarla ölçülürsə, miqyaslandırma aparılmadıqda gəlir məsafəyə həddindən artıq təsir edə bilər.

9.5. K-Means alqoritminin iş prinsipi

K-Means verilənləri əvvəlcədən seçilmiş K sayda klasterə bölən iterativ alqoritmdir. Hər klaster mərkəz (centroid) ilə təmsil olunur. Alqoritm müşahidələri ən yaxın mərkəzə təyin edir, sonra mərkəzləri yenidən hesablayır.

J = Σk=1K Σxᵢ∈Cₖ ||xᵢ − μₖ||²

Burada Cₖ — k-cı klaster, μₖ — həmin klasterin centroid-i, J isə klasterdaxili kvadrat məsafələrin cəmidir (WCSS/Inertia).

Alqoritmin mərhələləri

  1. K klaster sayını seç.
  2. İlkin centroid-ləri təyin et.
  3. Hər nöqtəni ən yaxın centroid-ə bağla.
  4. Hər klasterin orta nöqtəsini hesabla.
  5. Təyinatlar sabitləşənədək təkrarla.

Üstünlüklər və məhdudiyyətlər

  • Sürətli və sadədir.
  • Böyük verilənlərdə praktikdir.
  • K əvvəlcədən seçilməlidir.
  • Kənar qiymətlərə həssasdır.
  • Qeyri-sferik klasterlərdə zəif nəticə verə bilər.

İnteraktiv iş prinsipi

Başlanğıc: ilkin mərkəzlər

9.7. Optimal klaster sayının müəyyənləşdirilməsi

K seçimi klasterləşdirmənin əsas qərarlarından biridir. Çox kiçik K fərqli qrupları birləşdirə, çox böyük K isə təbii qrupları süni şəkildə parçalaya bilər. Universal optimal K yoxdur; nəticə verilənlərə, məqsədə və şərh edilə bilməyə əsasən qiymətləndirilməlidir.

9.8. Elbow Method

Elbow Method müxtəlif K qiymətləri üçün K-Means modelinin WCSS (inertia) göstəricisini hesablayır. K artdıqca WCSS azalır. “Dirsək” nöqtəsindən sonra əlavə klasterlərin faydası nisbətən azalır.

WCSS = Σk Σx∈Cₖ ||x − μₖ||²

Elbow qrafiki simulyatoru

Təxmini seçim: K=3

Məhdudiyyət: qrafikdə dirsək həmişə aydın görünmür. Buna görə Silhouette Score, klasterlərin interpretasiyası və domen biliyi ilə birlikdə istifadə edilməlidir.

9.9. Silhouette Score

Silhouette əmsalı hər obyekt üçün öz klasterinə yaxınlığı və ən yaxın qonşu klasterdən uzaqlığı müqayisə edir.

s(i) = (b(i) − a(i)) / max(a(i), b(i))
  • a(i): obyektin öz klasterindəki digər obyektlərə orta məsafəsi.
  • b(i): obyekt üçün ən yaxın alternativ klasterə orta məsafə.
  • s(i) 1-ə yaxın olduqda obyekt yaxşı yerləşib; 0 ətrafında olduqda sərhəddədir; mənfi olduqda yanlış klasterə düşmüş ola bilər.

Silhouette əmsalı kalkulyatoru

s = 0.60

5. Python kodu

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

from sklearn.datasets import make_blobs
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans, AgglomerativeClustering, DBSCAN
from sklearn.metrics import silhouette_score

# 1. Nümunə verilənlər
X, y_true = make_blobs(
    n_samples=450,
    centers=4,
    cluster_std=0.75,
    random_state=42
)

# 2. Miqyaslandırma
X_scaled = StandardScaler().fit_transform(X)

# 3. K-Means
kmeans = KMeans(n_clusters=4, n_init=10, random_state=42)
labels_km = kmeans.fit_predict(X_scaled)

# 4. Hierarchical Clustering
hier = AgglomerativeClustering(n_clusters=4, linkage="ward")
labels_h = hier.fit_predict(X_scaled)

# 5. DBSCAN
dbscan = DBSCAN(eps=0.25, min_samples=5)
labels_db = dbscan.fit_predict(X_scaled)

# 6. Silhouette: ən azı 2 klaster və səs-küy xaric
def safe_silhouette(X, labels):
    mask = labels != -1
    valid = labels[mask]
    if len(set(valid)) < 2 or len(set(valid)) >= len(valid):
        return None
    return silhouette_score(X[mask], valid)

print("K-Means:", safe_silhouette(X_scaled, labels_km))
print("Hierarchical:", safe_silhouette(X_scaled, labels_h))
print("DBSCAN:", safe_silhouette(X_scaled, labels_db))

# 7. Nəticələrin vizuallaşdırılması
fig, axes = plt.subplots(1, 3, figsize=(15, 4))
for ax, labels, title in zip(
    axes,
    [labels_km, labels_h, labels_db],
    ["K-Means", "Hierarchical", "DBSCAN"]
):
    ax.scatter(X_scaled[:, 0], X_scaled[:, 1],
               c=labels, cmap="tab10", s=18)
    ax.set_title(title)
    ax.set_xlabel("X1")
    ax.set_ylabel("X2")
plt.tight_layout()
plt.show()

DBSCAN yalnız bir klaster və ya hər nöqtəyə ayrıca etiket verərsə, Silhouette Score hesablamaq mümkün deyil.
