10.1. Maşın öyrənməsi modelinin keyfiyyəti

Modelin keyfiyyəti onun konkret tapşırıq üçün nə dərəcədə düzgün, sabit və yeni verilənlərə tətbiq edilə bilən nəticə verməsi ilə müəyyən olunur. Qiymətləndirmə metrikləri problemin növünə uyğun seçilməlidir.

ReqressiyaMAE, MSE, RMSE, R²Proqnoz xətası və izah olunan variasiya

İnteraktiv metrik hesablayıcısı

Qarışıqlıq matrisinin dəyərlərini daxil edin. Hesablayıcı Accuracy, Precision, Recall və F1 göstəricilərini çıxaracaq.

Accuracy=0.90 · Precision=0.875 · Recall=0.913 · F1=0.894
Accuracy = (TP + TN) / (TP + TN + FP + FN)
Precision = TP / (TP + FP)    Recall = TP / (TP + FN)
F1 = 2 × (Precision × Recall) / (Precision + Recall)
Siniflər balanssız olduqda Accuracy aldadıcı ola bilər. Məsələn, nümunələrin 99%-i “sağlam” sinfidirsə, bütün nümunələri sağlam proqnozlaşdıran model 99% Accuracy əldə edə bilər, lakin xəstə sinfini heç aşkarlamaya bilər.

10.3. Overfitting və Underfitting

Overfitting modelin təlim verilənlərini, o cümlədən təsadüfi səs-küyü həddindən artıq öyrənməsi nəticəsində yeni verilənlərdə zəif işləməsidir. Underfitting isə modelin verilənlərdəki əsas qanunauyğunluğu belə öyrənə bilməməsidir.

Underfitting

  • Model çox sadədir.
  • Təlim xətası yüksəkdir.
  • Test xətası da yüksəkdir.
  • Həll: modelin mürəkkəbliyini artırmaq, xüsusiyyətləri yaxşılaşdırmaq.

Overfitting

  • Model həddindən artıq mürəkkəbdir.
  • Təlim xətası çox aşağıdır.
  • Test xətası nəzərəçarpacaq dərəcədə yüksəkdir.
  • Həll: regularization, sadələşdirmə, daha çox məlumat, cross-validation.

Model mürəkkəbliyi və xəta diaqramı

Sxematik diaqram: model mürəkkəbliyi artdıqca təlim xətası azalır, test xətası isə müəyyən nöqtədən sonra arta bilər.

10.4. Bias–Variance Trade-off

Bias–Variance Trade-off modelin sadələşdirilməsi ilə verilənlərə həddindən artıq uyğunlaşma arasında tarazlığı ifadə edir. Yüksək bias modelin əsas əlaqəni tuta bilməməsi, yüksək variance isə təlim verilənlərindəki kiçik dəyişikliklərə həddindən artıq həssas olmasıdır.

E[(y − ŷ)²] = Bias(ŷ)² + Variance(ŷ) + Irreducible Noise

Həddindən artıq sadəYüksəkAşağıUnderfitting
Həddindən artıq mürəkkəbAşağıYüksəkOverfitting
TarazlaşdırılmışMünasibMünasibYaxşı ümumiləşdirmə

10.5. Cross-Validation

Cross-Validation (çarpaz yoxlama) verilənlər çoxluğunu bir neçə hissəyə ayıraraq modelin müxtəlif təlim və yoxlama bölmələrində performansını qiymətləndirmə üsuludur. Bu yanaşma nəticənin yalnız bir təsadüfi train/test bölünməsindən asılılığını azaltmağa kömək edir.

Əsas addımlar

  1. Verilənlər bir neçə hissəyə bölünür.
  2. Hər iterasiyada bir hissə yoxlama üçün saxlanılır.
  3. Qalan hissələrdə model öyrədilir.
  4. Hər iterasiyanın metrikası hesablanır.
  5. Nəticələr orta qiymət və yayılma ilə ümumiləşdirilir.
Vacib: preprocessing addımları (məsələn, StandardScaler və feature selection) cross-validation daxilində Pipeline vasitəsilə öyrədilməlidir. Bütün dataset üzərində əvvəlcədən miqyaslandırma məlumat sızmasına (data leakage) səbəb ola bilər.

10.6. K-Fold Cross-Validation

K-Fold metodunda verilənlər K bərabər (və ya mümkün qədər yaxın ölçülü) hissəyə bölünür. Hər iterasiyada bir fold validation, qalan K−1 fold isə training üçün istifadə edilir.

CV orta nəticəsi = (1/K) × Σ scoreₖ

İnteraktiv K-Fold sxemi

Stratified K-Fold təsnifat məsələlərində hər fold-da sinif nisbətlərini qorumağa çalışır. Zaman sıralarında isə gələcək müşahidələrin keçmişdən əvvəl təlimə düşməməsi üçün TimeSeriesSplit kimi zaman ardıcıllığını qoruyan üsullar seçilməlidir.

10.7. Parametr və hiperparametr anlayışları

Parametr modelin təlim zamanı verilənlərdən öyrəndiyi daxili qiymətdir. Hiperparametr isə təlimdən əvvəl istifadəçi tərəfindən təyin edilən və modelin öyrənmə prosesini və ya mürəkkəbliyini idarə edən parametrdir.

ModelParametr nümunəsiHiperparametr nümunəsi
Linear RegressionƏmsallar (w), sərbəst hədd (b)Fit zamanı seçilən model spesifikasiyası
Decision TreeDüyünlərdə öyrənilən bölünmə qaydalarımax_depth, min_samples_split
KNNKlassik mənada öyrənilən çəki parametri yoxdurn_neighbors, metric, weights
Neural NetworkÇəkilər və bias-larLearning rate, batch size, layer sayı
Hiperparametr optimallaşdırılmasının məqsədi validation və ya cross-validation nəticəsinə əsasən uyğun konfiqurasiyanı tapmaqdır. Test dəsti son, qərəzsiz qiymətləndirmə üçün saxlanmalıdır.

10.8. Grid Search

Grid Search əvvəlcədən verilmiş hiperparametr qiymətlərinin bütün mümkün kombinasiyalarını sistematik yoxlayır. Axtarış sahəsi kiçik olduqda şəffaf və təkrarlana bilən yanaşmadır, lakin kombinasiya sayı artdıqca hesablama xərci sürətlə böyüyür.

Nkombinasiya = n₁ × n₂ × ... × nₚ

Grid Search kombinasiya kalkulyatoru

3 × 4 × 2 = 24 konfiqurasiya

Python nümunəsi

from sklearn.model_selection import GridSearchCV
from sklearn.ensemble import RandomForestClassifier

model = RandomForestClassifier(random_state=42)
param_grid = {
    "n_estimators": [100, 200, 300],
    "max_depth": [None, 5, 10],
    "min_samples_split": [2, 5]
}

search = GridSearchCV(
    estimator=model,
    param_grid=param_grid,
    cv=5,
    scoring="f1",
    n_jobs=-1
)
search.fit(X_train, y_train)
print(search.best_params_)
print(search.best_score_)

10.10. Regularization metodları

Regularization modelin həddindən artıq mürəkkəbləşməsini məhdudlaşdırmaq üçün itki funksiyasına cərimə termini əlavə edir. Bu, xüsusilə çoxsaylı xüsusiyyətlər olduqda overfitting riskini azaltmağa kömək edə bilər.

L1: Loss + λ Σ |wᵢ|
L2: Loss + λ Σ wᵢ²
MetodCəriməTipik təsir
L1 / LassoƏmsalların mütləq qiymətləri cəmiBəzi əmsalları sıfıra endirə, seyrək model yarada bilər
L2 / RidgeƏmsalların kvadratları cəmiƏmsalları kiçildir, adətən sıfıra tam endirmir
Elastic NetL1 və L2 kombinasiyasıHər iki yanaşmanın xüsusiyyətlərini birləşdirir

Regularization gücünün interaktiv nümayişi

λ çox kiçik olduqda mürəkkəb modelin cəriməsi zəif, həddindən artıq böyük olduqda isə modelin öyrənməsi məhdud ola bilər. λ uyğunluğu validation/CV ilə seçilməlidir. Xüsusiyyətlər adətən regularization-dan əvvəl miqyaslandırılır.

5. Python kodu

import numpy as np
import pandas as pd

from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import (
    train_test_split, StratifiedKFold,
    cross_validate, GridSearchCV, RandomizedSearchCV
)
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score
from scipy.stats import randint

# 1. Dataset
data = load_breast_cancer()
X, y = data.data, data.target

# 2. Test dəstini əvvəlcədən ayırırıq
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.20, stratify=y, random_state=42
)

cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)

# 3. Logistic Regression: scaling Pipeline daxilindədir
log_pipe = Pipeline([
    ("scaler", StandardScaler()),
    ("model", LogisticRegression(max_iter=5000))
])

log_grid = {
    "model__C": [0.01, 0.1, 1, 10, 100],
    "model__solver": ["liblinear", "lbfgs"]
}
grid = GridSearchCV(
    log_pipe, log_grid, cv=cv, scoring="f1",
    n_jobs=-1, return_train_score=True
)
grid.fit(X_train, y_train)

# 4. Random Forest üçün Random Search
rf = RandomForestClassifier(random_state=42)
rf_dist = {
    "n_estimators": randint(100, 401),
    "max_depth": [None, 4, 6, 8, 12],
    "min_samples_split": randint(2, 12),
    "min_samples_leaf": randint(1, 6)
}
random_search = RandomizedSearchCV(
    rf, rf_dist, n_iter=30, cv=cv, scoring="f1",
    random_state=42, n_jobs=-1, return_train_score=True
)
random_search.fit(X_train, y_train)

# 5. Yalnız indi toxunulmamış test dəstini qiymətləndiririk
best_models = {
    "Logistic Regression": grid.best_estimator_,
    "Random Forest": random_search.best_estimator_
}
for name, model in best_models.items():
    pred = model.predict(X_test)
    print("\\n", name)
    print("Accuracy:", accuracy_score(y_test, pred))
    print("Precision:", precision_score(y_test, pred))
    print("Recall:", recall_score(y_test, pred))
    print("F1:", f1_score(y_test, pred))

print("Grid best params:", grid.best_params_)
print("Grid best CV F1:", grid.best_score_)
print("Random best params:", random_search.best_params_)
print("Random best CV F1:", random_search.best_score_)
