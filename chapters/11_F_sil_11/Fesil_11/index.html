11.1. Bioloji neyronun quruluşu

Bioloji neyron sinir sisteminin siqnalları qəbul edən, emal edən və digər hüceyrələrə ötürən əsas hüceyrələrindən biridir. Neyronların quruluşu və əlaqələri mürəkkəb sinir şəbəkələrinin fəaliyyətini təmin edir.

Bioloji neyronun əsas hissələri

  • Dendritlər: digər neyronlardan siqnalları qəbul edir.
  • Soma (hüceyrə cismi): daxil olan siqnalları inteqrasiya edir.
  • Akson: elektrik impulsunu hüceyrədən uzağa ötürür.
  • Sinaps: neyronlar arasında əlaqə nöqtəsidir.
  • Mielin qişası: bəzi aksonlarda siqnal ötürülməsini sürətləndirir.

11.6. Sürüşmə əmsalı (Bias)

Bias neyronun aktivləşmə həddini sürüşdürməyə imkan verən öyrənilən sabit termindir. Bias olmasa, qərar sərhədi bir çox sadə modellərdə koordinat başlanğıcından keçməyə məcbur olar. Bias modelə daha çevik qərar sərhədi yaratmağa kömək edir.

z = w₁x₁ + w₂x₂ + b

11.7. Çəkili cəmin hesablanması

Çəkili cəm hər girişin uyğun çəki ilə hasilinin toplanması və bias-ın əlavə edilməsi ilə hesablanır.

z = w₁x₁ + w₂x₂ + … + wₙxₙ + b

Hesablanmış nümunə: x₁=0.9, x₂=0.8, x₃=0.7; w₁=0.5, w₂=0.3, w₃=0.2; b=-0.4.

z = (0.5×0.9) + (0.3×0.8) + (0.2×0.7) − 0.4 = 0.25

İnteraktiv neyron kalkulyatoru

z=0.25; sigmoid(z)≈0.562

Canlı neyron şəbəkə sxemi — hesablanmış nəticəyə uyğun

Girişləri, çəkiləri, bias və aktivləşmə funksiyasını dəyişdikdə sxem avtomatik yenilənir.

Girişlər çəkilərlə vurulur, bias əlavə edilir və aktivləşmə funksiyasından keçirilərək çıxış alınır.

11.8. Aktivləşmə funksiyasının rolu

Aktivləşmə funksiyası neyronun xalis girişini çıxışa çevirir. Qeyri-xətti aktivləşmə funksiyaları çoxqatlı neyron şəbəkələrinə mürəkkəb qeyri-xətti əlaqələri öyrənmək imkanı verir. Əgər bütün qatlarda yalnız xətti çevirmələr tətbiq edilsə, onların ardıcıl kompozisiyası yenə xətti çevirmə olar.

Aktivləşmə funksiyası nə edir?

  • Çıxışın diapazonunu müəyyən edir.
  • Qeyri-xəttilik yarada bilər.
  • Gradientin davranışına təsir edir.
  • Şəbəkənin öyrənmə dinamikasını dəyişir.

Seçim nümunələri

  • Step — klassik perseptron qərarı.
  • Sigmoid — 0 və 1 arasında çıxış.
  • Tanh — −1 və 1 arasında çıxış.
  • ReLU — müsbət hissəni saxlayır, mənfi hissəni sıfırlayır.

11.9. Step, Sigmoid, Tanh və ReLU funksiyaları

Aktivləşmə funksiyaları eyni xalis giriş üçün fərqli çıxışlar yaradır. Aşağıdakı qrafiklər funksiyaların formasını və diapazonunu müqayisə edir.

Step(z) = 1, z ≥ 0; əks halda 0
Sigmoid(z) = 1 / (1 + e−z)
Tanh(z) = (ez − e−z) / (ez + e−z)
ReLU(z) = max(0, z)

11.11. Perceptronun öyrənmə qaydası

Perseptron öyrənərkən proqnoz ilə hədəf arasındakı fərqdən istifadə edərək çəkilərini yeniləyir. Sadə ikili perseptron üçün yenilənmə qaydası belə yazıla bilər:

wᵢ(new) = wᵢ(old) + η (y − ŷ) xᵢ
b(new) = b(old) + η (y − ŷ)

Burada η öyrənmə sürəti, y düzgün etiket, ŷ modelin proqnozudur. Əgər proqnoz düzgün olarsa, xəta sıfır olur və bu nümunə üzrə çəki dəyişmir.

Bir addımlıq çəki yenilənməsi kalkulyatoru

Öyrənmə prosesi

  1. Başlanğıc çəkiləri və bias təyin edilir.
  2. Təlim nümunəsi modelə verilir.
  3. Çəkili cəm və proqnoz hesablanır.
  4. Hədəf ilə proqnoz fərqi tapılır.
  5. Çəki və bias yenilənir.
  6. Nümunələr üzrə təkrar edilir.
Klassik perceptron öyrənmə qaydası xətti ayrılan verilənlərdə sonlu addımlardan sonra həllə yaxınlaşma zəmanətinə malikdir. Xətti ayrılmayan verilənlərdə, məsələn XOR-da, bu zəmanət yoxdur.

Məntiqi qapılar perseptronun imkanlarını anlamaq üçün klassik nümunələrdir. AND və OR xətti ayrıla bilir; XOR isə bir düz xəttlə ayrıla bilməyən nümunədir.

İnteraktiv məntiqi qapı sınağı

XOR niyə çətindir? XOR-da (0,0) və (1,1) bir sinfə, (0,1) və (1,0) digər sinfə aiddir. Bu nöqtələri bir düz xəttlə iki sinfə ayırmaq mümkün deyil. Çoxqatlı şəbəkə və qeyri-xətti ara qatlar XOR-u öyrənə bilər.

3. Tapşırıq A — neyronun sıfırdan qurulması

import numpy as np

def step(z):
    return 1 if z >= 0 else 0

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def tanh(z):
    return np.tanh(z)

def relu(z):
    return max(0, z)

def neuron(x, w, b, activation="sigmoid"):
    # Girişlərin çəkilərlə skalyar hasilini hesabla
    z = np.dot(x, w) + b

    # Aktivləşmə funksiyasını seç
    functions = {
        "step": step,
        "sigmoid": sigmoid,
        "tanh": tanh,
        "relu": relu
    }
    y = functions[activation](z)
    return z, y

# Nümunə girişlər, çəkilər və bias
x = np.array([0.9, 0.8, 0.7])
w = np.array([0.5, 0.3, 0.2])
b = -0.4

for name in ["step", "sigmoid", "tanh", "relu"]:
    z, output = neuron(x, w, b, name)
    print(name, "z =", round(float(z), 4),
          "çıxış =", round(float(output), 4))

5. Tapşırıq C — AND qapısı üçün perseptron

import numpy as np

X = np.array([
    [0, 0],
    [0, 1],
    [1, 0],
    [1, 1]
])
y = np.array([0, 0, 0, 1])

w = np.zeros(2)
b = 0.0
learning_rate = 0.1

def predict(x, w, b):
    return 1 if np.dot(x, w) + b >= 0 else 0

# Perceptron learning rule
for epoch in range(20):
    errors = 0
    for xi, target in zip(X, y):
        y_hat = predict(xi, w, b)
        error = target - y_hat
        w = w + learning_rate * error * xi
        b = b + learning_rate * error
        errors += int(error != 0)
    if errors == 0:
        print("Konvergensiya:", epoch + 1)
        break

print("Çəkilər:", w, "Bias:", b)
for xi in X:
    print(xi, "->", predict(xi, w, b))
