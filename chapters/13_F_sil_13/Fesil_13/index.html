13.1. Neyron şəbəkəsinin öyrədilməsi anlayışı

Neyron şəbəkəsinin öyrədilməsi — modelin çəkilərini (weights) və sürüşmə əmsallarını (bias) verilənlər əsasında elə tənzimləmək prosesidir ki, modelin proqnozları həqiqi hədəf qiymətlərə mümkün qədər yaxın olsun. Şəbəkə əvvəlcə ilkin parametrlərlə proqnoz yaradır, sonra proqnoz ilə düzgün cavab arasındakı fərq itki funksiyası ilə ölçülür. Bu itkinin parametrlərə görə dəyişmə istiqaməti hesablanır və parametrlər yenilənir.

Öyrənmə prosesi adətən təkrarlanan dövr kimi təsvir olunur: irəli yayılma → itkinin hesablanması → geriyə yayılma → parametr yenilənməsi. Bu dövr çoxlu mini-batch-lər və epoch-lar boyunca təkrarlanır.

Giriş qatı — x

Hər giriş neyronu bir xüsusiyyəti qəbul edir. Məsələn, tələbənin davamiyyət faizi, tapşırıq balı və aralıq imtahan balı.

Gizli qat — h

Girişlər çəkilərlə vurulur, bias əlavə edilir və aktivləşmə funksiyasından keçirilir. Şəbəkə burada mürəkkəb əlaqələri öyrənir.

Çıxış qatı — ŷ

Tapşırığın növünə görə bir ədəd proqnoz, sinif ehtimalı və ya bir neçə sinif üçün ehtimallar yarada bilər.

Bu diaqramın riyazi yazılışı:
z⁽¹⁾ = xW⁽¹⁾ + b⁽¹⁾;   a⁽¹⁾ = φ(z⁽¹⁾)
z⁽²⁾ = a⁽¹⁾W⁽²⁾ + b⁽²⁾;   ŷ = ψ(z⁽²⁾)
Burada W — çəkilər matrisi, b — bias vektoru, φ və ψ — aktivləşmə funksiyalarıdır.

Sadə nümunə: modelin səhvi

Tələbənin yekun balını proqnozlaşdıran model 74 bal proqnozlaşdırıb, real nəticə 80 baldır. Səhv (proqnoz − həqiqət) = 74−80 = −6 baldır. Bu fərq modelin parametrlərini hansı istiqamətdə dəyişməyin lazım olduğunu təkbaşına demir; bunun üçün itki funksiyasının parametrə görə törəməsi — gradient hesablanmalıdır.

y = 80,   ŷ = 74   ⇒   e = ŷ − y = −6
Əsas fikir: Öyrənmə zamanı model sadəcə cavabı yadda saxlamır; parametrləri dəyişərək verilənlərdəki ümumi əlaqəni öyrənməyə çalışır. Buna görə təlim, validation və test dəstləri ayrı saxlanılır.

13.2. İtki funksiyası (Loss Function)

İtki funksiyası modelin proqnozunun hədəfdən nə qədər uzaq olduğunu ədədi qiymətlə ifadə edir. Təlim alqoritmi bu qiyməti azaltmağa çalışır. Seçilən loss funksiyası məsələnin növünə uyğun olmalıdır: reqressiyada davamlı qiymətlər üçün MSE və ya MAE, təsnifatda isə Cross-Entropy geniş istifadə edilir.

Bir müşahidə üçün itki L(y, ŷ) kimi yazılır. Bir batch üçün itki adətən batch müşahidələrinin itkilərinin orta qiymətidir:

L_batch = (1/m) Σᵢ₌₁ᵐ L(yᵢ, ŷᵢ)

Burada m batch-dəki müşahidələrin sayıdır. Orta qiymət batch ölçüsündən asılı olaraq loss miqyasının müqayisəsini asanlaşdırır. Bəzi funksiyalarda əlavə regularization termini də loss-a daxil edilir.

İnteraktiv itki kalkulyatoru

Hədəf və proqnoz qiymətlərini daxil edin. Kalkulyator bir müşahidə üçün kvadratik xətanı göstərir.

MSE = 36

Bir nümunə üçün MSE = (y−ŷ)². Bu nümunədə (80−74)²=36. Bir neçə nümunədə bu qiymətlərin ortası hesablanır.

13.3. Mean Squared Error və Cross-Entropy

Mean Squared Error (MSE)

MSE reqressiya məsələlərində tez-tez istifadə olunur. Hər proqnoz xətası kvadrata yüksəldilir və müşahidələr üzrə orta qiymət hesablanır. Kvadratlaşdırma böyük xətaları daha çox cəzalandırır və törəməsi rahat hesablanır.

MSE = (1/n) Σᵢ₌₁ⁿ (yᵢ − ŷᵢ)²

Məsələn, həqiqi qiymətlər [3, 5, 2], proqnozlar [2, 5, 4] olsun. Xətalar [1, 0, −2], kvadratlar [1, 0, 4], MSE=(1+0+4)/3=1.667.

Binary Cross-Entropy

İkili təsnifatda model müsbət sinfə aid olma ehtimalı p proqnozlaşdırır. Hədəf y yalnız 0 və ya 1 olur. Binary Cross-Entropy düzgün sinif üçün yüksək ehtimal verildikdə kiçik, səhv sinifə yüksək əminlik göstərildikdə isə böyük itki yaradır.

BCE = −[y ln(p) + (1−y) ln(1−p)]

Əgər y=1 və p=0.8 olarsa BCE=−ln(0.8)≈0.223. Əgər y=1 və p=0.2 olarsa BCE=−ln(0.2)≈1.609. Deməli, həqiqi sinif 1 olduğu halda 0.2 ehtimalı vermək daha böyük cəza alır.

13.4. Gradient anlayışı

Törəmə bir dəyişənli funksiyanın girişindəki kiçik dəyişmənin çıxışa necə təsir etdiyini göstərir. Gradient çox dəyişənli funksiyada bütün parametrlərə görə qismən törəmələri bir vektorda birləşdirir. Neyron şəbəkəsində loss çəkilərdən və bias-lardan asılı olduğuna görə gradient parametrləri hansı istiqamətdə dəyişdirməyin itkini artıracağını göstərir.

∇θ L = [∂L/∂θ₁, ∂L/∂θ₂, …, ∂L/∂θₚ]ᵀ

Gradientin əks istiqaməti lokal olaraq loss-u azaltmağa yönəlir. Əgər ∂L/∂w müsbətdirsə, w-ni bir qədər azaltmaq loss-u azalda bilər. Əgər törəmə mənfidirsə, w-ni artırmaq istiqaməti loss-u azalda bilər. Dəyişmənin miqdarı learning rate ilə müəyyən edilir.

Sadə törəmə nümunəsi

L(w)=(w−3)² olsun. Törəmə L'(w)=2(w−3). w=5 nöqtəsində gradient 4-dür. Gradientin əks istiqamətində kiçik addım atmaq w-ni 3-ə yaxınlaşdırır.

L(w)=(w−3)²   ⇒   dL/dw=2(w−3)
w=5   ⇒   gradient=4

İnteraktiv gradient hesablayıcısı

L=4, gradient=4

13.5. Gradient Descent alqoritmi

Gradient Descent (qradiyent enişi) itki funksiyasını azaltmaq üçün parametrləri gradientin əks istiqamətində yeniləyən optimallaşdırma alqoritmidir. Hər addımda cari parametr qiymətində gradient hesablanır və parametr yeni qiymətə keçirilir.

θₜ₊₁ = θₜ − η ∇θ L(θₜ)

Burada θ parametr vektoru, η learning rate, ∇θL gradient, t isə iterasiya indeksidir. Sadə bir parametr üçün:

wₜ₊₁ = wₜ − η · dL/dw

Əl ilə hesablanan nümunə

L(w)=(w−3)², başlanğıc w₀=5, learning rate η=0.1 olsun. Gradient 2(w−3) olduğuna görə g₀=4. Yeni parametr w₁=5−0.1×4=4.6. Növbəti addımda gradient 2(4.6−3)=3.2, w₂=4.6−0.1×3.2=4.28. Parametr minimum nöqtəsi 3-ə yaxınlaşır.

13.6. Learning Rate və onun təsiri

Learning rate (öyrənmə sürəti) hər parametr yenilənməsində gradient istiqamətində atılan addımın ölçüsünü müəyyən edir. Kiçik learning rate daha ehtiyatlı addımlar yaradır, lakin təlimi ləngidə bilər. Böyük learning rate minimumun ətrafında sıçrayışa, loss-un artmasına və ya divergensiyaya səbəb ola bilər.

Çox kiçik η

Stabil, lakin yavaş yaxınlaşma. Təlim üçün çoxlu iterasiya tələb oluna bilər.

Uyğun η

Loss adətən daha sürətli və idarə olunan şəkildə azalır.

Çox böyük η

Minimumun üzərindən keçmə, dalğalanma və qeyri-sabitlik yarana bilər.

wₜ₊₁ = wₜ − ηgₜ

Learning rate bütün parametrlər üçün eyni addım miqyasını təyin edən sadə optimizatorda istifadə olunur. Adam kimi adaptiv optimizatorlar isə parametr üzrə addım miqyasını gradientlərin tarixi statistikalarına əsasən dəyişdirir.

İnteraktiv addım kalkulyatoru

w yeni = 4.6

13.7. Backpropagation alqoritmi

Backpropagation (geriyə yayılma) şəbəkənin çıxışındakı itkinin hər bir çəki və bias parametrinə görə törəməsini zəncir qaydası ilə hesablayan alqoritmdir. O, özü ayrıca parametr yeniləmə qaydası deyil: gradientləri hesablayır. Gradient Descent, Adam və digər optimizatorlar həmin gradientlərdən istifadə edərək parametrləri yeniləyir.

Sadə ikiqatlı şəbəkədə əvvəlcə gizli qatın aktivləşməsi, sonra çıxış hesablanır. Loss tapıldıqdan sonra çıxış qatından başlanaraq törəmələr əvvəlki qatlara ötürülür. Beləliklə, hər parametrin loss-a təsiri hesablanır.

Oxların mənası: Mavi oxlar verilənlərin şəbəkə boyunca irəli hərəkətini göstərir. Qırmızı oxlar loss-un törəmələrinin çıxış qatından əvvəlki qatlara ötürülməsini göstərir. Backpropagation zamanı giriş verilənləri geriyə daşınmır; zəncir qaydası ilə gradientlər hesablanır.

Backpropagation addımları

  1. Forward propagation ilə ŷ hesablanır.
  2. Loss funksiyası L(y, ŷ) hesablanır.
  3. Çıxış qatında loss-un çıxışa görə törəməsi tapılır.
  4. Zəncir qaydası ilə qat-qat geriyə keçilərək çəkilərə görə gradientlər hesablanır.
  5. Optimizator gradientlərdən istifadə edərək W və b parametrlərini yeniləyir.
Fərqi yadda saxlayın: Backpropagation — gradienti hesablayır; Gradient Descent/Adam — gradientdən istifadə edərək parametrləri yeniləyir.

13.8. Zəncir qaydası (Chain Rule)

Zəncir qaydası mürəkkəb funksiyanın törəməsini onun daxili funksiyalarının törəmələri vasitəsilə hesablamağa imkan verir. Neyron şəbəkəsi qat-qat funksiyaların kompozisiyası olduğundan backpropagation-un riyazi əsası məhz bu qaydadır.

Əgər y=f(u), u=g(x) olarsa:
dy/dx = (dy/du) · (du/dx)

Sadə ədədi nümunə

y=(3x+1)² olsun. Daxili funksiya u=3x+1, xarici funksiya y=u²-dir. dy/du=2u, du/dx=3. Buna görə dy/dx=2(3x+1)×3=6(3x+1). x=2 üçün törəmə 6×7=42-dir.

u=3x+1;   y=u²
dy/du=2u;   du/dx=3
dy/dx=2u×3=6(3x+1)
x=2 ⇒ dy/dx=42

Neyron üçün zəncir qaydası

Bir neyron üçün z=wx+b, a=φ(z), L=L(a) olduqda:

∂L/∂w = (∂L/∂a) · (∂a/∂z) · (∂z/∂w)
         = (∂L/∂a) · φ'(z) · x

Hər bir vuruq bir əlaqəni təsvir edir: loss-un aktivləşməyə təsiri, aktivləşmənin z-ə həssaslığı və z-nin çəkiyə həssaslığı. Bu vuruqların hasili həmin çəkinin yekun loss-a təsirini verir.

İntuitiv izah: “Loss dəyişəndə neyronun çıxışı nə qədər dəyişir?”, “çıxış z dəyişəndə nə qədər dəyişir?” və “z çəki dəyişəndə nə qədər dəyişir?” suallarının cavablarını bir-birinə vururuq.

13.9. Çəkilərin yenilənməsi mexanizmi

Gradientlər hesablandıqdan sonra optimizator parametrləri yeniləyir. Sadə Gradient Descent-də hər çəki öz gradientinin əks istiqamətində dəyişir. Bias üçün də eyni prinsip tətbiq olunur.

w_new = w_old − η(∂L/∂w)
b_new = b_old − η(∂L/∂b)

Ölçülərin uyğunluğu vacibdir: x vektoru 1×3, W matrisi 3×2 olduqda xW nəticəsi 1×2 ölçülü vektordur. Hər nəticə komponenti bir növbəti qat neyronunun çəkili cəmidir. Bias vektoru eyni sayda neyron üçün bir qiymət daşıyır.

Bir parametr üzrə tam nümunə

Fərz edək w=0.5, gradient=−0.8 və η=0.1. Onda w_new=0.5−0.1×(−0.8)=0.58. Gradient mənfi olduğuna görə parametr artdı. Bu artım loss-u lokal olaraq azaltmaq istiqamətindədir.

İnteraktiv parametr yeniləmə kalkulyatoru

w_new = 0.58

Çoxqatlı şəbəkədə bu əməliyyat bütün çəkilər matrisi və bias vektorlarına eyni qayda ilə, lakin hər parametr üçün ayrıca gradientlə tətbiq olunur.

13.10. Epoch, Batch və Iteration

Təlim verilənlərinin necə hissələrə bölünməsi optimallaşdırmanın sürətinə və gradientin dəyişkənliyinə təsir edir. Epoch bütün təlim dataset-inin model tərəfindən bir dəfə işlənməsidir. Batch bir yeniləmə addımında istifadə olunan müşahidələr qrupudur. Iteration bir batch üzrə gradient hesablanıb parametr yeniləndiyi addımdır.

Məsələn, təlim dataset-ində 1 000 müşahidə, batch size=100 olarsa, bir epoch-da 10 iteration olur. Əgər 20 epoch təlim aparılırsa, ümumi yenilənmə sayı 20×10=200 iteration olacaq.

Iteration per epoch = ⌈N / B⌉
Ümumi iteration = Epoch sayı × ⌈N / B⌉

İnteraktiv batch hesablayıcısı

Bir epoch: 10 iteration; ümumi: 200

Batch size kiçik olduqda bir epoch-da daha çox yenilənmə baş verir və gradient daha səs-küylü ola bilər. Böyük batch daha sabit gradient təxmini verə bilər, lakin daha çox yaddaş tələb edir. Optimal ölçü hardware və dataset-dən asılıdır.

13.11. SGD, Momentum, RMSprop və Adam

Optimizatorlar gradientlərdən istifadə edərək parametrləri yeniləyən qaydalardır. Onlar addımın istiqamətini və miqyasını müxtəlif üsullarla müəyyən edir.

SGD:   θₜ₊₁ = θₜ − ηgₜ
Momentum:   vₜ = βvₜ₋₁ + gₜ;   θₜ₊₁ = θₜ − ηvₜ
RMSprop:   sₜ = ρsₜ₋₁ + (1−ρ)gₜ²;   θₜ₊₁ = θₜ − ηgₜ/(√sₜ+ε)

Adam-da momentlərin bias correction mərhələsi də tətbiq olunur. Sadələşdirilmiş düsturlar əsas ideyanı göstərir; real kitabxana tətbiqlərində əlavə sabitlər və düzəlişlər mövcuddur.

Optimizator seçimi üzrə praktik yanaşma

Adam çox vaxt ilkin sınaq üçün rahat seçimdir. SGD+Momentum bəzi dərin modellərdə yaxşı ümumiləşdirmə verə bilər. RMSprop adaptiv addım tələb olunan hallarda istifadə edilir. Yekun qərar validation nəticələri, təlim sabitliyi və hesablama xərci əsasında verilməlidir.

13.12. Neyron şəbəkəsində overfitting

Overfitting modelin təlim verilənlərinə həddən artıq uyğunlaşması və yeni, görünməmiş verilənlərdə zəif nəticə göstərməsidir. Bu zaman training loss azalmağa davam etdiyi halda validation loss müəyyən nöqtədən sonra arta bilər. Model təsadüfi səs-küyü və dataset-ə xas detalları da öyrənmiş olur.

Qrafikdə qırmızı validation loss əvvəl azalır, sonra yüksəlir. Yaşıl şaquli xətt modelin validation nəticəsinin ən yaxşı olduğu nöqtəni göstərir. Bu nöqtədən sonra təlimi davam etdirmək modelin yeni verilənlərdəki keyfiyyətini pisləşdirə bilər.

Overfitting-in səbəbləri

  • Modelin verilənlərə nisbətən həddən artıq mürəkkəb olması;
  • təlim nümunələrinin az və ya təmsilçiliyinin zəif olması;
  • çox uzun təlim və early stopping tətbiq edilməməsi;
  • verilənlərdə səs-küy, etiket səhvləri və ya data leakage.

Azaldılması üçün daha çox və müxtəlif təlim veriləni, sadə arxitektura, regularization, dropout, data augmentation və early stopping tətbiq oluna bilər.

13.13. Dropout və digər regularization yanaşmaları

Regularization modelin həddən artıq mürəkkəbləşməsini məhdudlaşdıraraq ümumiləşdirməni yaxşılaşdırmağa yönəlmiş üsullar toplusudur. Dropout təlim zamanı neyronların müəyyən hissəsinin çıxışını təsadüfi olaraq sıfırlayır. Beləliklə, şəbəkə yalnız konkret neyron kombinasiyasına həddən artıq arxalanmamağı öyrənir.

Dropout rate=0.2 olduqda təlim zamanı həmin qatın aktivləşmələrinin təxminən 20%-i təsadüfi sıfırlanır. İnference mərhələsində dropout söndürülür; framework aktivləşmələrin miqyasını uyğunlaşdırır.

13.14. Öyrənmə prosesinin qrafiklə təhlili

Training loss və validation loss qrafikləri modelin öyrənmə davranışını izləməyə kömək edir. Hər iki əyrinin azalması modelin öyrəndiyini göstərə bilər. Training loss azalarkən validation loss artmağa başlayırsa, overfitting ehtimalı yaranır. Hər iki loss yüksək qalırsa, model underfitting yaşayır, xüsusiyyətlər yetərli deyil və ya optimallaşdırma düzgün qurulmayıb.

Laboratoriya işi №13

Bir və çoxqatlı neyron şəbəkəsində Forward Propagation, Backpropagation və Gradient Descent mexanizmlərinin hesablanması və proqramlaşdırılması.

1. İşin məqsədi

Birqatlı və çoxqatlı neyron şəbəkəsində irəli yayılma, loss hesablanması, zəncir qaydası ilə gradientlərin tapılması və Gradient Descent vasitəsilə çəkilərin yenilənməsini həm əl ilə, həm Python proqramı ilə həyata keçirmək.

2. Nəzəri əsas

Laboratoriyanın birinci hissəsində bir neyronlu reqressiya modeli, ikinci hissəsində isə bir gizli qatlı MLP istifadə edilir. Birinci modeldə gradientin analitik hesablanması asandır; ikinci modeldə isə backpropagation-un qatlar üzrə ötürülməsi müşahidə olunur.

3. Bir neyronlu model — əl ilə hesablanma

Model ŷ=wx+b, loss L=½(ŷ−y)² olsun. Onda ∂L/∂w=(ŷ−y)x və ∂L/∂b=(ŷ−y). x=2, y=5, w=1, b=0 olduqda ŷ=2, xəta −3, gradientlər ∂L/∂w=−6 və ∂L/∂b=−3 alınır. η=0.1 ilə w_new=1.6, b_new=0.3.

ŷ=wx+b=1×2+0=2
L=½(2−5)²=4.5
∂L/∂w=(ŷ−y)x=(−3)×2=−6
∂L/∂b=ŷ−y=−3
w_new=1−0.1(−6)=1.6; b_new=0−0.1(−3)=0.3

4. Çoxqatlı model — NumPy ilə backpropagation

Aşağıdakı nümunə bir gizli qatlı, sigmoid aktivləşməli kiçik şəbəkəni öyrədir. Kodda bir nümunəlik batch üçün gradientlər açıq hesablanır. Sadəlik üçün başlanğıc parametrlər sabit verilib.

import numpy as np # XOR verilənləri X = np.array([[0., 0.], [0., 1.], [1., 0.], [1., 1.]]) y = np.array([[0.], [1.], [1.], [0.]]) def sigmoid(z): return 1 / (1 + np.exp(-z)) def sigmoid_grad(a): # a = sigmoid(z), buna görə törəmə a(1-a) return a * (1 - a) rng = np.random.default_rng(7) W1 = rng.normal(0, 0.5, (2, 4)) b1 = np.zeros((1, 4)) W2 = rng.normal(0, 0.5, (4, 1)) b2 = np.zeros((1, 1)) lr = 0.8 for epoch in range(10000): # FORWARD z1 = X @ W1 + b1 a1 = sigmoid(z1) z2 = a1 @ W2 + b2 y_hat = sigmoid(z2) # Binary cross-entropy üçün sigmoid çıxışının # sadələşdirilmiş delta ifadəsi: m = len(X) dz2 = (y_hat - y) / m # BACKPROPAGATION dW2 = a1.T @ dz2 db2 = np.sum(dz2, axis=0, keepdims=True) da1 = dz2 @ W2.T dz1 = da1 * sigmoid_grad(a1) dW1 = X.T @ dz1 db1 = np.sum(dz1, axis=0, keepdims=True) # GRADIENT DESCENT W2 -= lr * dW2 b2 -= lr * db2 W1 -= lr * dW1 b1 -= lr * db1 if epoch % 2000 == 0: eps = 1e-9 loss = -np.mean(y*np.log(y_hat+eps) + (1-y)*np.log(1-y_hat+eps)) print(epoch, round(loss, 4)) print("Yekun ehtimallar:") print(np.round(y_hat, 3)) print("Sinif proqnozları:") print((y_hat >= 0.5).astype(int))

Kodun izahı: z1 gizli qatın xətti birləşməsidir, a1 sigmoid-dən sonrakı aktivləşmədir. z2 çıxış qatının xətti birləşməsi, y_hat isə proqnoz ehtimalıdır. dz2 çıxış qatında loss-un xətti birləşməyə görə törəməsidir. Sonra dW2 və db2 hesablanır, gradient gizli qata ötürülür, sigmoid törəməsi ilə vurulur və dW1/db1 tapılır. Sonda bütün parametrlər gradientin əks istiqamətində yenilənir.

Bu kiçik XOR nümunəsi tədris məqsədlidir. Neyron şəbəkəsinin nəticəsi başlanğıc parametrlərdən və learning rate-dən asılı ola bilər. Təcrübədə seed-ləri dəyişərək bir neçə dəfə yoxlayın və loss trayektoriyasını izləyin.
