15.2. Mətn verilənlərinin emalı

Şəkil 15.2. Mətnin model üçün rəqəmsal təqdimata çevrilməsi.

Əsas əməliyyatlar

  • Normallaşdırma: hərflərin, boşluqların, durğu işarələrinin standartlaşdırılması.
  • Tokenləşdirmə: mətnin sözlərə, alt-sözlərə və ya simvollara bölünməsi.
  • Stop-sözlərin idarəsi: məsələyə az informasiya verən sözlərin ehtiyatla çıxarılması. “deyil” kimi inkar sözlərini silmək sentiment analizini poza bilər.
  • Lemmatizasiya/stemminq: sözün lüğəvi formasına və ya kökünə yaxınlaşdırılması.
  • Vektorlaşdırma: sözləri say, TF-IDF və ya öyrənilmiş embedding vektorları ilə təqdim etmək.

İnteraktiv mətn emalı nümunəsi

Nəticə burada görünəcək.

TF-IDF ideyası

TF-IDF sözün konkret sənəddə nə qədər əhəmiyyətli olduğunu, eyni zamanda bütün sənədlərdə nə qədər geniş yayıldığını nəzərə alır.

TF-IDF(t,d) = TF(t,d) × log( N / DF(t) )

Burada TF sözün sənəddəki tezliyi, DF sözün rast gəlindiyi sənədlərin sayı, N isə sənədlərin ümumi sayıdır. Bu yanaşma axtarış, sənəd təsnifatı və açar söz çıxarılmasında istifadə oluna bilər.

15.3. Natural Language Processing (NLP)

Natural Language Processing (NLP) kompüterlərin insan dilindəki mətni və nitqi emal etməsi, təhlil etməsi və yaratması ilə məşğul olan süni intellekt sahəsidir. NLP-də qrammatika, statistika, maşın öyrənməsi və neyron şəbəkələri birləşir.

Ənənəvi yanaşma

Qayda, lüğət, n-gram, Bag-of-Words və TF-IDF. Kiçik verilənlərdə izahı nisbətən asan ola bilər.

Müasir yanaşma

Embedding və Transformer modelləri konteksti nəzərə alaraq söz və cümlələrin mənasını öyrənir.

Maşın tərcümə sistemi necə işləyir?

Google Translate tipli sistemlər sadəcə sözləri lüğətdə əvəz etmir. Müasir neyron maşın tərcüməsi cümlənin kontekstini kodlaşdırır və başqa dildə uyğun ardıcıllığı yaradır. Sadələşdirilmiş ardıcıllıq:

Necə yaradılır? Əvvəlcə mənbə və hədəf dildə paralel cümlə korpusu toplanır; mətn təmizlənir və tokenləşdirilir; Transformer modeli öyrədilir; BLEU və ya chrF kimi göstəricilər, eləcə də insan qiymətləndirməsi ilə yoxlanılır; model API vasitəsilə tətbiqə inteqrasiya edilir. Lüğət, domen və dialekt fərqləri ayrıca nəzərə alınmalıdır.

Transformer və attention

Self-attention cümlədəki hər tokenin digər tokenlərlə əlaqəsini hesablamağa imkan verir. Bu, uzaq kontekstdəki sözlər arasında əlaqəni tutmağa kömək edir.

Attention(Q,K,V) = softmax( QKᵀ / √dₖ ) V

Q — sorğu (query), K — açar (key), V — dəyər (value), dₖ isə açar vektorunun ölçüsüdür. Softmax çəkiləri normallaşdırır; nəticədə model kontekstə uyğun informasiya birləşdirir.

Attention çəkilərinin mini-simulyasiyası

“Mən kitabı tələbəyə verdim” cümləsində “verdım” felinin hansı sözə diqqət ayırdığını təsəvvür edin.

Bu, mexanizmi izah edən tədris simulyasiyasıdır; real modelin çəkiləri deyil.

Səs sistemləri dalğa formasını rəqəmsal siqnala çevirir. Nitqin tanınması (ASR) səsi mətnə, nitqin sintezi (TTS) isə mətni səsə çevirir. Səsli köməkçi adətən ASR → NLP/LLM → dialoq idarəetməsi → TTS ardıcıllığı ilə işləyir.

Səs emalında nümunələmə tezliyi, amplituda, fon səs-küyü və danışanın xüsusiyyətləri nəzərə alınır. Mel-spektroqram zaman və tezlik komponentlərini vizuallaşdırmaq üçün istifadə oluna bilər.

x[n] = x(n / fₛ)    ·    Nyquist: fₛ ≥ 2 fₘₐₓ

Burada fₛ nümunələmə tezliyi, fₘₐₓ isə saxlanılacaq ən yüksək tezlikdir. Nitq tanıma keyfiyyəti Word Error Rate (WER) ilə qiymətləndirilə bilər:

WER = (S + D + I) / N

S — əvəzlənmə, D — silinmə, I — əlavə edilmə, N — istinad transkriptindəki sözlərin sayıdır.

Azərbaycan dili üçün korpus yaratma

  1. Məqsəd və lisenziyanı müəyyən edin.
  2. İcazəli mənbələrdən müxtəlif janrlı mətn toplayın.
  3. Şəxsi məlumatları anonimləşdirin.

Python nümunəsi: TF-IDF + Logistic Regression

Python · scikit-learn
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.pipeline import Pipeline
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import classification_report

# CSV: text, category sütunları olmalıdır
df = pd.read_csv("muracietler.csv").dropna(subset=["text", "category"])
X_train, X_test, y_train, y_test = train_test_split(
    df["text"], df["category"], test_size=0.2,
    random_state=42, stratify=df["category"]
)

model = Pipeline([
    ("tfidf", TfidfVectorizer(ngram_range=(1, 2), min_df=2)),
    ("clf", LogisticRegression(max_iter=1000, class_weight="balanced"))
])
model.fit(X_train, y_train)
print(classification_report(y_test, model.predict(X_test)))

yeni_muraciet = ["Təqaüd üçün hansı sənədlər lazımdır?"]
print(model.predict(yeni_muraciet))

Kod real dataset faylı və uyğun etiketlər olduqda işlədilir. Kiçik nümunədə min_df parametrini dataset ölçüsünə uyğunlaşdırın. Mətnin dilinə uyğun tokenləşdirmə və normalizasiya ayrıca əlavə oluna bilər.

  • API autentifikasiya, avtorizasiya və rate limiting ilə qorunur.
  • Şəxsi məlumatlar loglarda maskalanır.
  • Cavab vaxtı, xəta faizi, data drift və model keyfiyyəti izlənir.
  • Rollback və əvvəlki model versiyasına qayıtma planı hazırlanır.

FastAPI ilə sadə model API-si

Python · FastAPI (konseptual nümunə)
from fastapi import FastAPI
from pydantic import BaseModel
import joblib

app = FastAPI(title="MDU NLP API")
model = joblib.load("text_classifier.joblib")

class TextRequest(BaseModel):
    text: str

@app.post("/predict")
def predict(request: TextRequest):
    label = model.predict([request.text])[0]
    return {"category": str(label)}

Bu nümunədə model əvvəlcədən təlim keçib joblib ilə saxlanmalıdır. İstehsalat mühitində model faylının etibarlı mənbədən gəlməsi, giriş uzunluğunun məhdudlaşdırılması, autentifikasiya və audit vacibdir.

Praktiki tapşırıqlar

  1. Mətn emalı: Azərbaycan dilində 30 qısa rəy toplayın (icazəli və anonim mənbədən), normallaşdırın, tokenləşdirin və tezlik cədvəli qurun.
  2. Sentiment analizi: Rəyləri müsbət, mənfi və neytral siniflərinə etiketləyin. TF-IDF + Logistic Regression modeli qurub Precision, Recall və F1 göstəricilərini hesablayın.
  3. Multimodal sistem: Eyni istifadəçi müraciətinə mətn və əlavə edilmiş təsvir daxil olan prototip dizayn edin. OCR və mətn təsnifatını birləşdirən arxitektura sxemi çəkin.
  4. Tövsiyə sistemi: 5 istifadəçi və 6 tədris resursu üçün kiçik reytinq matrisi qurun; content-based və collaborative yanaşmaları müqayisə edin.
  5. İnteqrasiya: Təlim edilmiş modeli API şəklində təqdim edin; giriş validasiyası, xəta cavabı və cavab vaxtını sənədləşdirin.

Laboratoriya işi №15

Mətn və ya təsvir verilənləri əsasında sadə intellektual tanıma sisteminin hazırlanması

İşin məqsədi

Mətn və ya təsvir verilənlərini hazırlamaq, uyğun model seçmək, modeli öyrətmək və test nəticələrini qiymətləndirməklə işlək prototip yaratmaq.

Tapşırıq variantı A — Mətn tanıma

  1. Ən azı 3 kateqoriya üzrə etiketlənmiş mətn dataset-i hazırlayın.
  2. Boş və təkrarlanan qeydləri təmizləyin, mətn normallaşdırması aparın.
  3. TF-IDF + Logistic Regression modelini öyrədin.
  4. Test dəstində classification report və confusion matrix yaradın.
  5. Modeli sadə veb/API interfeysinə inteqrasiya edin.

Tapşırıq variantı B — Təsvir tanıma

  1. Ən azı 2 sinifdən ibarət, istifadəyə icazəli təsvir dataset-i seçin.
  2. Train/validation/test bölgüsü yaradın; təsvir ölçülərini eyniləşdirin.
  3. Transfer learning və ya kiçik CNN modeli qurun.
  4. Accuracy, Precision, Recall və confusion matrix hesablayın.
  5. Yeni təsvir üçün sinif və confidence göstərən prototip hazırlayın.
