17.3. Elmi hipotezin formalaşdırılması

Hipotez tədqiqat sualına verilən, empirik məlumatlarla yoxlanıla bilən ilkin cavabdır. Hipotez sadəcə gözlənti deyil; dəyişənlər arasındakı əlaqəni və ya metodlar arasındakı fərqi ölçülə bilən formada ifadə etməlidir.

Hipotezin növləri

NövMəzmunNümunə
H₀ — sıfır hipoteziFərq və ya əlaqə yoxdurİki modelin orta F1 göstəriciləri arasında fərq yoxdur
H₁ — alternativ hipotezFərq və ya əlaqə mövcuddurRandom Forest-in orta F1 göstəricisi Logistic Regression-dan yüksəkdir
İstiqamətliFərqin istiqaməti əvvəlcədən müəyyən edilirModel A model B-dən yüksək Recall verir
İstiqamətsizFərq var, istiqamət əvvəlcədən iddia edilmirİki modelin nəticələri fərqlənir

Hipotezin yoxlanması üçün əsas anlayışlar

Asılı dəyişən

Ölçülən nəticə: Accuracy, F1, MAE, RMSE və ya gecikmə.

Müstəqil dəyişən

Təsiri araşdırılan amil: alqoritm, feature dəsti, hiperparametr və ya təlim strategiyası.

Əhəmiyyət səviyyəsi α

Yanlış müsbət nəticə ehtimalı üçün əvvəlcədən seçilən hədd; çox vaxt 0.05.

Effekt ölçüsü

Fərqin yalnız statistik deyil, praktik böyüklüyünü ifadə edir.

H₀: μA = μB     H₁: μA ≠ μB

Burada μA və μB eyni eksperiment protokolu üzrə alınan nəticələrin orta qiymətləridir. Bir neçə təsadüfi seed və ya fold istifadə edilirsə, müqayisə cütləşdirilmiş müşahidələr əsasında qurula bilər.

Hipotez yoxlama simulyatoru

p-value və orta göstəriciləri daxil edin.
Diqqət: p-value H₀ hipotezinin doğru olma ehtimalı deyil. O, H₀ doğru qəbul edildikdə müşahidə edilən və ya daha ekstremal nəticənin əldə olunma ehtimalını ifadə edir. Statistik əhəmiyyət praktik əhəmiyyətlə eyni deyil.

17.4. Dataset seçimi və məlumat mənbələrinin əsaslandırılması

Dataset tədqiqatın sübut bazasıdır. Uyğun olmayan və ya zəif əsaslandırılmış dataset üzərində qurulan model yüksək metrik göstərsə belə, elmi nəticə etibarlı olmaya bilər. Dataset seçərkən onun tədqiqat sualına uyğunluğu, mənşəyi, lisenziyası, ölçüsü, təmsilçiliyi, etiket keyfiyyəti və zaman konteksti araşdırılmalıdır.

Dataset kartı (Dataset Card)

Dataset kartı məlumatın mənşəyini, məqsədini, toplanma prosesini, strukturunu, lisenziyasını, məhdudiyyətlərini və etik risklərini sənədləşdirir. Bu sənəd başqa tədqiqatçıya verilənin hansı kontekstdə yarandığını anlamağa imkan verir.

Dataset kartı generatoru

Daxil edilən məlumatlardan qısa kart yaradılacaq.
Data leakage nümunəsi: tələbənin kursu tərk edib-etmədiyini ilk dörd həftədə proqnozlaşdırmaq istəyirik. Əgər modelə semestrin sonunda hesablanan yekun nəticə və ya sonrakı həftələrin fəaliyyəti daxil edilirsə, model gələcək məlumatı görmüş olur. Bu, real proqnoz şəraitini təhrif edir.

Baseline nəticəsinin nümunə müqayisəsi

Şəkil 17.5. Tədris üçün nümunəvi F1 göstəriciləri. Bunlar real eksperiment nəticəsi deyil.

Modelin üstünlüyünü sübut etmək üçün bütün modellər eyni train/test bölgüsü, eyni preprocessing qaydası, eyni hədəf dəyişən və eyni metriklə qiymətləndirilməlidir. Test dəstinə baxaraq hiperparametr seçmək olmaz; bu, test dəstini dolayı yolla təlim prosesinə daxil edir.

Python: sadə baseline nümunəsi

Python · scikit-learn
from sklearn.dummy import DummyClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import classification_report

# X_train, X_test, y_train, y_test əvvəlcədən hazırlanıb
dummy = DummyClassifier(strategy="most_frequent")
dummy.fit(X_train, y_train)
dummy_pred = dummy.predict(X_test)

baseline = Pipeline([
    ("scale", StandardScaler()),
    ("model", LogisticRegression(max_iter=1000))
])
baseline.fit(X_train, y_train)
baseline_pred = baseline.predict(X_test)

print("Dummy baseline")
print(classification_report(y_test, dummy_pred))
print("Logistic Regression baseline")
print(classification_report(y_test, baseline_pred))

17.6. Eksperiment dizaynı

Eksperiment dizaynı hipotezi yoxlamaq üçün hansı məlumatın, hansı modelin, hansı parametrlərin, hansı qiymətləndirmə protokolunun və hansı statistik metodun istifadə ediləcəyini əvvəlcədən müəyyən edir. Düzgün dizayn təsadüfi dəyişikliklərin təsirini azaldır və modellər arasında ədalətli müqayisə yaradır.

Şəkil 17.6. Nümunəvi bölgü. Faizlər dataset və problemə görə dəyişə bilər; zaman və qrup strukturu varsa uyğun split seçilməlidir.

Cross-validation

K-Fold cross-validation dataset-i K hissəyə ayırır. Hər iterasiyada bir hissə validasiya, qalan K−1 hissə təlim üçün istifadə olunur. Bu proses hər hissə bir dəfə validasiya olana qədər davam edir. Nəticədə bir neçə ölçmə əldə edilir və modelin dəyişkənliyi haqqında fikir yaranır.

K-Fold bölgüsünün interaktiv təsviri

Hər sətirdə bir fold validasiya, qalanları təlim üçün seçilir.

Eksperiment protokolu

  1. Dataset və hədəf dəyişəni sabitləşdirin.
  2. Train/test bölgüsünü model qurulmazdan əvvəl yaradın.
  3. Preprocessing addımlarını yalnız təlim məlumatında öyrədin (məsələn, scaler).
  4. Baseline və namizəd modelləri eyni şərtlərdə öyrədin.
  5. Hiperparametrləri yalnız train/validation və ya cross-validation üzərində seçin.
  6. Test dəstini yekun qiymətləndirməyə qədər toxunulmaz saxlayın.
  7. Seed, versiya, konfiqurasiya və metrikləri qeyd edin.

17.7. Modellərin müqayisəli qiymətləndirilməsi

Model müqayisəsi yalnız bir metrikə əsaslanmamalıdır. Məsələnin məqsədi, sinif balansı, yanlış pozitiv və yanlış neqativlərin nəticəsi, proqnoz sürəti, resurs sərfi və izaholunma ehtiyacı nəzərə alınmalıdır.

Təsnifat üçün metriklər

Reqressiya üçün metriklər

MAE = (1/n) Σ |yᵢ − ŷᵢ|    ·    RMSE = √[(1/n) Σ (yᵢ − ŷᵢ)²]

MAE orta mütləq xətanı, RMSE isə böyük xətalara daha çox cəza verən kvadrat köklü orta kvadratik xətanı göstərir. R² modelin hədəf dəyişənin variasiyasını nə dərəcədə izah etdiyini qiymətləndirir; mənfi R² test nəticəsinin sadə orta proqnozundan da zəif ola biləcəyini göstərir.

İnteraktiv confusion matrix

TP, FP, FN və TN dəyərlərini dəyişərək Precision, Recall və Accuracy hesablayın.

Model müqayisəsi — nümunə qrafik

Şəkil 17.7. Nümunəvi modellər üzrə Precision, Recall və F1. Dəyərlər metodun izahı üçündür.

Model A daha yüksək F1 verə bilər, lakin tətbiqdə Recall daha vacibdirsə Model B seçilə bilər. Model seçimi metriklərə baxıb avtomatik qərar vermək deyil; tədqiqat probleminin məqsədi və səhvlərin qiyməti ilə əsaslandırılmalıdır.

17.8. Statistik nəticələrin təhlili

Eksperiment nəticələri təsadüfi bölünmə, seed, nümunə seçimi və ölçmə xətası səbəbindən dəyişə bilər. Statistik təhlil müşahidə olunan fərqin təsadüfi dəyişkənliklə izah olunub-olunmadığını və fərqin nə qədər böyük olduğunu araşdırmağa kömək edir.

Əsas statistik anlayışlar

Orta qiymət

Bir neçə ölçmənin mərkəzi tendensiyası: x̄ = Σxᵢ/n.

Standart kənarlaşma

Nəticələrin orta ətrafında yayılmasını göstərir.

Etibar intervalı

Parametr üçün verilən etibar səviyyəsinə uyğun interval qiymətləndirməsi.

p-value

H₀ doğru olduqda müşahidə edilən qədər və ya daha ekstremal nəticənin ehtimalı.

Effekt ölçüsü və statistik əhəmiyyət

p-value kiçik olması fərqin praktik cəhətdən böyük olması demək deyil. Elmi dürüstlük: mənfi və ya gözlənilməz nəticələri gizlətmək, metrikləri seçərək təqdim etmək, eyni nəticəni yeni tədqiqat kimi təkrar nəşr etmək, saxta istinad və ya uydurma eksperiment yaratmaq yolverilməzdir. Generativ AI istifadə olunubsa, nəşriyyat və qurum qaydalarına uyğun açıqlama edilməli, fakt və istinadlar müəllif tərəfindən yoxlanılmalıdır.

Praktiki tapşırıqlar

  1. Tədqiqat probleminin formalaşdırılması: təhsil, səhiyyə, sənaye və ya kibertəhlükəsizlik sahəsindən bir problem seçin. Geniş mövzunu konkret tədqiqat sualına çevirin və problemin elmi/praktik əhəmiyyətini əsaslandırın.
  2. Hipotez və dəyişənlər: seçilmiş problem üzrə H₀ və H₁ hipotezlərini yazın. Asılı, müstəqil və nəzarət dəyişənlərini müəyyən edin.
  3. Dataset kartı: açıq dataset seçin. Mənbə, lisenziya, nümunə sayı, feature-lər, hədəf dəyişən, çatışmazlıqlar və etik məhdudiyyətləri sənədləşdirin.
  4. Baseline qurulması: təsnifat problemi üçün DummyClassifier və Logistic Regression, reqressiya problemi üçün DummyRegressor və Linear Regression qurun.
  5. Eksperiment protokolu: train/validation/test bölgüsü, cross-validation, random seed, metrik və hiperparametr axtarışını əvvəlcədən təsvir edin.
  6. Müqayisəli qiymətləndirmə: ən azı üç modeli eyni protokolla qiymətləndirin. Macro-F1, Recall, Precision və ROC-AUC və ya MAE/RMSE metriklərindən uyğun olanları seçin.
  7. Statistik təhlil: təkrar ölçmələr üzrə orta, standart kənarlaşma və etibar intervalı hesablayın. Uyğun statistik test seçiminizi əsaslandırın.
  8. Təkrarlana bilmə paketi: README, requirements.txt, seed, konfiqurasiya faylı, nəticə cədvəli və qrafiklərdən ibarət layihə qovluğu yaradın.
  9. Elmi vizuallaşdırma: nəticələri ən azı iki qrafik və bir cədvəldə təqdim edin. Ox adlarını, vahidləri, nümunə sayını və qrafikin izahını əlavə edin.
  10. Elmi hesabat: tədqiqatın giriş, metodologiya, nəticə, müzakirə, məhdudiyyət və nəticə bölmələrini hazırlayın.
