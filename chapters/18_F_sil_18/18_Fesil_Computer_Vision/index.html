Fəsilə giriş və öyrənmə xəritəsi

Kompüter görməsi kompüterə foto, video və kameradan gələn görüntülərdən faydalı məlumat çıxarmağı öyrədən süni intellekt sahəsidir. İnsan gözlə avtomobili, piyadanı və yol nişanını tanıyır; kompüter görmə sistemi isə piksel ədədlərini emal edir, nümunələri model vasitəsilə öyrənir və nəticədə obyektin sinfini, yerini və bəzən hərəkətini müəyyən edir.

Giriş

Kamera, şəkil, video, skaner, mikroskop və ya sensor.

Emal

Rəng çevirmə, filtr, kənar, kontur, seqmentasiya və neyron şəbəkə.

Nəticə

Sinif, koordinat, maska, say, izləmə və qərar.

Fəslin sonunda tələbə bacarmalıdır: kameranı və hesablama qurğusunu sistemə qoşmağı; piksel və rəng kanallarını izah etməyi; OpenCV ilə şəkli oxumağı, çevirməyi, filtrləməyi; kontur və kənarları tapmağı; Google Colab-da real dataset üzərində YOLO ilə video kadrlarında obyektləri aşkarlamağı.

Aparat təminatı: qurğular, quraşdırma və əlaqələndirmə

Kompüter görmə sistemi təkcə proqramdan ibarət deyil. Görüntünü əldə edən sensor, onu ötürən interfeys, hesablayan qurğu, yaddaş və nəticəni göstərən qurğular birlikdə işləyir. Qurğuların seçimi tapşırığın məqsədindən asılıdır: laboratoriyada USB kamera kifayət edə bilər, avtonom robotda isə kamera, dərinlik sensoru, GPU və real-vaxt idarəetmə modulu tələb oluna bilər.

Quraşdırma və əlaqələndirmənin mərhələləri

  1. Tələbi müəyyən edin: hansı obyekt, hansı məsafə, hansı işıq, neçə kadr/saniyə və hansı dəqiqlik lazımdır?
  2. Kameranı yerləşdirin: görüntü sahəsi, kamera bucağı, fokus və işıqlandırmanı yoxlayın.
  3. Fiziki qoşulma: USB kameranı USB portuna; IP kameranı Ethernet/PoE şəbəkəsinə; sensoru istehsalçının interfeysinə qoşun. Gərginlik və kabel standartını yoxlamadan enerji verməyin.
  4. Drayver və proqram: əməliyyat sisteminin kameranı tanıdığını yoxlayın; OpenCV və ya istehsalçı SDK-sını quraşdırın.
  5. Kalibrləmə: lazım olduqda kamera daxili parametrlərini (focal length, principal point, distortion) şahmat taxtası nümunəsi ilə hesablayın.
  6. Test: görüntü, FPS, gecikmə, fokus, kadr itkisi və temperaturu ölçün.

Məlumat axını: kamera görüntünü yaradır, interfeys ötürür, hesablama qurğusu emal edir; model qərar verir, yaddaş nəticələri saxlayır, tətbiq isə istifadəçiyə təqdim edir.

18.1. Kompüter görməsi (Computer Vision) anlayışı və inkişaf mərhələləri

Kompüter görməsi kompüter elminin görüntüdən məna çıxarmaqla məşğul olan sahəsidir. Sadə dillə desək, kompüterə “şəkildə nə var?”, “haradadır?”, “neçə dənədir?” və “nə baş verir?” suallarına cavab verməyi öyrədir. İnsan görməsi ilə kompüter görməsini eyniləşdirmək olmaz: insan beyni dünyanı bütöv təcrübə ilə qavrayır, kompüter isə rəqəmsal piksel massivlərini və öyrədilmiş riyazi modelləri emal edir.

Təsnifat (classification)

Bütün təsvirə bir və ya bir neçə sinif etiketi verir: “avtomobil”, “pişik”.

Obyekt aşkarlanması (detection)

Obyektin sinfini və sərhəd düzbucaqlısını (bounding box) tapır.

Seqmentasiya

Hər pikseli obyektə və ya fon sinfinə aid edir.

İzləmə (tracking)

Obyektin ardıcıl video kadrlarında kimliyini izləyir.

İnkişaf mərhələləri: 1960–1980-ci illərdə həndəsi və qayda əsaslı yanaşmalar; 1980–2000-ci illərdə xüsusiyyət çıxarılması, SIFT/HOG kimi metodlar; 2012-ci ildən sonra GPU və dərin CNN modellərinin geniş tətbiqi; 2020-ci illərdə Transformer, multimodal modellər, real-vaxt aşkarlama və edge AI.

Nümunə: kamera qarşısında avtomobil görünür. Təsnifat yalnız “avtomobil” deyə bilər. Aşkarlama avtomobilin çərçivəsini çəkir. Seqmentasiya avtomobilin formasını piksel-piksel ayırır. İzləmə isə avtomobilin növbəti kadrlarda hərəkətini izləyir.

18.2. Kompüter görmə sistemlərinin arxitekturası və iş prinsipi

Arxitektura sistemin hissələrinin necə təşkil olunduğunu və məlumatın hansı ardıcıllıqla keçdiyini göstərir. Tipik sistemdə görüntünün alınması → ilkin emal → xüsusiyyət/model → qərar → nəticənin saxlanması və təqdimatı mərhələləri var.

  1. Acquisition: kamera və ya fayldan kadr alınır.
  2. Preprocessing: ölçü uyğunlaşdırılır, rəng çevrilir, səs-küy azaldılır, normallaşdırılır.
  3. Feature extraction: klassik üsullarda kənar, tekstura, histogram; dərin öyrənmədə CNN/Transformer xüsusiyyətləri öyrənir.
  4. Inference: model sinif ehtimalı, bounding box və ya maska çıxarır.
  5. Postprocessing: hədd (confidence threshold), NMS və koordinatların ilkin ölçüyə qaytarılması tətbiq olunur.
  6. Output: görüntü üzərində işarələr, hesabat, xəbərdarlıq və ya idarəetmə siqnalı.

İş prinsipi: model əvvəlcədən etiketlənmiş nümunələrdə öyrədilir. Təlim zamanı proqnoz ilə düzgün cavab arasındakı itki hesablanır və çəkilər yenilənir. İstifadə zamanı model yeni görüntüyə proqnoz verir. Təlim (training) və proqnoz (inference) fərqli mərhələlərdir.

Sistemin keyfiyyəti yalnız modelin dəqiqliyi deyil. Kamera bucağı, işıq, bulanıqlıq, məlumatların təmsilçiliyi, hesablama gecikməsi və səhv qərarın nəticəsi də vacibdir.

18.3. Rəqəmsal təsvirlərin formalaşması və təsvirin təqdim olunması

Kamera obyektivindən keçən işıq sensorun fotohəssas elementlərinə düşür. Sensor işıq enerjisini elektrik siqnalına çevirir; analoq-rəqəmsal çevirici bu siqnalı ədədi qiymətlərə çevirir. Rəngli kamerada Bayer filtri kimi quruluşlar vasitəsilə rəng kanalları bərpa oluna bilər. Nəticə kompüter yaddaşında massiv kimi saxlanır.

Rəqəmsal təsvir iki ölçülü piksel torudur. Boz təsvir üçün bir piksel intensivlik qiyməti daşıyır. Rəngli təsvir üçün hər piksel bir neçə kanalın qiymətlərindən ibarətdir. 8-bit kanal adətən 0–255 aralığındadır: 0 qaranlıq, 255 yüksək intensivlik deməkdir.

Rəqəmsallaşdırmada iki anlayış vacibdir: məkan nümunələnməsi — təsvirin neçə piksel ilə təmsil olunması; kvantlaşdırma — hər pikselin neçə mümkün intensivlik səviyyəsi ala bilməsi. Daha yüksək çözünürlük daha çox detal verə bilər, lakin yaddaş və emal xərci artır.

Məsələn, 1920×1080 ölçülü RGB təsvir 2,073,600 piksel və hər piksel üçün 3 kanal saxlayır. Sıxılmamış 8-bit təsvirin təxmini həcmi: 1920 × 1080 × 3 = 6,220,800 bayt ≈ 5.93 MiB.

18.4. Piksel, rəng kanalları və təsvir ölçüləri

Piksel (picture element) rəqəmsal təsvirin ən kiçik ünvanlana bilən elementidir. shape çox vaxt (height, width, channels) ardıcıllığı ilə qaytarılır. Məsələn, (480, 640, 3) — 480 sətir, 640 sütun, 3 rəng kanalıdır. Diqqət: OpenCV massivlərində əvvəl hündürlük, sonra en göstərilir.

Koordinat başlanğıcı adətən sol yuxarı küncdür: x sağa, y aşağıya artır. Pikselə müraciət image[y, x] şəklindədir; əvvəl sətir (y), sonra sütun (x) yazılır.

Bit dərinliyi də vacibdir: 8-bit boz təsvir 256 intensivlik səviyyəsi, 8-bit × 3 kanallı RGB isə hər kanal üçün 256 mümkün qiymət daşıyır. 16-bit tibbi və elmi görüntülərdə daha geniş dinamik diapazon saxlanıla bilər.

18.5. RGB, BGR, HSV və Grayscale rəng modelləri

RGB qırmızı, yaşıl, mavi kanallarının qarışığıdır. Ekranlarda geniş yayılıb. BGR eyni üç kanalın fərqli ardıcıllıqla saxlanmasıdır; OpenCV-nin imread funksiyası standart olaraq BGR qaytarır. Buna görə Matplotlib/PIL ilə göstərərkən BGR→RGB çevirməsi vacibdir.

ModelTərkibİstifadəÜstünlük / məhdudiyyət

HSVHue, Saturation, ValueRəng diapazonu ilə obyekt seçimiRəng tonu ayrıca idarə olunur; işıq dəyişmələrindən tam azad deyil.
GrayscaleBir intensivlik kanalıKənar, threshold, sadə analizHesablama sadələşir, rəng məlumatı itir.

RGB-dən boz rəngə təxmini çevirmə: Y = 0.299R + 0.587G + 0.114B. Yaşıl kanalın çəkisi böyükdür, çünki insan görməsi yaşıl diapazona daha həssasdır.

gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
hsv  = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)
rgb  = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
HSV-də H rəng tonunu, S rəngin doymasını, V parlaqlığı ifadə edir. OpenCV-nin 8-bit HSV təqdimatında Hue diapazonu çox vaxt 0–179 olur; kitabxanalar arasında diapazon fərqlərinə diqqət edin.

18.6. Təsvirlərin yüklənməsi, göstərilməsi və saxlanılması

Şəkil faylı yaddaşdan oxunarkən əvvəlcə fayl yolu düzgün olmalıdır. cv2.imread() faylı oxuya bilməsə None qaytara bilər. Buna görə hər zaman nəticəni yoxlamaq lazımdır. cv2.imwrite() emal edilmiş təsviri diskə yazır.

import cv2
img = cv2.imread("photo.jpg")
if img is None:
    raise FileNotFoundError("Şəkil tapılmadı və ya format oxunmadı")

print(img.shape, img.dtype)

18.8. Həndəsi çevrilmələr: ölçüləndirmə, döndərmə və kəsmə

Həndəsi çevrilmələr pikselin koordinatını dəyişir. Resize təsvirin enini və hündürlüyünü dəyişir. Rotation təsviri müəyyən bucaq qədər döndərir. Crop maraq doğuran sahəni seçir. Ölçünü kiçiltmək üçün INTER_AREA, böyütmək üçün INTER_LINEAR və ya INTER_CUBIC çox vaxt münasib seçimdir.

resized = cv2.resize(img, (640, 480))
h, w = img.shape[:2]
M = cv2.getRotationMatrix2D((w/2, h/2), 30, 1.0)
rotated = cv2.warpAffine(img, M, (w, h))
crop = img[100:300, 150:450]  # y1:y2, x1:x2

Ölçüləndirmə nisbəti qorunmadan aparılarsa obyekt uzana və ya yastılana bilər. Dərin öyrənmə modelləri üçün letterbox yanaşması (nisbəti saxlayıb boş sahə əlavə etmək) geniş istifadə olunur.

18.9. Rəng və intensivlik üzrə emal

İntensivlik pikselin parlaqlıq qiymətidir. Parlaqlıq artırılması, kontrastın dəyişdirilməsi, gamma korreksiyası və histogram bərabərləşdirilməsi zəif görünən detalları üzə çıxara bilər.

Sadə xətti çevirmə: g(x,y)=αf(x,y)+β. Burada α kontrastı, β parlaqlığı dəyişir. Məsələn, α=1.3 kontrastı artırır; β=20 bütün piksellərə 20 əlavə edir (qiymətlər diapazonda kəsilir).

bright = cv2.convertScaleAbs(img, alpha=1.2, beta=25)
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
equalized = cv2.equalizeHist(gray)

CLAHE lokal histogram bərabərləşdirməsidir: təsviri kiçik bloklara bölür və kontrastı lokal artırır. Həddən artıq tətbiq səs-küyü də gücləndirə bilər.

18.10. Səs-küy növləri və təsvirlərin filtrlənməsi

Səs-küy görüntüyə təsadüfi və ya sistematik şəkildə qarışan arzuolunmaz dəyişiklikdir. Sensorun istiliyi, zəif işıq, ötürmə xətası və sıxılma artefaktları səbəb ola bilər.

Filtrləmə səs-küyü azaldır, amma çox güclü filtr incə kənarları və teksturanı da silə bilər. Ona görə “ən hamar görüntü” həmişə “ən yaxşı görüntü” deyil.

18.11. Gaussian, Median və Bilateral filtrlər

Gaussian blur qonşu pikselləri məsafəyə görə çəkiləndirir. Mərkəzə yaxın piksellərin təsiri daha böyükdür. Median blur qonşuluqdakı qiymətlərin medianını götürür; kəskin impuls nöqtələrini aradan qaldırmaqda faydalıdır. Bilateral filter həm məkan yaxınlığını, həm də rəng/intensivlik oxşarlığını nəzərə alır; kənarları qorumağa çalışaraq hamarlaşdırır.

18.12. Kənarların aşkarlanması: Sobel, Laplacian və Canny

Kənar təsvirin intensivliyinin sürətlə dəyişdiyi sərhəddir. Obyektin formasını, xəttini və konturunu tapmaq üçün istifadə olunur. Sobel x və y istiqamətlərində birinci törəməni təxmini hesablayır. Laplacian ikinci törəməyə əsaslanır. Canny bir neçə mərhələni birləşdirir: səs-küyü yumşaltma, gradient hesabı, non-maximum suppression, iki hədd və hysteresis.

Gradientin modulu: G = √(Gx² + Gy²). İstiqamət: θ = atan2(Gy,Gx). Gradient böyükdürsə, həmin yerdə kənar olma ehtimalı yüksəkdir.

gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
sx = cv2.Sobel(gray, cv2.CV_64F, 1, 0, ksize=3)
lap = cv2.Laplacian(gray, cv2.CV_64F)
edges = cv2.Canny(gray, 80, 160)

Canny hədləri aşağı və yuxarı həddir. Aşağı hədd zəif kənar namizədlərini, yuxarı hədd güclü kənarları müəyyən edir. Hədləri görüntüyə uyğun seçmək lazımdır.

18.13. Binarlaşdırma və thresholding üsulları

Binarlaşdırma boz təsviri iki sinifli təsvirə çevirir: ön plan və fon. Qlobal threshold hər pikselə eyni T həddini tətbiq edir: g(x,y)=255, əgər f(x,y)>T, əks halda 0. Adaptive threshold lokal qonşuluqdan hədd hesablayır. Otsu metodu isə histogram əsasında siniflərarası dispersiyanı maksimum edən həddi avtomatik seçir.

_, binary = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)
adaptive = cv2.adaptiveThreshold(
    gray, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
    cv2.THRESH_BINARY, 11, 2)
_, otsu = cv2.threshold(
    gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)

Qlobal hədləmə işıqlandırma sabit olanda yaxşı işləyə bilər. Sənəd şəkli kölgəli və qeyri-bərabər işıqlıdırsa adaptive threshold daha münasib ola bilər.

18.14. Morfoloji əməliyyatlar: Erosion, Dilation, Opening və Closing

Morfoloji əməliyyatlar binar təsvirin formasını struktur elementi (kernel) ilə dəyişir. Erosion ön plan sahəsini daraldır və kiçik ağ nöqtələri silə bilər. Dilation ön planı genişləndirir və yaxın sahələri birləşdirə bilər. Opening = erosion → dilation kiçik ağ səs-küyü azaltmaq üçün; Closing = dilation → erosion kiçik qara boşluqları doldurmaq üçün istifadə olunur.

kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (3,3))
eroded = cv2.erode(binary, kernel, iterations=1)
dilated = cv2.dilate(binary, kernel, iterations=1)
opened = cv2.morphologyEx(binary, cv2.MORPH_OPEN, kernel)
closed = cv2.morphologyEx(binary, cv2.MORPH_CLOSE, kernel)

Kernel ölçüsü nəticəyə birbaşa təsir edir. Böyük kernel obyektin incə hissələrini yox edə və ya yaxın obyektləri birləşdirə bilər.

18.15. Konturların aşkarlanması və təsvir xüsusiyyətlərinin çıxarılması

Kontur eyni rəngə və ya intensivliyə malik əlaqəli sahənin sərhəd nöqtələrinin ardıcıllığıdır. Konturların sahəsi, perimetri, sərhəd düzbucaqlısı, mərkəzi, dairəviliyi və aspekt nisbəti hesablana bilər.

contours, hierarchy = cv2.findContours(
    binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
for c in contours:
    area = cv2.contourArea(c)
    perimeter = cv2.arcLength(c, True)
    x,y,w,h = cv2.boundingRect(c)
    if area > 100:
        print(area, perimeter, (x,y,w,h))

Kontur əsaslı xüsusiyyətlər sadə formalı obyektlərdə faydalıdır. Mürəkkəb görüntülərdə işıq, örtülmə və fon dəyişməsi kontur çıxarılmasını çətinləşdirir. Dərin öyrənmə modelləri daha mürəkkəb xüsusiyyətləri məlumatdan öyrənə bilər.

18.16. Təsvirlərin seqmentasiyasına giriş

Seqmentasiya təsviri mənalı sahələrə ayırır. Semantic segmentation hər pikselə sinif verir (bütün avtomobillər eyni sinif). Instance segmentation eyni sinifdəki ayrı-ayrı obyektləri fərqləndirir (avtomobil A və avtomobil B). Panoptic segmentation hər piksel üçün həm sinif, həm də obyekt identifikasiyasını birləşdirir.

Sadə seqmentasiya threshold, rəng diapazonu, watershed və region-growing ilə aparıla bilər. Müasir yanaşmalar U-Net, Mask R-CNN və digər neyron şəbəkələrindən istifadə edir. Seqmentasiya nəticəsi maskadır: maskada obyektə aid piksellər 1, fon pikselləri 0 kimi kodlana bilər.

18.17. Histogram və təsvirlərin statistik təhlili

Histogram piksel intensivliklərinin neçə dəfə rast gəlindiyini göstərir. X oxu intensivlik (0–255), Y oxu həmin qiymətin tezliyidir. Histogramın sola yığılması qaranlıq, sağa yığılması parlaq görüntüyə işarə edə bilər. Geniş yayılma yüksək kontrastla əlaqəli ola bilər.

Əsas statistik göstəricilər: orta qiymət μ = (1/N)Σxi, dispersiya σ²=(1/N)Σ(xi−μ)², standart kənarlaşma σ=√σ². Bu göstəricilər təsvirin ümumi parlaqlığı və dəyişkənliyi barədə ilkin fikir verir, lakin məkan quruluşunu təkbaşına izah etmir.

hist = cv2.calcHist([gray], [0], None, [256], [0,256])
mean, std = cv2.meanStdDev(gray)
print("Orta:", mean[0][0], "Std:", std[0][0])

18.18. Python və OpenCV ilə ilkin kompüter görmə tətbiqləri

İlkin tətbiqdə məqsəd proqramın bütün mərhələlərini birləşdirməkdir: faylı oxumaq, ölçünü yoxlamaq, boz rəngə çevirmək, filtrləmək, kənarları tapmaq, konturları çəkmək və nəticəni saxlamaq.

import cv2
img = cv2.imread("sample.jpg")
if img is None:
    raise ValueError("sample.jpg tapılmadı")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
blur = cv2.GaussianBlur(gray, (5,5), 0)
edges = cv2.Canny(blur, 70, 150)
contours, _ = cv2.findContours(
    edges, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
out = img.copy()
cv2.drawContours(out, contours, -1, (0,255,0), 2)
cv2.imwrite("edges.png", edges)
cv2.imwrite("contours.png", out)

Bu klassik emal nümunəsi obyektin semantik sinfini öz-özünə öyrənmir. O, yalnız piksel dəyişmələri və konturlarla işləyir. “Bu kontur avtomobildir” qərarı üçün təlim edilmiş təsnifat/aşkarlama modeli tələb oluna bilər.
