Fayllar:
- index.html: 19 bölməli interaktiv veb kitab. Chrome/Edge/Firefox ilə açın.
- MDU_Fesil_19_Colab_Laboratoriya.ipynb: Google Colab laboratoriyası.
- README_AZ.txt: bu təlimat.

Veb kitabda interaktiv CNN ölçü kalkulyatoru, IoU qutu kalkulyatoru, Precision/Recall/F1 qrafiki, ssenari əsaslı avtomatik qiymətləndirilən yoxlama sualları, kod nümunələri və laboratoriya rubrikası var.

Colab notebook:
1. Google Colab açın: https://colab.research.google.com/
2. File > Upload notebook ilə .ipynb faylını yükləyin.
3. Runtime > Change runtime type bölməsində GPU seçin (əgər əlçatandırsa).
4. Hüceyrələri ardıcıllıqla icra edin.
