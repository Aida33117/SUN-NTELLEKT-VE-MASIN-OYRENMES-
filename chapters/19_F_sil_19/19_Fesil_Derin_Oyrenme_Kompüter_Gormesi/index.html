19.1. Dərin öyrənmədə kompüter görməsinin yeri və tətbiq sahələri

Dərin öyrənmə kompüter görməsində təsvirin içindəki faydalı xüsusiyyətləri əl ilə yazılmış qaydalarla deyil, çoxsaylı nümunələrdən öyrənir. Klassik yanaşmada mühəndis kənar, tekstura, rəng histogramı kimi xüsusiyyətləri seçir; CNN isə təlim zamanı sadə xətlərdən başlayaraq mürəkkəb formalar və obyekt hissələrinə qədər iyerarxik təsvirlər qurur.

Bu yanaşma tibbi görüntülərdə şiş sahələrinin aşkarlanması, istehsalatda qüsurlu məhsulun tapılması, kənd təsərrüfatında bitki xəstəliklərinin tanınması, nəqliyyatda avtomobil/piyada aşkarlanması, robototexnikada maneələrdən yayınma və peyk təsvirlərində obyekt xəritələşdirilməsi üçün istifadə olunur.

Elmi məntiq: modelin öyrəndiyi xüsusiyyətlər datasetin paylanmasından asılıdır. Laboratoriya şəraitində yüksək nəticə göstərən model real zavodda fərqli işıq, kamera bucağı və məhsul növündə zəifləyə bilər. Buna domain shift deyilir.

19.2. Təsvirlərin maşın öyrənməsi üçün hazırlanması

Modelə verilən şəkil rəqəmsal tensor şəklində təqdim olunur. Rəngli şəkil adətən H×W×C ölçülüdür. Batch əlavə edildikdə N×H×W×C (TensorFlow) və ya N×C×H×W (PyTorch) düzülüşü istifadə oluna bilər. Piksel qiymətləri 0–255 diapazonundan 0–1 diapazonuna keçirilə və ya pretrained modelin gözlədiyi orta qiymət/standart kənarlaşma ilə normallaşdırıla bilər.

Hazırlıq mərhələləri: faylları oxumaq; korlanmış faylları yoxlamaq; sinif etiketlərini kodlaşdırmaq; şəkilləri ölçüləndirmək; train/validation/test bölmək; augmentation tətbiq etmək; sinif balansını yoxlamaq. Detection üçün şəkil ilə yanaşı bounding box koordinatları da eyni çevrilmələrə uyğun dəyişdirilməlidir.

import torch
from torchvision import transforms

train_tfms = transforms.Compose([
    transforms.Resize((224, 224)),
    transforms.RandomHorizontalFlip(p=0.5),
    transforms.ColorJitter(brightness=0.15, contrast=0.15),
    transforms.ToTensor(),  # [0,1]
    transforms.Normalize(
        mean=[0.485, 0.456, 0.406],
        std=[0.229, 0.224, 0.225]
    )
])

Augmentation yalnız təlim məlumatına tətbiq olunur. Test məlumatını süni şəkildə dəyişərək nəticəni yaxşı göstərmək olmaz. Tibbi və sənaye şəkillərində horizontal flip və rotation hər zaman məna baxımından düzgün deyil; məsələn, yazı olan təsviri çevirmək etiketi dəyişə bilər.

19.3. Konvolyusional neyron şəbəkələrinin (CNN) kompüter görməsində rolu

CNN təsvirlərdə lokal əlaqələri nəzərə alan neyron şəbəkəsidir. Tam əlaqəli şəbəkədə hər giriş neyronu çoxlu çıxışlarla əlaqələnə bilər. Konvolyusiyada isə kiçik filtr (kernel) təsvir üzərində sürüşür və hər mövqedə eyni çəkilərdən istifadə edir. Bu, parametr sayını azaldır və kənar/tekstura kimi lokal nümunələri tapmağa kömək edir.

İlk qatlar çox vaxt kənar və rəng keçidləri kimi sadə nümunələrə, dərin qatlar isə hissələrə və obyekt səviyyəli kombinasiyalara həssas olur. Bu izah konseptualdır: konkret filtrin nə öyrəndiyini yalnız çəkiləri və aktivasiya xəritələrini analiz etməklə yoxlamaq olar.

19.4. CNN arxitekturasında Convolution, Pooling və Fully Connected qatları

Convolution: kernel giriş üzərində sürüşərək feature map yaradır. Pooling: məkan ölçüsünü azaldaraq lokal sahənin maksimum və ya orta qiymətini saxlayır. Fully Connected: çıxarılan xüsusiyyətləri sinif skorlarına çevirir. Müasir arxitekturalarda Global Average Pooling və residual bağlantılar da geniş yayılıb.

Konvolyusiya çıxış ölçüsü: O = floor((I + 2P − K)/S) + 1. Burada I giriş ölçüsü, K kernel, P padding, S stride-dir. Məsələn, I=32, K=3, P=1, S=1 olduqda O=32; padding ölçünü saxlayır.

İnteraktiv arxitektura: qatlardakı ölçüləri dəyişmək üçün parametrləri aşağıda sınayın.

19.5. Təsvirlərin təsnifatı (Image Classification)

Təsnifat bütöv təsvirə sinif etiketi və sinif ehtimalları verir. Məsələn, bitki yarpağının “sağlam”, “pas xəstəliyi”, “ləkə xəstəliyi” siniflərindən hansına aid olduğunu müəyyən edir. Çoxsinifli təsnifatda softmax funksiyası logitləri ehtimala çevirir: pᵢ = exp(zᵢ)/Σⱼ exp(zⱼ). Binary tapşırıqda sigmoid geniş istifadə olunur.

Əsas qiymətləndirmə göstəriciləri accuracy, precision, recall, F1 və confusion matrix-dir. Siniflər balanssız olduqda yalnız accuracy-yə güvənmək olmaz. Məsələn, nümunələrin 95%-i sağlam, 5%-i xəstədirsə, hamısına “sağlam” deyən model 95% accuracy ala bilər, lakin xəstələri tapmaya bilər.

19.6. Transfer Learning və əvvəlcədən öyrədilmiş modellər

Transfer learning böyük datasetdə öyrədilmiş modelin biliklərini yeni, daha kiçik tapşırığa daşımaqdır. Praktikada iki strategiya var: (1) feature extraction — backbone qatlarını dondurub yalnız yeni classifier qatını öyrətmək; (2) fine-tuning — əvvəlcə yeni başlığı öyrədib sonra backbone-un bir hissəsini kiçik learning rate ilə yenidən öyrətmək.

ImageNet çəkiləri ilə başlayan ResNet/EfficientNet kimi modellər az nümunəli tapşırıqlarda sıfırdan təlimə nisbətən daha tez nəticə verə bilər. Lakin yeni datasetin domeni fərqlidirsə (məsələn, adi foto ilə rentgen), uyğunlaşdırma və ayrıca test vacibdir.

from torchvision.models import resnet18, ResNet18_Weights
import torch.nn as nn

weights = ResNet18_Weights.DEFAULT
model = resnet18(weights=weights)
for p in model.parameters():
    p.requires_grad = False
model.fc = nn.Linear(model.fc.in_features, num_classes)
# Optimizer yalnız trainable parametrləri yeniləyir.

19.7. Obyektlərin aşkarlanması (Object Detection) anlayışı

Object detection bir təsvir daxilində bir və ya bir neçə obyektin sinfini və yerini müəyyən edir. Nəticə adətən (class, confidence, x₁, y₁, x₂, y₂) formasındadır. Təsnifat bütün şəkilə etiket verir; detection isə hər obyekt üçün ayrıca çərçivə verir.

Detection modeli obyektin fonla qarışdığı, qismən örtüldüyü və müxtəlif ölçüdə göründüyü səhnələrdə çətinlik çəkə bilər. Kiçik obyektlər üçün yüksək giriş çözünürlüğü və uyğun dataset xüsusilə əhəmiyyətlidir.

19.8. Region-based yanaşmalar: R-CNN, Fast R-CNN və Faster R-CNN

R-CNN ailəsi əvvəlcə mümkün obyekt sahələrini (region proposals) tapır, sonra regionları CNN ilə təhlil edir. Orijinal R-CNN hər region üçün CNN xüsusiyyətlərini ayrıca çıxardığına görə yavaşdır. Fast R-CNN bütün təsvir üçün feature map yaradır və regionlardan RoI pooling ilə xüsusiyyət götürür. Faster R-CNN Region Proposal Network (RPN) əlavə edərək təklifləri şəbəkənin daxilində öyrənir.

19.9. YOLO alqoritminin arxitekturası və iş prinsipi

YOLO (You Only Look Once) bir mərhələli detection ailəsidir. Giriş təsviri backbone vasitəsilə xüsusiyyətlərə çevirir, neck müxtəlif ölçülü xüsusiyyət xəritələrini birləşdirir, head isə bounding box, sinif və confidence proqnozları verir. “Bir mərhələli” ifadəsi region proposal və ayrıca region classifier mərhələlərinə ehtiyac olmadan birbaşa proqnoz verməsini bildirir.

YOLO versiyaları arasında arxitektura və loss detalları dəyişir. Ona görə bütün YOLO modelləri üçün eyni qat sayı və eyni çıxış forması iddia etmək düzgün deyil. Təlimdə box regression, classification və bəzi versiyalarda objectness/quality ilə bağlı itki komponentləri optimallaşdırılır.

19.10. Obyektlərin lokallaşdırılması və Bounding Box anlayışı

Bounding box obyektin ətrafını əhatə edən düzbucaqlıdır. Koordinatlar (x₁,y₁,x₂,y₂) və ya (x_center,y_center,width,height) formatında verilə bilər. YOLO dataset formatında koordinatlar çox vaxt təsvirin eninə/hündürlüyünə bölünərək 0–1 aralığında normallaşdırılır.

Qutunun sahəsi: A=(x₂−x₁)(y₂−y₁). Koordinatlar piksel ölçüsündədirsə, x en, y hündürlük istiqamətidir. Şəkil resize/letterbox ediləndə qutu koordinatları da eyni transformasiyaya uyğun çevrilməlidir.

19.11. Non-Maximum Suppression və aşkarlama nəticələrinin süzgəcdən keçirilməsi

Model eyni obyekt üçün bir neçə üst-üstə düşən qutu proqnozlaşdıra bilər. NMS əvvəlcə confidence-a görə qutuları sıralayır, ən yüksək skorlu qutunu saxlayır, onunla IoU həddi üzərində üst-üstə düşən eyni sinif qutularını silir və prosesi davam etdirir. NMS iki fərqli obyektin qutuları üst-üstə düşəndə ehtiyatla tətbiq edilməlidir.

NMS həddi çox aşağı olsa, yaxın obyektlərdən biri səhvən silinə bilər; çox yüksək olsa, eyni obyekt üçün təkrarlanan qutular qala bilər. Confidence threshold və IoU threshold ayrı parametrlərdir: biri proqnoz skorunu, digəri qutuların üst-üstə düşməsini idarə edir.

19.12. Təsvirlərin semantik və instans seqmentasiyası

Semantic segmentation hər pikselə sinif etiketi verir. Eyni sinifə aid iki avtomobilin pikselləri eyni “car” sinfinə daxildir. Instance segmentation isə obyekt nümunələrini ayırır: avtomobil A və avtomobil B ayrı maskalar alır. Panoptic segmentation bu iki yanaşmanı birləşdirir.

Seqmentasiya maskası binary və ya çoxsinifli ola bilər. Pixel accuracy ümumi düzgün piksel faizidir, lakin sinif balanssızlığında yanıltıcı ola bilər. IoU və Dice/F1 maska keyfiyyətini qiymətləndirmək üçün geniş istifadə olunur.

19.13. Mask R-CNN və seqmentasiya modelləri

Mask R-CNN Faster R-CNN detektorunu hər aşkarlanan obyekt üçün maska proqnozlaşdıran əlavə budaqla genişləndirir. Model eyni zamanda sinif, bounding box və instance maska verir. Mask head adətən hər RoI üçün kiçik konvolyusional şəbəkə kimi işləyir. U-Net isə encoder-decoder arxitekturası və skip connection-larla xüsusilə tibbi görüntü seqmentasiyasında geniş tətbiq olunub.

Mask keyfiyyəti IoU və Dice ilə ölçülə bilər: Dice=2|A∩B|/(|A|+|B|). Kiçik obyektlərdə bir neçə piksel fərq göstəriciyə ciddi təsir edə bilər.

19.14. Üz aşkarlanması və üz tanıma sistemləri

Üz aşkarlanması şəkildə üzün yerini tapır. Üz tanıma isə üz təsvirindən biometrik şablon/embedding çıxarıb şəxsin kimliyini yoxlama və ya namizədlərlə müqayisə etmə tapşırığıdır. Bunlar eyni deyil. Üz aşkarlanması “üz haradadır?” sualına, tanıma isə “bu üz kimə uyğun gəlir?” sualına cavab verir.

Üz tanıma yüksək məxfilik və hüquqi risk daşıyır. Tədris laboratoriyasında üz aşkarlanması ilə məhdudlaşmaq, şəxsi identifikasiya aparmamaq, razılıq alınmış və hüquqi istifadəsi aydın məlumatlardan istifadə etmək tövsiyə olunur. Biometrik sistemlərdə false accept/false reject, demographic performance variation, spoofing və data protection ayrıca təhlil edilməlidir.

19.15. Video axınında obyektlərin izlənməsi (Object Tracking)

Detection hər kadrda obyektləri tapır; tracking isə ardıcıl kadrlarda eyni obyektə eyni ID-ni verməyə çalışır. Tracking-by-detection yanaşmasında detektor kadr başına qutuları verir, tracker isə qutuları zaman üzrə əlaqələndirir. SORT Kalman filter və Hungarian assignment kimi mexanizmlərdən istifadə edir; Deep SORT görünüş embedding-i əlavə edir. ByteTrack aşağı confidence aşkarlamalarını da əlaqələndirmə prosesində nəzərə alır.

İzləmə keyfiyyəti ID switch, track fragmentation, HOTA, MOTA və IDF1 kimi göstəricilərlə qiymətləndirilə bilər. Kamera hərəkəti, örtülmə və oxşar görünüşlü obyektlər identifikasiya ardıcıllığını çətinləşdirir.

19.16. Real vaxt rejimində kompüter görmə sistemlərinin qurulması

Real-vaxt sistemində təkcə modelin dəqiqliyi deyil, kadr gecikməsi və davamlılıq da vacibdir. Ümumi gecikmə: capture + preprocess + inference + postprocess + display/transfer. FPS təxmini olaraq emal olunan kadr sayının saniyəyə nisbətidir. 30 FPS hədəfi üçün orta emal müddəti təxminən 33.3 ms-dən çox olmamalıdır; bu, bütün sistem gecikməsinin sərhədi kimi qəbul edilməməlidir.

Edge cihazlarda model quantization, pruning, TensorRT/ONNX optimallaşdırması və input ölçüsünün seçilməsi ilə sürət artırıla bilər. Ancaq optimallaşdırma dəqiqliyə təsir edə bilər; hər dəyişiklikdən sonra test aparılmalıdır.

19.17. Modelin dəqiqliyinin qiymətləndirilməsi: IoU, Precision, Recall və mAP

IoU proqnoz qutusu ilə ground-truth qutusunun kəsişməsinin birləşməyə nisbətidir: IoU=|A∩B|/|A∪B|. IoU 1-ə yaxın olduqca qutular daha çox üst-üstə düşür. Precision = TP/(TP+FP), Recall = TP/(TP+FN). TP doğru aşkarlama, FP yanlış müsbət, FN buraxılmış obyekt deməkdir.

AP precision-recall əyrisi altında sahənin hesablanması ilə əlaqəlidir. mAP müxtəlif siniflər üzrə AP-nin ortasıdır. mAP@0.5 IoU həddi 0.5 olduqda, mAP@0.5:0.95 isə adətən 0.50-dən 0.95-ə qədər müxtəlif IoU hədlərinin ortalamasını ifadə edir. Konkret implementasiyada interpolasiya və matching qaydaları fərqlənə bilər.

19.18. TensorFlow, Keras və PyTorch ilə kompüter görmə modellərinin tətbiqi

TensorFlow/Keras yüksək səviyyəli model qurma və təlim API-ləri təqdim edir. PyTorch dinamik hesablama qrafiki və geniş model ekosistemi ilə tədqiqatda geniş istifadə olunur. Hər üç ekosistemdə əsas proses eynidir: dataset → model → loss → optimizer → training loop → validation → checkpoint → test.

# Keras ilə transfer learning üçün minimal skelet
import tensorflow as tf
base = tf.keras.applications.MobileNetV2(
    input_shape=(224,224,3), include_top=False,
    weights="imagenet"
)
base.trainable = False
inputs = tf.keras.Input(shape=(224,224,3))
x = tf.keras.applications.mobilenet_v2.preprocess_input(inputs)
x = base(x, training=False)
x = tf.keras.layers.GlobalAveragePooling2D()(x)
outputs = tf.keras.layers.Dense(num_classes, activation="softmax")(x)
model = tf.keras.Model(inputs, outputs)
model.compile(optimizer="adam",
              loss="sparse_categorical_crossentropy",
              metrics=["accuracy"])

Detection üçün yalnız image classification modelini çağırmaq kifayət etmir: bounding box etiketləri, detection loss, matching, NMS və uyğun qiymətləndirmə proseduru lazımdır. Hazır Ultralytics API-si bu mərhələlərin çoxunu birləşdirir.

19.19. Kompüter görməsində məlumat dəstləri və annotasiya prosesi

Dataset şəkillər/video və onlara uyğun annotasiyalardan ibarətdir. Detection annotasiyası sinif + bounding box, segmentation annotasiyası maska/polygon, classification annotasiyası isə şəkil üçün sinif etiketi ola bilər. Annotasiyanın keyfiyyəti modelin öyrənə biləcəyi sərhədi müəyyən edir.

Annotasiya protokolu əvvəlcədən yazılmalıdır: obyektin sərhədi necə çəkilir, örtülmüş obyekt necə işarələnir, çox kiçik obyekt saxlanılırmı, “ignore” sahəsi varmı? Annotatorlar arasında uyğunluğu ölçmək və nümunələri ikinci annotatorla yoxlamaq faydalıdır.

19.20. Kompüter görməsinin sənaye, təhlükəsizlik, robototexnika və digər sahələrdə tətbiqi

Sənaye: səth qüsuru, ölçü nəzarəti, montaj yoxlaması. Təhlükəsizlik: təhlükəli zonaya daxilolma, PPE (dəbilqə/jilet) aşkarlanması; şəxsin identifikasiyası olmadan da təhlükəsizlik analitikası mümkündür. Robototexnika: obyektin lokallaşdırılması, grasping, maneə aşkarlanması. Kənd təsərrüfatı: xəstəlik, alaq otu, meyvə yetişkənliyi. Tibb: radioloji görüntü təhlili — klinik qərarı müstəqil əvəz etməməlidir.

İstehsalata yerləşdirmədən əvvəl risk analizi aparılmalıdır: yanlış aşkarlamanın nəticəsi, məlumatın məxfiliyi, modelin dəyişən mühitdə sabitliyi, insan nəzarəti, audit jurnalı və yenidən təlim proseduru müəyyən edilməlidir.

Laboratoriya işi №19: YOLO və ya CNN əsaslı modeldən istifadə etməklə təsvirlərdə obyektlərin aşkarlanması, nəticələrin vizuallaşdırılması və modelin IoU/mAP göstəriciləri ilə qiymətləndirilməsi

Məqsəd: real görüntü datasetini hazırlamaq, əvvəlcədən öyrədilmiş YOLO modelindən inference almaq, annotasiya ilə proqnozu müqayisə etmək və qiymətləndirmə göstəricilərini hesablamaq.

A mərhələsi — hazır model ilə inference

  1. Google Colab-da GPU runtime seçin (mövcud olduqda).
  2. Ultralytics kitabxanasını quraşdırın.
  3. COCO tipli demo şəkli və ya müəllim tərəfindən verilmiş icazəli şəkil/video yükləyin.
  4. YOLO modelini çağırın, confidence həddini 0.25 seçin.
  5. Bounding box, sinif və confidence nəticələrini vizuallaşdırın.
  6. Confidence 0.15, 0.25, 0.50 dəyərləri ilə nəticələri müqayisə edin.

B mərhələsi — öz datasetinizlə təlim

  1. Ən azı 2 sinif seçin və hər sinif üçün müxtəlif işıq/bucaq/məsafədə görüntü toplayın.
  2. CVAT və ya Roboflow ilə bounding box annotasiyası aparın.
  3. Train/validation/test bölgüsünü çəkiliş sessiyalarını qarışdırmadan qurun.
  4. Dataset YAML faylında yolları və sinif adlarını göstərin.
  5. Kiçik model ilə təlim aparın; epoch, image size və batch ölçüsünü qeyd edin.
  6. Test nəticəsində precision, recall, mAP50 və mAP50-95 göstəricilərini şərh edin.

from ultralytics import YOLO
model = YOLO("yolo26n.pt")
model.train(
    data="/content/dataset/data.yaml",
    epochs=30,
    imgsz=640,
    batch=8,
    project="/content/runs",
    name="mdu_ch19"
)
metrics = model.val(data="/content/dataset/data.yaml")
print(metrics.box.map, metrics.box.map50)

Praktiki tapşırıqlar

  1. 224×224×3 ölçülü float32 tensorun bir şəkil üçün yaddaş həcmini hesablayın.
  2. ImageNet pretrained ResNet modelinin son qatını 5 sinif üçün uyğunlaşdırın.
  3. Convolution çıxış ölçüsünü I=64, K=3, P=1, S=2 üçün hesablayın.
  4. Eyni obyekt təsviri üçün classification və detection çıxışlarını müqayisə edin.
  5. R-CNN, Fast R-CNN və Faster R-CNN arxitekturalarının fərqini cədvəldə göstərin.
  6. YOLO confidence həddini dəyişərək FP/FN sayına təsirini ölçün.
  7. İki bounding box üçün IoU-nu əl ilə və interaktiv kalkulyatorla hesablayın.
  8. NMS IoU həddinin 0.3 və 0.7 seçilməsinin nəticələrini izah edin.
  9. Semantic və instance segmentation üçün bir real tətbiq nümunəsi göstərin.
  10. Video üzərində tracking zamanı ID switch-in nə demək olduğunu izah edin.
  11. Datasetdə train/test data leakage riskini araşdırın.
  12. Modelin mAP50 və mAP50-95 nəticələrini müqayisə edib hansı ssenaridə hansı göstəricinin vacib olduğunu əsaslandırın.
