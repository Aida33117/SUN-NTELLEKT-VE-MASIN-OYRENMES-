MDU — Fəsil 20. Yekun layihə: Maşın öyrənməsi əsasında intellektual analiz sistemi

Fayllar:
- index.html: interaktiv veb kitab; Chrome/Edge/Firefox ilə açın.
- MDU_Fesil_20_Yekun_ML_Layihe_Colab.ipynb: tam layihə nümunəsi üçün Google Colab notebook.
- README_AZ.txt: bu təlimat.

Veb kitabda:
- Layihə həyat dövrünün interaktiv arxitektura diaqramı.
- 10 bölmənin elmi və addım-addım izahı.
- Dataset, preprocessing, baseline, model seçimi, təlim, qiymətləndirmə, prototip və hesabat nümunələri.
- İnteraktiv classification metrik kalkulyatoru.
- Layihə planlayıcısı və 8 həftəlik iş qrafiki.
- 14 ssenari əsaslı yoxlama sualı və izahlı cavablar.
- Laboratoriya işinin 100 ballıq qiymətləndirmə rubrikası.

Colab notebook:
1. https://colab.research.google.com/ açın.
2. File > Upload notebook seçin və .ipynb faylını yükləyin.
3. Hüceyrələri ardıcıllıqla icra edin.
4. Notebook OpenML-dəki wine-quality-red datasetini internet üzərindən endirir.
5. Nümunə layihə binary classification qurur: quality >= 6 olduqda good=1.
6. Real layihənizdə dataset, hədəf hədd, dəyişənlər və metriklər əsaslandırılmalıdır.

Qeyd:
Notebook-un rəqəmləri nümunə dataset və seçilmiş təsadüfi seed əsasında hesablanır; əvvəlcədən sabit nəticə kimi qəbul edilməməlidir.
Datasetin lisenziyası və OpenML versiyası hesabat hazırlanarkən yoxlanmalıdır.
Yüksək riskli qərarlarda model yalnız qərar dəstəyi kimi istifadə edilməli, insan nəzarəti saxlanmalıdır.
